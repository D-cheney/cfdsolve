# 质量、动量与能量守恒方程概览

CFD 的一切都建立在守恒之上：求解器把计算域切成许多互不重叠的控制体，让每个控制体在质量、动量、能量（必要时还有组分与湍流量）上逐项平衡。质量守恒给出速度场的约束，动量守恒（Navier–Stokes 方程）决定速度分布，能量守恒决定温度场，三者再通过状态方程与物性关系耦合。本文从控制体观点给出三大方程的守恒形式、牛顿流体本构与闭合关系，并说明工程上如何取舍与校验。

## 1. 结论与适用场景

核心结论：**守恒形式描述的是"某个量在控制体内的积累等于净通量加上源项"，而不是某一点的导数关系。** 这一观点直接决定了有限体积法的局部守恒性，也决定了方程该保留哪几项：

- 不可压、等温流动：只需连续性与动量方程，压力作为约束变量由压力—速度耦合确定；
- 存在传热、可压缩、燃烧或相变：必须补充能量方程，并可能加入组分方程；
- 湍流：时均后多出雷诺应力项，必须用湍流模型闭合；
- 多相、多组分：每个相或组分各自守恒，通过相间或组分交换项耦合。

判断能否省略某个方程，本质是判断该物理量是否反过来影响已求解的方程。若温度不影响密度、物性与浮力，动量与能量可以单向耦合；一旦浮力或变物性起作用，就必须双向求解。适用场景覆盖几乎所有连续介质流动，例外是稀薄气体（连续介质假设失效，需用 DSMC 或动理学方法）与需要分子尺度信息的场合。

## 2. 物理与数学基础

守恒律有两种等价的书写层次。**微分形式**在一点上成立，便于推导与理论分析；**积分形式**在有限体积上成立，是有限体积法直接离散的对象。两者通过高斯散度定理互相转换。

对任意守恒标量 $\phi$（单位质量携带量），守恒律的物理叙述是：

$$
\text{积累率} = \text{净对流进入} + \text{净扩散进入} + \text{体积源}
$$

把这一叙述写成对固定控制体 $V$ 的积分守恒式：

$$
\frac{d}{dt}\int_V \rho\phi\,dV + \oint_{\partial V}\rho\phi\,\mathbf{u}\cdot d\mathbf{A} = \oint_{\partial V}\Gamma_\phi\nabla\phi\cdot d\mathbf{A} + \int_V S_\phi\,dV
$$

左边第一项是控制体内该量的总储存变化率，第二项是穿过闭合表面的净对流通量；右边是净扩散通量与体积源。三个输运机制各有特征：

- **对流**，通量 $\rho\phi\mathbf{u}$：随流体一起输运，方向由速度决定，是非线性与双曲性的来源；
- **扩散**，通量 $\Gamma_\phi\nabla\phi$：由梯度驱动，从高值流向低值，是椭圆的、光滑的，负责抹平陡峭分布；
- **源项** $S_\phi$：体积生成或消耗，例如重力、化学反应、辐射、相变潜热、旋转科氏力。

动量与能量都可以塞进这一模板：动量取 $\phi=\mathbf{u}$ 且源项含压力与重力；能量取内能、焓或总能量。区别只在扩散系数 $\Gamma_\phi$ 与源项 $S_\phi$ 的具体形式。把不同物理统一成同一模板，正是有限体积法能用一个框架处理多物理场的根本原因。更重要的推论是：内部界面上的通量对两侧控制体符号相反，求和时逐一抵消，因此离散层面天然满足局部守恒，再累加即得全局守恒。

## 3. 关键公式与推导

### 3.1 质量守恒（连续性方程）

质量对应的守恒量是 $\phi=1$，扩散项为零，于是微分形式为

$$
\frac{\partial \rho}{\partial t} + \nabla\cdot(\rho\mathbf{u}) = 0
$$

对不可压流体，$\rho$ 恒定，它就化为**速度散度约束**

$$
\nabla\cdot\mathbf{u} = 0
$$

这个式子不直接给出压力，但压力通过动量方程与这一约束共同确定速度场，这正是不可压求解的核心难点：压力没有独立的演化方程，而是被当作维持散度为零的拉格朗日乘子。若把微分形式在控制体上积分并对通量使用散度定理，就回到§2 的积分守恒式，二者对任意控制体等价，这也是有限体积法可以从积分形式出发而不损失一般性的原因。

### 3.2 动量守恒与 Navier–Stokes

取 $\phi=\mathbf{u}$，写出保留守恒形式的动量方程

$$
\frac{\partial(\rho\mathbf{u})}{\partial t} + \nabla\cdot(\rho\mathbf{u}\mathbf{u}) = -\nabla p + \nabla\cdot\boldsymbol{\tau} + \rho\mathbf{g} + \mathbf{S}_m
$$

牛顿流体的黏性应力张量是

$$
\boldsymbol{\tau} = \mu\left(\nabla\mathbf{u} + \nabla\mathbf{u}^{\mathrm{T}}\right) - \frac{2}{3}\mu(\nabla\cdot\mathbf{u})\,\mathbf{I}
$$

把它代回并整理，就得到 **Navier–Stokes 方程**。对常黏度不可压流体：

$$
\rho\left(\frac{\partial\mathbf{u}}{\partial t} + \mathbf{u}\cdot\nabla\mathbf{u}\right) = -\nabla p + \mu\nabla^{2}\mathbf{u} + \rho\mathbf{g}
$$

左侧是非线性对流加速度，右侧依次是压力梯度、黏性扩散与体积力。非线性对流项 $\mathbf{u}\cdot\nabla\mathbf{u}$ 是湍流、分离与混沌的根源，也是离散时最棘手的一项，它的处理方式直接决定数值耗散与稳定性。

### 3.3 能量守恒

可压缩流常求**总能量** $E = e + \frac{1}{2}|\mathbf{u}|^{2}$：

$$
\frac{\partial(\rho E)}{\partial t} + \nabla\cdot(\rho E\mathbf{u}) = -\nabla\cdot(p\mathbf{u}) + \nabla\cdot(k\nabla T) + \nabla\cdot(\boldsymbol{\tau}\cdot\mathbf{u}) + S_h
$$

右侧四项依次是**压力功、导热、黏性耗散功与外部热源**。低速传热问题更常用**焓**或温度形式，忽略压力功与黏性耗散：

$$
\rho c_p\left(\frac{\partial T}{\partial t} + \mathbf{u}\cdot\nabla T\right) = \nabla\cdot(k\nabla T) + S_h
$$

保留哪一形式取决于问题：高马赫数、激波管与气动加热必须用总能量形式，因为压力功与黏性耗散量级不可忽略；而水道流动、换热器与电子散热这类低马赫数问题，温度形式更稳定、更易与物性耦合。两者在低马赫数极限下应当一致，若结果差异明显，往往是边界或物性处理出了问题。

## 4. 工程做法与参数

**工程做法与参数**的起点是把物理判断落到方程取舍上，再用参数把离散稳定下来。

**方程组的取舍**。先判断可压缩性与传热：$Ma \leq 0.3$ 且温差不大时按不可压处理，可省能量方程；有浮力时用 Boussinesq 近似或真变密度；$Ma$ 较高时保留可压缩修正与能量方程。

**闭合关系**。未知量多于方程时必须有闭合，缺一不可：状态方程与热力学关系，如 $p=\rho R T$、$e=c_v T$；物性随温度与压力的函数 $k(T)$、$\mu(T)$、$c_p(T)$；湍流闭合，把雷诺应力 $\overline{\rho\mathbf{u}'\mathbf{u}'}$ 用湍流模型给出；以及组分扩散系数与相间交换关系。

**离散与参数**。有限体积法把每个方程化为 $a_P\phi_P = \sum_N a_N\phi_N + b$ 的稀疏线性系统。压力与动量亚松弛因子常取 0.3 与 0.7 量级，湍流量更小。压力参考点、参考温度、重力方向与参考高度都必须与边界设置一致，否则会出现虚假的浮力或压差。

**边界条件数目**。定常不可压动量方程需在每段边界给出速度或压力之一；能量方程需给出温度或热流之一；可压缩流的边界处理与特征线方向有关，需要对每条入流特征给定值、出流特征外推。边界条件欠约束会导致奇异系统，过约束则会引入强源汇而破坏守恒。工程上还要保证壁面无穿透与切向条件相容，避免在角点处出现相互矛盾的约束。

## 5. 可复现示例

用一段脚本核算控制体的质量与能量收支，是最廉价的守恒性检查。下面用进、出口面通量验证稳态不可压条件的净质量流是否为零：

```python
import numpy as np

rho = 998.2                        # 水的密度, kg/m^3
faces = [                          # (面积 m^2, 面法向平均速度 m/s, 类型)
    (0.0020,  2.00, "inlet"),
    (0.0025, -1.60, "outlet"),     # 出流速度取外法向, 必为负
    (0.0004,  0.00, "wall"),       # 无穿透
]

net = 0.0
for area, un, kind in faces:
    m = rho * area * un            # 质量流量 kg/s
    net += m
    print(f"{kind:6s} mdot = {m:+.6f} kg/s")

print("net mass flux =", f"{net:+.3e}", "kg/s")
print("relative imbalance =", f"{abs(net)/(rho*0.0020*2.0):.2e}")
```

步骤与判读：

1. 把每段边界的面积矢量与外法向速度相乘，得到带符号质量流量，流入为正、流出为负；
2. 求和应接近机器精度零（不可压且已收敛）；相对不平衡超过 $10^{-3}$ 就说明边界、离散或收敛仍有问题；
3. 能量收支同理：把 $\rho c_p T$ 的对流通量、导热与热源分别累加，残差应为零；
4. 换成瞬态问题后，还要把控制体内的储存项 $\frac{d}{dt}\int_V \rho\phi\,dV$ 一并计入收支。

把这个检查写进后处理脚本，和残差一起看，能挡住绝大多数"看起来收敛、实际不守恒"的问题。实际项目中还应把它固化成一条验收流水线：每次改网格、改边界或改模型后都重新跑一遍，只有当收支残差、目标量平直度与网格敏感性三项同时通过，才认为结果可用于工程判读。

## 6. 常见坑与排查

- **只解连续性加动量却报告温度**：能量方程根本没闭入，温度只是初始化的残影；
- **不可压却用理想气体密度**：密度恒定假设与状态方程冲突，应改用 Boussinesq 近似或真变密度；
- **漏掉浮力或重力**：自然对流问题中动量源项缺失，流速与换热会被严重低估；
- **湍流项未闭合**：用层流黏度算高雷诺数流动，结果必然失真，且往往还"看起来收敛"；
- **边界过约束**：入口同时给定压力和速度，系统变成奇异或引入强源汇；
- **只看残差**：局部残差小不代表全局守恒，必须做守恒报表。

排查顺序建议：先查边界与量纲，再看守恒收支，最后才调离散格式与松弛因子。实践中还要区分两类失败：一类是不收敛（残差振荡或发散），通常来自边界、格式或松弛；另一类是收敛到错误解，残差很漂亮但守恒被破坏，往往来自闭合关系或边界位置不当。后者更隐蔽，也更依赖守恒报表与基准对比才能发现。
