# 流动尺度、无量纲化与主导机制判断

建立任何 CFD 模型之前，都应先做一遍尺度分析。它的目的不是套公式，而是回答一个朴素问题：在这股流动里，惯性、黏性、浮力、压缩性和非定常效应，谁说了算？把控制方程用特征量无量纲化，各项前面的系数就会自动暴露出答案。本文从特征尺度选取出发，推导不可压缩 N-S 方程的无量纲形式，并说明如何用它选择模型与设定网格、时间步。

## 1. 结论与适用场景

一句话结论：**无量纲化把"物理"变成"系数"，看懂系数就抓住了主导机制。** 具体到工程决策：

- 惯性远大于黏性（$Re$ 很大）：湍流开始主导，需用湍流模型并加密壁面网格；
- 黏性不可忽略（$Re$ 很小）：可走层流或蠕流近似，网格需求大幅下降；
- 浮力与惯性可比（$Ri$ 或 $Gr/Re^{2}$ 接近 1）：动量方程必须保留浮力源项；
- 非定常项与对流项可比（$St$ 不可忽略）：必须做瞬态求解，稳态假设失效；
- 压缩性与惯性可比（$Ma$ 不可忽略）：必须求解能量方程并考虑密度变化。

尺度分析适合所有连续介质流动问题，是开题阶段成本最低、收益最高的动作。它尤其适合在"该用稳态还是瞬态""该用不可压还是可压""该用层流还是湍流"这类二选一上给出明确答案。反过来，如果连特征尺度都说不清，说明对问题的把握还不够，应先补物理认识再建模。一个直接的好处是：它能在花掉大量计算资源之前就否决掉一批不合理的方案，把试错成本降到纸面上。

## 2. 物理与数学基础

无量纲化的数学依据是**量纲齐次原理**：一个物理方程中各项的量纲必然相同，因此用同一组特征量去除各项后，各项变成纯数，其相对大小直接反映物理机制的强弱对比。由此还可得相似准则：两个几何相似的流动，只要所有相关无量纲数相同，它们的无量纲解也相同，这就是缩比实验与 CFD 外推的依据。

实施步骤固定为四步：

1. 写出目标量及其空间、时间尺度；
2. 列出控制方程中出现的力、通量与源项；
3. 选取特征长度 $L$、特征速度 $U$、特征时间 $T$、特征密度 $\rho_0$ 与特征压力 $p_0$；
4. 用统一特征量无量纲化整套方程，得到由无量纲数系数化的形式。

特征尺度的选取决定一切。内流取水力直径与截面平均速度；外流取弦长与来流速度；旋转机械取叶高与叶尖速度；自然对流更适合由温差与浮力构造尺度，而不是硬套来流速度。**混用入口速度、局部最大速度与几何总长，会让工况比较彻底失去意义**——这是尺度分析里最致命也最常见的问题。

还需要区分两件事：一是把物理量变成纯数的映射，二是把方程变成纯数系数的过程。前者写在报告里便于交流，后者才是真正暴露主导机制的步骤。很多人只做了前者就以为完成了尺度分析，结果还是不知道哪一项重要。

## 3. 关键公式与推导

以常黏度不可压缩流动为例，动量方程为

$$
\rho_0\left(\frac{\partial \mathbf{u}}{\partial t} + \mathbf{u}\cdot\nabla\mathbf{u}\right) = -\nabla p + \mu\nabla^{2}\mathbf{u} + \rho_0\mathbf{g}
$$

引入无量纲变量：

$$
\mathbf{x} = L\,\mathbf{x}^{*},\quad \mathbf{u} = U\,\mathbf{u}^{*},\quad t = T\,t^{*},\quad p = \rho_0 U^{2}\,p^{*},\quad \mathbf{g} = g\,\mathbf{g}^{*}
$$

代入并按 $\rho_0 U^{2}/L$ 归一化，得到**非量纲动量方程**

$$
St\,\frac{\partial \mathbf{u}^{*}}{\partial t^{*}} + \mathbf{u}^{*}\cdot\nabla^{*}\mathbf{u}^{*} = -\nabla^{*}p^{*} + \frac{1}{Re}\nabla^{*2}\mathbf{u}^{*} + \frac{1}{Fr^{2}}\,\mathbf{g}^{*}
$$

其中

$$
Re = \frac{\rho_0 U L}{\mu},\qquad St = \frac{L}{U T},\qquad Fr = \frac{U}{\sqrt{g L}}
$$

各项含义一目了然：$1/Re$ 是黏性扩散项的相对权重，$1/Fr^{2}$ 是浮力（重力）项的权重，$St$ 是非定常项的权重。若 $Re \gg 1$，黏性项可以忽略，方程退化为欧拉方程，湍流涡结构主导；若 $St \ll 1$，非定常项可以丢弃，用稳态求解即可；若 $Fr \gg 1$，重力项可忽略（如高速气流），反之自由面与浮力问题必须保留。

可压缩流还需检查 $Ma = U/c$，其中 $c = \sqrt{\gamma R T}$，$Ma$ 决定密度变化与激波是否重要；传热问题再补两个数：

$$
Pr = \frac{\nu}{\alpha},\qquad Pe = Re\,Pr = \frac{U L}{\alpha}
$$

$Pe$ 大意味着对流压倒导热，热边界层薄、对流离散与网格方向性成为精度瓶颈。

再对能量方程做同构的无量纲化，可得到

$$
St\,\frac{\partial \theta^{*}}{\partial t^{*}} + \mathbf{u}^{*}\cdot\nabla^{*}\theta^{*} = \frac{1}{Pe}\nabla^{*2}\theta^{*} + S^{*}
$$

其中 $\theta$ 为无量纲温度。这个式子说明：热量的对流输运与导热扩散之比正是 $Pe$，而 $Pe = Re\,Pr$ 把流动与传热串在一起——所以同一套流动尺度下，高 $Re$ 与高 $Pr$ 都会把热边界层推向“对流主导”。把动量与能量两式并排看，会发现它们共享同一批系数，这正是热流固耦合建模时必须同步选择 $Re$、$Pr$、$Pe$ 的原因。

## 4. 工程做法与参数

**从系数读出机制**。逐项比较系数：$1/Re$ 与 1 的大小关系决定能否做无粘近似；$St$ 与 1 的关系决定稳态还是瞬态；$1/Fr^{2}$ 与 1 的关系决定浮力是否可忽略。多数工程问题的判定标准就是"系数是否比 1 小一个数量级以上"。这里的“1”就是对流项的自然尺度，一切比较都以它为基准，这也是为什么无量纲化时把对流项系数归一为 1 最方便。

**浮力与自然对流**。温度差驱动的流动常用瑞利数与格拉晓夫数代替 $Re$：

$$
Ra = \frac{g\beta\Delta T L^{3}}{\nu\alpha},\qquad Gr = \frac{g\beta\Delta T L^{3}}{\nu^{2}}
$$

其中 $\beta$ 为热膨胀系数，$\Delta T$ 为特征温差。判断强迫与自然对流谁主导，用 $Ri = Gr/Re^{2}$：远大于 1 则浮力主导，远小于 1 则可忽略浮力。

**转换为可直接使用的设置**。$Re$ 决定层流还是湍流、以及壁面首层网格高度；$Ma$ 决定是否启用能量方程与激波捕捉；$St$ 与目标频率决定时间步与采样长度；$Pe$ 决定对流格式与加密区域。每个无量纲数都应能落到一个具体的求解设置上。

**保留敏感性分析**。当某个系数接近 1（机制势均力敌）时，不要武断取舍，而应保留该项并做敏感性对比，用两组计算的差异量化被保留或被忽略项的影响。

**尺度分析如何反哺网格与时间步**。得到 $Re$ 后可用壁面律估算首层网格高度以命中目标 $y^{+}$；得到 $St$ 与目标频率后可估算时间步与采样长度；得到 $Pe$ 后可在高梯度区加密。也就是说，尺度分析不是学术练习，它直接决定了三个最贵的求解参数：网格量、时间步数与迭代次数。

## 5. 可复现示例

下面用一段脚本，把一个矩形通道的流动无量纲化，算出各系数的量级，并据 $St$ 与 $Re$ 判断该用稳态还是瞬态、层流还是湍流：

```python
import numpy as np

# 特征量: 通道高 H, 主流速度 U, 采样周期 T
H, U, T = 0.10, 1.5, 0.02          # m, m/s, s
rho, mu, g = 998.2, 1.002e-3, 9.81 # SI

Re = rho * U * H / mu
St = H / (U * T)
Fr = U / np.sqrt(g * H)

print(f"Re = {Re:.3e}")
print(f"St = {St:.3f},  1/St = {1/St:.2f}")
print(f"Fr = {Fr:.3f},  1/Fr^2 = {1/Fr**2:.4f}")

# 判读
if Re > 4000:
    model = "湍流 (需湍流模型 + 壁面加密)"
else:
    model = "层流"
if St > 0.1:
    regime = "瞬态求解 (非定常项不可忽略)"
else:
    regime = "可先试稳态"
print(f"建议模型: {model}")
print(f"建议流程: {regime}")
```

步骤与判读：

1. 先确定 $H$、$U$、$T$ 的物理含义，它们是全部系数的分母；
2. $Re \approx 1.5\times10^{5}$，属湍流，应选湍流模型并把首层网格按 $y^{+}$ 反算；
3. $St \approx 3.3$，远大于 1，说明在一个采样周期内流体已对流穿过多个特征长度，非定常效应强，应走瞬态；
4. $1/Fr^{2} \approx 0.06$，重力影响不大，可先忽略浮力；
5. 把结论写成一行"模型选择声明"存档，后续任何改工况都要复核。

注意这个例子中 $St > 1$ 的含义：特征时间 $T$ 短于对流时间 $H/U$，说明在一个周期内流速变化剧烈，非定常项权重反而超过对流项。初学者常把 $St$ 小当作“快流”的判据，其实 $St$ 比较的是非定常与对流两个时间尺度，与绝对速度快慢无关。

## 6. 常见坑与排查

- **特征尺度选错或混用**：用几何总长当特征长度、又用局部最大速度算 $U$，得到的无量纲数没有可比性；
- **只算孤立经验数**：不经无量纲化直接背 $Re$ 阈值，忽略了几何与扰动对临界值的强烈影响；
- **在临界范围武断取舍**：系数接近 1 时仍一刀切忽略某效应，结果偏差无法评估；
- **忽略变物性**：温差大时 $\mu$、$\rho$ 随温度变化，常物性假设下的系数会失真；
- **稳态求解本质非定常流动**：$St$ 并不小时仍求稳态，只会得到一个被数值耗散抹平的"伪定常"场；
- **把结果量当作定性参数**：$Nu$、$C_d$ 是求解输出，不能预先“设定”去反推模型；
- **忽略局部尺度**：全域平均 $Re$ 很小不代表局部不湍流，喉部、间隙与近壁区的局部 $Re$、$Ma$ 往往才是关键；
- **浮力源项遗漏**：$Ri$ 接近 1 时若漏掉浮力项，流速与换热会被系统性低估。

还要警惕一种“看起来对”的假象：无量纲数都在预期范围内，但方程里却漏了浮力、旋转科氏力或非定常项。这类错误的共同特征是残差收敛得很漂亮，目标量却与手算明显偏离。因此尺度分析结束后，应回头逐项核对微分方程，确认每个重要机制都有对应的项与源。

排查顺序：先复核特征尺度定义与量纲 → 再逐个核对系数大小 → 最后才决定模型升级与否。
