# CFD 常用无量纲数与尺度判断

无量纲数把几何、物性和运行条件压缩成可比较的尺度比，是选择模型、设计网格和寻找实验基准的第一层依据。它们不是装饰性的经验参数，而是决定"哪一项在方程中主导"的硬指标。关键不在于背诵阈值，而在于选择与问题相符的特征速度和特征长度，并让报告里的定义保持自洽。同一台设备，换一个特征长度就可能把结论从“层流”翻成“湍流”，因此无量纲数背后真正重要的是“你把什么当作尺度”。

## 1. 结论与适用场景

一句话结论：**先算无量纲数，再决定用不用可压缩、要不要能量方程、走层流还是湍流、网格和时间步怎么定。** 具体对应关系是：

- 雷诺数 $Re$ 定层流、转捩与湍流，直接决定湍流模型与壁面网格需求；
- 马赫数 $Ma$ 定可压缩性，是判断能否用不可压近似的第一把尺；
- 欧拉数 $Eu$ 把压差写成动压的倍数，用于压降估算与结果核对；
- 普朗特数 $Pr$ 由物性决定，衡量动量扩散与热扩散的相对强弱；
- 努塞尔数 $Nu$ 是换热的无量纲结果量，用于与关联式对比；
- 佩克莱数 $Pe$ 比较对流与扩散，决定离散格式的有界性与网格方向性要求。

只要问题涉及内流、外流、传热、旋转或浮力，无量纲数都是开题与验收的共同语言。它们还能把不同尺度的设备放到同一张图上比较：只要几何相似且 $Re$、$Ma$、$Pr$ 相同，小模型的结果就能外推到实物。例外情形是分子平均自由程与特征长度同量级（$Kn$ 不可忽略）的稀薄气体，此时连续介质框架本身就不再成立，需要动理学或 DSMC 方法。

## 2. 物理与数学基础

无量纲化来自**量纲齐次原理**：物理方程中各项量纲必须相同，因此用特征量去除后，各项的系数必然是若干无量纲数的组合。换句话说，无量纲数就是"某两种效应的量级之比"。

以动量方程为例，惯性项的量级是 $\rho U^{2}/L$，黏性项是 $\mu U/L^{2}$，二者之比正是 $Re$；惯性项与压力梯度项之比给出 $Eu$；惯性项与非定常项之比给出斯特劳哈尔数 $St$；惯性项与浮力项之比给出弗劳德数 $Fr$ 与理查森数 $Ri$。这样，一个复杂的流动就被少数几个无量纲数完全刻画——同 $Re$、同 $Ma$ 的两个流动相似，这正是缩比实验与 CFD 外推的理论基础。

需要牢记区分：$Re$、$Ma$、$Pr$、$Fr$ 属于**定性参数**，由几何、物性与工况决定，计算前就能算出；而 $Nu$、$Eu$、阻力系数 $C_d$ 属于**结果量**，是求解或实验得到的输出，用它们才能做验证。把两者混用在报告里，是初学者最典型的错误之一。无量纲数属于“先导判断”，它只能指方向，不能替代守恒校验与目标量对比。

相似原理还有一个实用推论：**不可能同时匹配所有无量纲数**。缩比实验或简化仿真时，应优先匹配控制主要物理机制的那一个或几个数，并明确哪些效应被牺牲，再用敏感性分析估计牺牲带来的偏差。例如缩比水箱若不能同时匹配 $Re$ 与 $Fr$，就要根据关注的是黏性主导还是重力主导来取舍。

## 3. 关键公式与推导

常用无量纲数定义如下：

$$
Re = \frac{\rho U L}{\mu} = \frac{U L}{\nu}
$$

$$
Eu = \frac{\Delta p}{\rho U^{2}}
$$

$$
Ma = \frac{U}{c}, \qquad c = \sqrt{\gamma R T}
$$

$$
Pr = \frac{\nu}{\alpha} = \frac{\mu c_p}{k}, \qquad \alpha = \frac{k}{\rho c_p}
$$

$$
Nu = \frac{h L}{k}
$$

$$
Pe = Re\,Pr = \frac{U L}{\alpha}
$$

其中 $U$、$L$ 为特征速度与特征长度，$\rho$、$\mu$、$\nu$ 为密度与动力、运动黏度，$c$ 为声速，$\gamma$ 为比热比，$\Delta p$ 为特征压差，$c_p$、$k$、$\alpha$ 为比热、导热系数与热扩散率，$h$ 为对流换热系数。每个数的分子与分母都对应一对竞争的物理效应：$Re$ 是惯性比黏性，$Eu$ 是压力比惯性，$Ma$ 是流速比声速，$Pr$ 是动量扩散比热扩散，$Nu$ 是对流换热比纯导热，$Pe$ 是对流比热扩散。养成“读分母”的习惯，就能一眼看出参数变化会强化哪种效应。

几个关系值得记住：$Pe = Re\,Pr$ 把流动与传热联系起来；强制对流换热的经典关联式 $Nu = 0.023\,Re^{0.8}Pr^{0.4}$（Dittus–Boelter，适用于充分发展湍流管内流）说明 $Nu$ 由 $Re$ 与 $Pr$ 共同决定；非定常问题还有

$$
St = \frac{f L}{U}, \qquad Gr = \frac{g\beta\Delta T L^{3}}{\nu^{2}}, \qquad Ri = \frac{Gr}{Re^{2}}
$$

$St$ 描述涡脱落或旋转的周期性，$Gr$ 衡量浮力与黏性，$Ri$ 判断强迫对流与自然对流谁主导。

逐项理解这些定义，就能把方程里的系数翻译成物理：$1/Re$ 是黏性项前的系数，越大越像“慢速黏性主导”；$1/Ma^{2}$ 出现在可压缩动量的压力项前；$1/Pe$ 是能量方程中导热项的系数；$Nu$ 则是把壁面温度梯度无量纲化后的换热强弱。理解了这层对应，就不会把无量纲数当作孤立公式去背。

## 4. 工程做法与参数

**特征尺度的选择**。这是最容易出错也最关键的一步。圆管内流取截面平均速度与直径；非圆通道取水力直径 $D_h = 4A/P$（$A$ 为截面积，$P$ 为湿周）；外流取来流速度与弦长或直径；旋转机械取叶尖速度与叶高或弦长；自然对流更适合用温差构造 $Ra$ 与 $Gr$ 而不是硬套 $Re$。报告中必须显式写出 $U$ 与 $L$ 的定义，否则不同计算之间的 $Re$ 根本不可比。

**典型阈值**。圆管层流到湍流的临界 $Re$ 约为 2300，但受入口扰动与几何影响很大；外流边界层转捩常在 $Re_x \approx 5\times10^{5}$ 量级；$Ma \leq 0.3$ 时密度变化小于约 5%，可按不可压处理；$Ma>1$ 必出现激波，必须用可压缩求解；空气 $Pr \approx 0.71$，水约 $7$，液态金属远小于 $1$，$Pr$ 决定热边界层与速度边界层的相对厚度。

**模型筛选准则**。$Re$ 决定用层流、RANS 还是 LES；$Ma$ 决定是否启用能量方程与激波捕捉；$Pe$ 很大时对流离散与网格方向性更重要，一阶格式的数值耗散会显著污染结果；$Ri$ 接近或大于 1 时必须把浮力源项写进动量方程。还有一个常被忽略的尺度：克努森数 $Kn = \lambda/L$（$\lambda$ 为分子平均自由程）；$Kn < 0.01$ 时连续介质与无滑移假设成立，$Kn$ 较大时需引入滑移边界甚至动理学方法。

**把数变成动作**。定模型只是第一步，还要把无量纲数转成具体设置：根据 $Re$ 与 $y^{+}$ 目标反算首层网格高度，根据 $Ma$ 决定是否开启能量方程与激波敏化，根据 $St$ 与目标频率决定采样时长，根据 $Pe$ 决定对流格式与局部加密区域。每个无量纲数都应能对应到某个具体的求解设置，否则它就只是纸面上的数字。具体到网格：$Re$ 越高，壁面速度梯度越陡，首层网格高度必须按 $y^{+}$ 目标反算；$Ma$ 越过 1 后要在激波附近加密以捕捉间断；大 $Pe$ 的传热问题则要求沿流向与法向同时加密。

## 5. 可复现示例

下面用一段脚本，对一根水管的入口段同时算出 $Re$、$Pr$、$Pe$、$Eu$ 与 $Nu$，并据关联式反推换热系数 $h$：

```python
import numpy as np

# 工况与物性: 水 20C, 圆管
rho, mu, cp, k = 998.2, 1.002e-3, 4182.0, 0.598   # SI
D, U = 0.05, 2.0                                   # 直径 m, 平均速度 m/s
dp = 3500.0                                        # 特征压差 Pa

nu = mu / rho
alpha = k / (rho * cp)
Re = rho * U * D / mu
Pr = nu / alpha
Pe = Re * Pr
Eu = dp / (rho * U**2)

# 充分发展湍流管内流关联式
Nu = 0.023 * Re**0.8 * Pr**0.4
h = Nu * k / D

print(f"Re = {Re:.3e},  Pr = {Pr:.2f},  Pe = {Pe:.3e}")
print(f"Eu = {Eu:.3f},  Nu = {Nu:.1f},  h = {h:.1f} W/(m^2 K)")
```

步骤与判读：

1. 先由物性算出 $\nu$ 与 $\alpha$，它们是 $Re$、$Pr$、$Pe$ 的共同基础；
2. $Re$ 落在 $10^{4}$ 量级、远超 2300，说明是湍流，应选湍流模型并把首层网格做到壁面解析或配壁函数；
3. $Pr$ 只由物性决定，与工况无关，可用来核对物性是否合理（水约 7）；
4. $Eu$ 把 $3500\ \mathrm{Pa}$ 的压差折算成动压的倍数，可与 Darcy–Weisbach 估算互相印证；
5. $Nu$ 与 $h$ 是结果量，用于和实测换热数据对比，是验证计算最直接的抓手。

把这段算稿存进项目记录，任何一次改工况或改物性后重算，就能立刻发现参数是否越界。建议把 $Re$、$Ma$、$Pr$、$Pe$ 四个数作为“开题四件套”固定输出，一旦其中某个数超出了模型假设的适用范围（比如 $Ma$ 接近 0.3 或 $Re$ 接近转捩区），就回到第一步重新选模型，而不是硬着头皮往下算。

## 6. 常见坑与排查

- **特征量混用**：入口速度、局部最大速度和几何总长混着用，会让工况比较彻底失去意义；
- **只看平均值**：局部 $Re$、$Ma$ 可能远高于入口名义值，壁面附近、喉部与激波后的极值往往才是决定网格与模型的量；
- **忽略变物性**：温差大或接近相变时 $\mu$、$k$、$c_p$ 随温度变化，用常物性算出的 $Re$、$Pr$ 会系统性偏离；
- **临界值当铁律**：层流到湍流的临界 $Re$ 强烈依赖几何与来流扰动，不能机械套用；
- **结果量与定性参数混淆**：$Nu$、$Eu$ 是输出，不能当输入去"设定"；
- **物性单位不一致**：把 mPa·s 当 Pa·s 会让 $Re$ 差三个数量级，这是最常见的低级错误。

还有一个容易被忽视的陷阱：**用错温度取物性**。管内流动的物性通常取主流平均温度，壁面附近的黏度差异会改变阻力与换热，若温度跨度大，最好用变物性或至少用膜温修正。排查顺序：先固定 $U$ 与 $L$ 的定义并统一单位 → 再核对 $Re$、$Ma$ 的量级 → 最后才讨论模型是否需要升级。
