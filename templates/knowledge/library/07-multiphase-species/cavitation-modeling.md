# 空化模型、汽蚀判据与结果判读

空化发生在局部压力接近液体饱和蒸气压时，但气泡形成与塌陷还受成核、溶解气体、湍流脉动与非定常压力影响。常用质量传递空化模型只是这些过程的工程近似，因此结果判读必须区分"气相分布"与"材料损伤"两件事，否则容易把蒸气云误当作已发生汽蚀。

## 1. 结论与适用场景

- **适合**：泵、螺旋桨、水翼、喷油嘴、阀门与涡轮机械中可能出现低压汽化的场景。
- **判据**：用空化数 $\sigma$ 判断空化发生倾向；当局部绝对压力降到饱和蒸气压附近且停留时间足够，才可能形成可见蒸气。
- **注意**：蒸气体积分数高不等于汽蚀损伤严重；损伤还取决于塌陷位置、压力脉冲、持续时间和材料特性。

同时要区分"空化（cavitation）"与"汽蚀（cavitation erosion）"：前者是物理相变现象，后者是气泡塌陷冲击导致的材料损伤。CFD 直接给出的是前者，后者需要结合压力脉冲与材料响应进一步评估。

## 2. 物理与数学基础

空化是多相相变问题，蒸气体积分数 $\alpha_v$ 与液体分数满足

$$
\alpha_l + \alpha_v = 1
$$

混合物密度为

$$
\rho = \alpha_l \rho_l + \alpha_v \rho_v
$$

气泡动力学由 Rayleigh–Plesset 方程描述，忽略黏性与表面张力时为

$$
R \frac{d^{2} R}{dt^{2}} + \frac{3}{2}\left(\frac{dR}{dt}\right)^{2} = \frac{p_v - p}{\rho_l}
$$

多数工程空化模型由此简化出蒸发与凝结的质量源项，因而需要气泡半径、成核体积分数或经验系数。源项把亚格子气泡动力学折算到宏观相分数变化上，这一步的近似程度决定模型的适用边界。

按形态，空化可分为游移空化、固定空化、片状空化与云空化；其中云空化伴随气泡群的非定常脱落，是扬程下降、噪声与汽蚀损伤的主要来源。工程模型通常只能捕捉其时间平均行为，云空化细节对网格与时间步极为敏感。

## 3. 关键方程与公式

空化数衡量空化倾向：

$$
\sigma = \frac{p_{ref} - p_v}{\frac{1}{2} \rho U^{2}}
$$

其中 $p_{ref}$ 为参考压力，$p_v$ 为饱和蒸气压，$U$ 为特征速度。$p_v$ 必须对应局部或指定温度，并使用绝对压力。空化初生还可用压力系数判断：

$$
C_{p,min} = \frac{p_{min} - p_{ref}}{\frac{1}{2}\rho U^{2}}, \qquad \sigma_i = -C_{p,min}
$$

当运行空化数低于初生空化数 $\sigma_i$ 时，空化开始出现。蒸气体积分数与气泡数目密度 $n$、半径 $R$ 相关：

$$
\alpha_v = \frac{n \frac{4}{3}\pi R^{3}}{1 + n \frac{4}{3}\pi R^{3}}
$$

以 Schnerr–Sauer 类模型为例，当 $p < p_v$ 时的质量传递源项形如

$$
\dot{m} = C \frac{3 \alpha_v (1 - \alpha_v) \rho_v \rho_l}{R \rho_m} \sqrt{\frac{2}{3}\frac{p_v - p}{\rho_l}}
$$

其中 $C$ 为经验系数，通常是主要不确定度来源。

## 4. 工程做法与参数

1. **压力基准**：统一绝对压力，蒸气压随温度更新，避免表压混用。
2. **成核与系数**：气泡半径、成核体积分数、蒸发与凝结系数须按实验或公开基准校准，不能默认接受。
3. **数值要求**：空化与压力-速度强耦合，需要瞬态计算、小时间步，并细化低压区、剪切层与尾迹。
4. **耗散控制**：过度数值耗散会抑制蒸气云脱落，粗网格会改变最低压力；应使用低耗散格式。
5. **湍流耦合**：湍流压力脉动影响局部压力，须与湍流模型一致，必要时考虑压力脉动修正。
6. **收敛与统计**：瞬态结果需在多个脱落周期后统计蒸气云长度、频率与压力谱。
7. **初生校核**：用无空化计算得到的 $C_{p,min}$ 估算初生空化数，与实验对照后再设定工作点。

## 5. 可复现示例

下面用 Python 在一组工况下计算空化数并给出倾向判断。

```python
def cavitation_number(p_ref, p_v, rho, U):
    return (p_ref - p_v) / (0.5 * rho * U * U)

rho, p_v = 998.0, 2340.0   # 水, 20 摄氏度饱和蒸气压 Pa
cases = [
    (200000.0, 15.0),   # 高压高流速
    (80000.0, 25.0),    # 低压高流速 -> 易空化
    (150000.0, 8.0),
]
for p_ref, U in cases:
    s = cavitation_number(p_ref, p_v, rho, U)
    risk = "高风险" if s < 1.5 else ("中风险" if s < 3.0 else "低风险")
    print("p_ref=%7.0f Pa U=%4.1f m/s sigma=%.2f -> %s"
          % (p_ref, U, s, risk))
```

注意：$\sigma$ 只是发生倾向的指标，真实蒸气区还需瞬态求解器与足够细的网格确认，二者不可互相替代。

## 6. 常见坑与排查

- **表压与绝对压力混用**：$\sigma$ 与相变判定直接错误。
- **蒸气压不随温度更新**：热工况下误差很大。
- **粗网格**：最低压力被抹平，蒸气云虚假。
- **过度耗散**：蒸气云不脱落，非定常频率丢失。
- **把蒸气分数当损伤**：误判汽蚀风险；应比较压力脉冲与实验侵蚀区。
- **默认系数未校准**：不同系数可给出数量级不同的蒸气体积。
- **忽略湍流压力脉动**：仅用平均压力判定会低估空化初生。
- **分辨率不足导致频率失真**：网格过粗时脱落频率与实验偏离，不能用于噪声评估。

- [ ] 网格是否细化低压区与剪切层，格式是否低耗散？
