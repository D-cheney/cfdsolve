# 组分输运、扩散与反应源项建模

组分输运在动量、能量之外增加了质量分数场与化学源项。工程中最常见的错误不是求解器问题，而是入口基准、物性数据与反应机理三者不一致，导致组分或元素在求解域内"凭空"产生或消失。因此守恒检查应被当作一等公民，而不是事后补充。

## 1. 结论与适用场景

- **适合**：涉及多组分混合、稀释扩散、燃烧、催化反应、污染物迁移与传质的问题。
- **关键前提**：各组分质量分数之和必须为 1，每个入口基准与物性、机理保持一致。
- **判据**：混合强度可用 Péclet 数刻画；反应快慢用 Damköhler 数比较化学时间与流动时间；湍流混合由湍流 Schmidt 数控制。

需要强调的是，组分输运常与多相、燃烧、传热耦合出现：喷雾蒸发会同时改变组分、温度与相分数，因此单一物理的验证不足以支撑整机结论，必须做耦合基准测试。

## 2. 物理与数学基础

对每个组分求解质量分数 $Y_i$ 的对流-扩散方程：

$$
\frac{\partial (\rho Y_i)}{\partial t} + \nabla \cdot (\rho \mathbf{u} Y_i) = \nabla \cdot (\rho D_{i,eff} \nabla Y_i) + R_i
$$

其中 $R_i$ 为化学反应生成或消耗速率，$D_{i,eff}$ 为有效扩散系数。所有组分满足归一化约束：

$$
\sum_{i=1}^{N} Y_i = 1, \qquad 0 \leq Y_i \leq 1
$$

软件通常只求解 $N-1$ 个组分，最后一个由总和得到，因此该组分的守恒依赖其余组分的准确度。选择哪个组分作为"由总和确定"的组分，会直接影响其局部质量误差。

对于非预混燃烧，常引入不含源项的守恒标量——混合分数 $f$，其输运只受对流与扩散控制：

$$
\frac{\partial (\rho f)}{\partial t} + \nabla \cdot (\rho \mathbf{u} f) = \nabla \cdot (\rho D_f \nabla f)
$$

由于 $f$ 无化学源项，它比组分场更稳定，常用来构造状态关系、检验混合模型并诊断网格分辨率。

## 3. 关键方程与公式

有效扩散由分子扩散与湍流扩散叠加：

$$
D_{i,eff} = D_{i,m} + \frac{\mu_t}{\rho Sc_t}
$$

其中 $Sc_t$ 为湍流 Schmidt 数，典型取 0.7 左右，对混合长度与峰值浓度有直接影响。稀混合物可用 Fick 定律，复杂混合物宜用多组分扩散、热扩散或压力扩散。

反应与混合的相对快慢用 Damköhler 数衡量，流动与扩散的相对强弱用 Péclet 数衡量：

$$
Pe = \frac{U L}{D}, \qquad Da = \frac{\tau_{flow}}{\tau_{chem}}
$$

$Da \gg 1$ 时反应受混合控制，$Da \ll 1$ 时受化学动力学控制，两者的建模策略与网格要求完全不同。

反应速率常用 Arrhenius 形式：

$$
k = A T^{b} \exp\left(-\frac{E_a}{R T}\right)
$$

其中 $A$ 为指前因子，$E_a$ 为活化能，$b$ 为温度指数。放热或吸热反应必须与能量方程耦合，生成焓、比热与温度依赖速率应使用同一套热力学数据，否则会出现能量与质量不一致。

## 4. 工程做法与参数

1. **基准一致**：入口组分与温度对应同一工况；质量分数与摩尔分数换算需显式记录；惰性组分与载气定义清楚。
2. **扩散模型**：按混合物复杂度选择 Fick、多组分、热扩散或压力扩散；湍流扩散交给 $Sc_t$ 控制。
3. **反应求解**：有限速率反应源项常高度刚性，需合适的时间步与化学求解策略（如算子分裂或隐式刚性积分）。
4. **边界**：出口回流也需给定组分；避免在开放边界直接施加组分梯度造成非物理通量。
5. **初始化**：初始场与入口差异过大将产生强瞬态或非物理反应峰；反应流宜先算冷态流场再点火。
6. **网格与时间步**：反应区、剪切层与火焰面需加密；时间步受化学反应时间尺度限制。
7. **收敛判据**：组分方程的残差与守恒量应同时收敛；仅看全局流量平衡容易掩盖局部组分误差。

## 5. 可复现示例

下面用 Python 计算 Arrhenius 速率常数并检查不同温度下的量级，同时演示组分归一化检查。

```python
import math

# Arrhenius: k = A * T^b * exp(-Ea / (R * T))
A, b, Ea, R = 1.0e10, 0.5, 8.0e4, 8.314

def arrhenius(T):
    return A * T**b * math.exp(-Ea / (R * T))

for T in (600.0, 900.0, 1200.0):
    print("T=%6.0f K  k=%.3e" % (T, arrhenius(T)))

# 组分归一化检查
Y = {"CH4": 0.10, "O2": 0.22, "N2": 0.68}
s = sum(Y.values())
print("sum Yi = %.4f" % s)
Y["N2"] += 1.0 - s          # 用惰性组分吸收残差
print("修正后 sum Yi = %.4f" % sum(Y.values()))
```

运行后可见速率随温度急剧上升，以及如何用惰性组分吸收归一化残差。工程中应把该检查固化为每次后处理的必做项。

## 6. 常见坑与排查

- **组分不守恒**：入口基准或物性不一致，或用摩尔分数冒充质量分数。
- **元素不守恒**：机理中元素配平错误，或源项符号反了。
- **质量分数越界**：刚性源项或过大时间步产生负值或超过 1。
- **峰值浓度偏差**：$Sc_t$ 取值不当或网格过粗。
- **温度-速率不一致**：速率与热力学用了不同来源的数据。
- **回流未设组分**：出口回流带入默认值，污染内部解。
- **混合分数与组分混用**：$f$ 无源项而 $Y_i$ 有源项，二者不可互相替换。
- **只查总质量不看元素**：总质量守恒但元素配平错误时，反应结果仍可能全错。
