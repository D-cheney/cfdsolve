# 共轭传热、薄壁与接触热阻建模

当壁面温度未知、固体内部导热对结果有影响时，把流体与固体放在同一个框架里同时求解，就是共轭传热（CHT）。它省去了猜壁温的循环，但把**界面条件、薄壁近似和接触热阻**这三件事推到了问题的中心。

## 1. 结论与适用场景

共轭传热适合以下情形：

- 壁温由两侧换热共同决定，无法事先给定，例如换热器管壁、电子芯片与散热器、涡轮叶片；
- 固体内部存在明显的纵向或横向温度梯度，等温壁假设会带来显著误差；
- 存在多个固体部件与空隙，热流经过多层材料逐级传递；
- 需要给出器件结温、外壳温度或结构热应力这类以固体侧为目标的结果。

典型不适用的场景也要说清：固体热导率极高、厚度极小、在感兴趣方向上温度近乎均匀时，用等温壁或对流边界更省算力；流体域与固体域时间尺度相差几个数量级而只关心稳态时，不必强行做全瞬态耦合。判断的核心是**毕渥数**：

$$
Bi = \frac{h L_c}{k_s}
$$

$Bi<0.1$ 时固体内部温度梯度可忽略，用集中参数或等温壁即可；$Bi\gg 1$ 时内部导热主导，必须显式建模固体域。

共轭传热的收益是消除了"猜壁温—算流体—再猜"的外循环，代价是流体与固体的时间尺度、网格尺度差异被同时带进求解器，收敛与内存成本上升。因此工程上常先用手算热阻网络把量级算清，再用 CFD 确定温度分布与热点位置，两者互为校验。

## 2. 物理与数学基础

共轭传热由两套方程在界面上耦合而成。固体侧是纯导热方程（无对流）：

$$
\rho_s c_s \frac{\partial T_s}{\partial t} = \nabla\cdot(k_s\nabla T_s) + q_v
$$

流体侧则是带对流的能量方程。界面上的耦合条件有两条：

1. **温度连续**：$T_f = T_s$，界面两侧取同一温度；
2. **热流连续（守恒）**：法向热流相等，$-k_f\,\partial T_f/\partial n = -k_s\,\partial T_s/\partial n$。

理想接触就是这两条。现实中界面往往存在涂层、氧化层或微观空隙，导致温度在界面上出现跳跃。这时用一个**接触热阻** $R''_{tc}$ 把温度间断与热流联系起来：

$$
q'' = \frac{T_{s,1} - T_{s,2}}{R''_{tc}}
$$

接触热阻源于表面粗糙度造成的真实接触面积不足。它与压力、粗糙度、界面材料和间隙介质都相关：真空中靠微凸体导热，间隙中若有机油或导热脂则显著改善。$R''_{tc}$ 的单位是 $\mathrm{m^2\cdot K/W}$。

要注意界面条件的两条（温度连续、热流守恒）是**理想接触**的极限。一旦把接触热阻、辐射、黏性耗散或相变引入，界面就变成带源或带阻的环节，需要额外的关系式。固体通常对辐射不透明，因此辐射只在流体侧或表面之间起作用，但半透明介质（玻璃、熔融盐）会在固体内部参与辐射，此时固体导热方程也要加上辐射源项。

当把流固界面当作良好导热时，区域的数量与拓扑也很关键：多个固体域串联时，热流会依次穿过各层；存在间隙或空腔时，若不做网格填充而是留空，就必须显式给定该空腔的接触热阻或等效导热，否则热量会被"隔断"。

## 3. 关键公式与推导

**薄壁的一维导热。** 当固体厚度 $t$ 远小于其他特征尺度、且向导热在该方向占主导时，可把薄壁当作一维导热层：

$$
q'' = \frac{k_s}{t}\,(T_{s,1} - T_{s,2}),\qquad R''_{wall} = \frac{t}{k_s}
$$

薄壁模型把它作为一个面条件施加，不额外划分固体网格，但必须输入**真实厚度** $t$、正确方向的导热系数 $k_s$ 与面朝向。

**串联热阻网络。** 多层或复合结构的总热阻是各段串联之和。设面积为 $A$，常用三种热阻：

$$
R_{cond} = \frac{t}{k A},\qquad R_{conv} = \frac{1}{h A},\qquad R_{tc} = \frac{R''_{tc}}{A}
$$

总热阻 $R_{tot}=\sum R_i$，总换热功率与总温差由欧姆定律式给出：

$$
Q = \frac{\Delta T_{tot}}{R_{tot}}
$$

**共轭交换的等价写法。** 把界面热流写成两侧温差除以热阻，就能在流体与固体之间建立"等效对流"：

$$
q'' = h_{eff}\,(T_{fluid} - T_{solid}),\qquad h_{eff} = \left(\frac{1}{h} + R''_{wall} + R''_{tc}\right)^{-1}
$$

它把对流、薄壁与接触热阻三类阻抗串成一条链，是快速估算结温最实用的公式。

**总传热系数。** 当一面壁两侧都是流体时，把两侧对流也串起来，得到以面积为基准的总传热系数 $U$：

$$
\frac{1}{U A} = \frac{1}{h_1 A} + \frac{t_w}{k_w A} + \frac{R''_{tc}}{A} + \frac{1}{h_2 A}
$$

$U$ 的倒数就是单位面积总热阻，它是换热器设计的核心参数。把 $U$ 与传热面积、温差相乘即得换热量 $Q=UA\,\Delta T_{lm}$，其中 $\Delta T_{lm}$ 为对数平均温差。

## 4. 工程做法与参数

**建显式固体域还是薄壁。** 厚实体、内部温度梯度重要或需要输出固体应力时建固体域；厚度远小于其他尺度、法向温变可近似线性时用薄壁。切记不要把薄壁厚度重复建入几何——几何与薄壁参数二选一，否则厚度被算两遍。

**接触热阻取值。** 工程常用量级：金属—金属干接触约 $10^{-4}\sim10^{-3}\ \mathrm{m^2\cdot K/W}$；涂导热脂约 $10^{-5}\sim10^{-4}$；焊料或直接键合约 $10^{-6}$ 量级。数值随压力与表面粗糙度变化，关键结构应实测或查手册给出区间并做敏感性分析，而不是随手取零。

**固体网格。** 按 $Bi$ 与预期梯度在厚度方向布置至少 5～10 层单元；金属内部虽温度梯度小，但为分辨界面附近剧变仍需加密首层。非共形接口必须验证插值后总热量守恒，接口两侧热流的面积积分之差应低于项目容差。

**材料物性。** 金属导热系数随温度变化、复合材料各向异性、界面涂层都会改变热点位置与路径。各向异性材料的导热主轴必须与坐标对齐，否则热流方向会错。

**共形与非共形网格。** 共形接口两侧网格节点对齐，热流守恒天然成立；非共形接口靠插值传递温度与热流，必须显式检查两侧热流积分是否相等。含薄壁、涂层或多层贴合的复杂结构建议在接口处做局部加密或使用界面层单元。

**稳态与瞬态。** 只关心工作点温度时用稳态 CHT，但强热源、预热、启停过程必须瞬态。瞬态还要注意流体时间步与固体热惯性不匹配的问题，必要时用双时间步或子循环。

**时间尺度与耦合。** 固体热惯性常远大于流体对流时间尺度，其特征时间约为

$$
\tau_s = \frac{\rho_s c_s L^2}{k_s}
$$

瞬态 CHT 的物理时间必须覆盖 $\tau_s$，否则固体温度尚未响应。强耦合或强源项问题可先冻结界面温度，再逐步放开耦合与热源。

## 5. 可复现示例：芯片结温的热阻网络估算

问题：某芯片经导热界面材料（TIM）贴到金属基座，再经散热器向空气散热。已知面积 $A=0.001\ \mathrm{m^2}$、功耗 $Q=5\ \mathrm{W}$、环境温度 $T_{amb}=298.15\ \mathrm{K}$。估算结温 $T_j$，并给出 CFD 中对应要建的固体域与界面。

```python
A = 0.001          # 传热面积 m^2
Q = 5.0            # 功耗 W
Tamb = 298.15      # 环境温度 K
h_air = 50.0       # 散热器到空气的对流，W/(m^2*K)
t_tim = 1e-4       # TIM 厚度 m
k_tim = 3.0        # TIM 导热系数 W/(m*K)
Rtc = 1e-4         # 接触热阻 m^2*K/W（两处界面）

R_conv = 1.0 / (h_air * A)        # 对流热阻
R_tim = t_tim / (k_tim * A)       # TIM 导热热阻
R_contact = 2.0 * Rtc / A         # 两处接触热阻
R_tot = R_conv + R_tim + R_contact
dT = Q * R_tot
Tj = Tamb + dT
print("R_tot =", R_tot, "dT =", dT, "Tj =", Tj)
```

先用手算得到 $R_{tot}$、温差 $\Delta T$ 与结温 $T_j$，再搭建 CFD 模型：流体域为空气中的散热器与周围环境，固体域为基座与散热器实体、TIM 用薄壁或薄层表达并施加 $R''_{tc}$。检查接口两侧分别积分的法向热流差值、固体储能变化与对流散热总量是否闭合到 1% 以内，并与手算 $\Delta T$ 对比。若 CFD 结温明显低于手算，最常见原因就是接触热阻被忽略或薄壁厚度重复计入。为便于与手算对照，可先做一个二维或轴对称简化模型：热源给定热流，散热器外表面给对流边界，先不算真实散热器翅片，只保留等效散热面积。确认总热阻与手算一致后，再逐步加入真实几何、辐射与温度依赖物性。

## 6. 常见坑与排查

- **薄壁厚度重复建入几何**：几何厚度与薄壁参数叠加，热阻被算两遍，壁温偏低；
- **忽略接触热阻**：低估结温，器件寿命评估过于乐观；
- **非共形接口插值不守恒**：界面热流出现"凭空多出"或"漏掉"的能量；
- **固体网格过粗**：界面附近梯度没分辨，热点位置偏移；
- **各向异性方向错**：导热主轴与几何错位，热流走向错误；
- **瞬态时间不够**：只跑了几个流体时间步，固体还没热起来；
- **初期耦合过猛**：强非线性界面一次全开导致发散；
- **用流体网格尺度要求固体**：强行统一 界面两侧的 $y^+$ 导致固体网格异常；
- **半透明固体忽略内部辐射**：玻璃、晶体等材料内部温度分布失真；
- **只报最高温度不报热流路径**：无法定位热点器件与热阻瓶颈。

排查顺序：先核对热阻网络与界面条件（是否连续、是否守恒），再查网格分辨与材料方向，最后再动松弛和耦合步长。
