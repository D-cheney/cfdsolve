# CFD 入口边界、剖面与湍流量设置

入口应给出实际可测、或由上游系统确定的变量，而不是同时指定彼此依赖的全部状态。入口类型还必须与出口条件、流动可压缩性以及湍流模型相容。本文从类型选择讲到剖面构造与湍流量换算，并给出可复现的设置流程。

## 1 结论与适用场景

核心结论：

- 入口只应规定**独立且可测**的量：速度或质量流量（运动学）、总温总压或静压（热力学）、湍流量。不要同时固定速度与压差，那会过度约束问题。
- 已知泵送流量时用质量流量入口；已知截面速度或来流速度时用速度入口；可压缩设备进口常用总压、总温与流向描述。
- 入口距上游扰动较近时，均匀剖面会引起虚假的初始发展过程，需要导入或构造充分发展剖面。
- 湍流强度、长度尺度、$k$、$\varepsilon$、$\omega$ 必须相互一致，不能各写一个来源。
- 所有入口量都要做**面积积分核对**：指定流量是否等于实际通量，方向是否符合面法向。

适用场景覆盖内流（管道、阀门、换热器）与外流（风洞、绕流、进气口）。对转捩、射流与短入口段问题，湍流量输入的不确定性会直接影响结果，必须做敏感性分析；反之，对充分发展、湍流已饱和的内流，入口湍流量影响可能很小。

## 2 背景与原理

边界条件的作用是把外部世界的信息传入计算域。入口的特征线指向域内，因此必须规定与指向域内的特征线数量相等的独立条件。对不可压缩流，这与质量守恒等价于"规定一个流量或速度尺度 + 一个压力水平由出口确定"。若在入口同时规定速度和质量流量，就重复约束了同一个自由度，求解器只能忽略其一，导致边界处通量不守恒。

对流场结构而言，均匀入口意味着"上游没有记忆"。当入口离几何扰动（弯头、阀、叶轮）很近时，真实来流带有非均匀剖面与湍流结构，均匀假设会让边界层从头开始重新发展，下游目标量因此偏差。此时应把上游剖面（实验、上游 CFD 或充分发展解析关系）映射到入口面。反之，若入口足够远、来流已充分发展，均匀甚至稍粗的入口往往也不影响所关注的下游目标量。

湍流量的输入决定了初始的湍流强度与尺度。$k$ 表示湍动能，$\varepsilon$ 与 $\omega$ 分别表示其耗散率与比耗散率，它们由流动强度与含能涡尺度共同决定，不能独立指定。至于入口湍流究竟是“干净来流”还是“已饱和”，会直接影响边界层转捩位置与分离尺度，因此选择 $I$ 与 $l$ 时必须结合风洞实测或上游仿真的真实背景湍流，而不是随手取一个“看着舒服”的数。

另一个容易混淆的点是温度与组分的入口处理。它们同样是特征线条件：不可压缩热问题中，入口温度剖面会向下游平流并在壁面处重新分布；如果入口温度均匀而实际存在热边界层，下游换热会被低估。

## 3 关键公式与判据

质量流量入口的核心是面积积分：

$$
\dot{m} = \int_A \rho \, \vec{u} \cdot \vec{n} \, dA
$$

对均匀不可压缩来流可简化为 $\dot{m} = \rho U A$。设置后必须核对积分值是否等于目标流量，并检查 $\vec{u} \cdot \vec{n}$ 的符号：负号意味着该面在局部是流出而非流入。

湍流强度定义为脉动均方根与平均速度之比：

$$
I = \frac{u'}{U}
$$

若已知 $I$ 与平均速度，则湍动能为

$$
k = \frac{3}{2} (U I)^{2}
$$

湍流长度尺度常按特征尺度的比例估算：

$$
l = 0.07 \, L
$$

$L$ 为特征长度（如管径、水力直径）。由 $k$ 与 $l$ 可换算耗散率与比耗散率：

$$
\varepsilon = C_\mu^{3/4} \frac{k^{3/2}}{l}, \qquad \omega = \frac{k^{1/2}}{C_\mu^{1/4} \, l}
$$

其中 $C_\mu \approx 0.09$。另一种常见输入是湍流黏度比 $\mu_t / \mu$，工程上常取 $1 \sim 10$，由它反推 $k$ 与耗散量；需要注意它必须与 $I$、$l$ 的组合自洽。

充分发展剖面的速度分布可用幂律近似：

$$
\frac{u}{U_{max}} = \left(\frac{y}{R}\right)^{1/n}
$$

$y$ 为到壁面的距离，$R$ 为半径，$n$ 常取 7（湍流），或由 $1/n \approx \sqrt{f/8}$ 与摩擦因子关联。

## 4 工程做法与参数

**类型选择。**

- 质量流量入口：最稳健，适合泵/风机系统已知流量的内流；不依赖密度假设。
- 速度入口：适合外流与风洞；需保证入口面法向与主流方向一致，避免斜出入射。
- 总压入口：适合可压缩设备；必须同时给出总温与流向分量。
- 静压入口：较少单独用于入口，通常与速度或流量组合使用。

**剖面处理。** 均匀剖面适合湍流充分、入口远离扰动的情形；近距入口应导入剖面。导入时保持网格插值一致性，并核对面积积分。对层流入口段，可直接用抛物线（Poiseuille）剖面。

**湍流量参数取值。** 外流风洞常用 $I = 0.1\% \sim 1\%$；一般内流 $I = 1\% \sim 5\%$；强扰动或钝体后 $I = 5\% \sim 20\%$。长度尺度对外流可取来流特征长度的 0.07 倍，对内流取水力直径的 0.07 倍。$I$ 与 $l$ 一旦选定，$k$、$\varepsilon$、$\omega$ 就由公式唯一确定。

**内流的水力直径。** 非圆截面管道用四倍流通面积除以湿周长定义水力直径 $D_h = 4A / P$，把它代入长度尺度关系，这是内流入口湍流量估算中最常用、也最容易被忽略的几何量。

**湍流黏度比的估算。** 若求解器要求给定 $\mu_t / \mu$ 而非 $k$，可由 $\mu_t = \rho C_\mu k^2 / \varepsilon$ 反推，并与由 $I$ 换算得到的 $k$ 对照，确保两条途径得到同一量级。

**相容性检查。** 入口量与出口条件必须在特征线意义上相容。可压缩亚声速入口给总压总温、出口给静压；超声速入口给全部状态、出口不再施加压力约束。同时检查入口温度与组分是否与出口回流值冲突。

**网格与分辨率。** 入口面网格应与内部网格尺度平滑过渡，避免在入口处突然放大。若入口需要导入剖面，入口面应足够密以分辨剖面梯度；若入口湍流量沿展向非均匀，最好用场函数或剖面文件逐面赋值。

## 5 可复现示例

以圆管内流为例，管径 $D = 0.05\,\mathrm{m}$，目标质量流量 $\dot{m} = 0.1\,\mathrm{kg/s}$，空气 $\rho = 1.2\,\mathrm{kg/m^3}$，取 $I = 5\%$、$L = D$。代码块内不含货币符号或美元符。

```text
输入: D=0.05, mdot=0.1, rho=1.2, I=0.05, C_mu=0.09

A     = pi * (D/2)**2
U_avg = mdot / (rho * A)          # 由质量流量反推平均速度
l     = 0.07 * D                  # 湍流长度尺度
k_in  = 1.5 * (U_avg * I)**2      # 湍动能
eps   = C_mu**0.75 * k_in**1.5 / l
omega = k_in**0.5 / (C_mu**0.25 * l)

# 剖面: 幂律 n=7,  沿半径 R 布点
R = D/2
for y in radial_grid:
    u = U_avg * (1 + 1/7) * (y/R)**(1/7) * (R/(R))   # 近似归一
    写入剖面(u, u, 0, T=k_in, epsilon=eps)

核对 = 积分(rho * u * dA)
打印("U_avg=", U_avg, "k=", k_in, "eps=", eps, "omega=", omega)
打印("积分流量=", 核对, "目标=", mdot)
```

设置步骤：

1. 选定入口类型并给出物理量，避免重复约束；
2. 计算平均速度或直接给定剖面，核对面积积分；
3. 由 $I$ 与 $l$ 计算 $k$、$\varepsilon$ 或 $\omega$，保持三者自洽；
4. 检查流向与面法向，必要时旋转或修正矢量；
5. 与出口条件和可压缩性相容性逐条核对；
6. 对入口参数做敏感性分析，确认目标量不敏感。

上例中，若把 $I$ 从 5% 降到 1%，$k$ 会降到原来的约四十九分之一，$\varepsilon$、$\omega$ 也随之改变，下游若存在分离或转捩，结果可能明显不同。这说明入口湍流量不是可随意忽略的“辅助参数”，而应先根据实际背景湍流定下来，再在报告中声明其不确定性。

## 6 常见坑与排查

- 同时给速度和流量：重复约束，边界通量不守恒，残差在入口堆积。
- 均匀入口离扰动太近：边界层被迫重新发展，下游压降与换热偏差偏大。
- 湍流量互不一致：由 $I$、$l$ 推出 $k$ 后又手工改 $\varepsilon$，破坏物理自洽。
- 湍流黏度比随意取：$\mu_t/\mu$ 过大相当于注入了不真实的湍流，可能压制分离或转捩。
- 忽略方向符号：入口面为斜切面时，$\vec{u}\cdot\vec{n}$ 局部为负，实际是出流。
- 可压缩入口只给静压：入口特征线需要总压总温，静压入口在亚声速下欠定。
- 温度或组分与出口回流冲突：回流带入的量与入口不一致，引发能量残差震荡。
- 入口面网格与内部不匹配：突然放大造成数值反射，入口附近出现虚假振荡。
- 只给入口不给出口压力基准：不可压缩流虽由入口定流量，但压力水平仍需由出口或参考压力确定。
- 剖面文件与网格不匹配：插值到边界面时点位置错位，实际注入的剖面已经变形。
- 把入口湍流当作可随意调节的“旋钮”：为了让分离或转捩“好看”而反复改 $I$，相当于把物理模型参数当拟合量。
- 入口给了斜向速度却未归一化：只给分量不做矢量归一，实际流量偏离目标。
- 只校入口未校出口：入口给了漂亮剖面，出口却因回流或堵塞把下游反推回入口附近，需两者一起看。

## 7 检查清单与参考

检查清单：

1. 入口类型是否与已知信息匹配，是否避免了重复约束？
2. 剖面来源是否可信，面积积分是否等于目标流量？
3. $I$、$l$、$k$、$\varepsilon$、$\omega$ 是否相互一致？
4. 入口流向与面法向是否核对过？
5. 入口条件与出口条件在可压缩性上是否相容？
6. 是否对入口不确定量做过敏感性分析？
7. 是否记录了入口量的物理含义、数值、单位与来源？
