# CFD 入口边界、剖面与湍流量设置

入口应给出实际可测或由上游系统确定的变量，而不是同时指定彼此依赖的全部状态。边界类型还必须与出口条件和流动可压缩性相容。

## 1. 类型选择

已知泵送流量时可用质量流量入口；已知截面速度时使用速度入口；可压缩设备进口常以总压、总温和流向描述来流。不要同时用入口流量和出口流量过度约束同一稳态内流问题。

## 2. 入口剖面

入口距上游扰动较近时，均匀剖面可能错误。可使用实验、上游计算或充分发展关系导入速度、温度和组分剖面，并核对面积积分是否等于目标流量。

```text
ṁ = ∫A ρ u·n dA
```

## 3. 湍流量

常见输入包括湍流强度与长度尺度、`k` 与 `ε`、或 `k` 与 `ω`。这些量必须相互一致。缺少数据时可以使用工程估算，但要做敏感性分析，尤其是射流、转捩和短入口段。

## 4. 一致性检查

检查法向方向、绝对/相对速度、参考系、总量/静量、绝对压力、温度单位和组分基准。旋转域入口尤其要明确速度是惯性系还是旋转系定义。

## 5. 计算后验证

输出入口面积积分、剖面图和湍流量分布。若入口附近出现强烈非物理调整，说明边界剖面与域内解不匹配，宜增加发展段或改用更真实剖面。
