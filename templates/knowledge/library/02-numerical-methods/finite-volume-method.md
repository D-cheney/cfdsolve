# 有限体积法：从积分守恒到离散方程

有限体积法（Finite Volume Method，FVM）是 OpenFOAM、Fluent、STAR-CCM+ 等主流 CFD 软件的核心离散方法。它把计算域剖分为互不重叠的控制体，在**每个控制体上直接求解积分形式的守恒方程**，再通过数值通量把相邻控制体耦合起来。与有限差分法直接近似微分算子不同，有限体积法近似的是守恒量的积分平衡；与有限元法不同，它的自由度通常定义在单元中心，实现更直接，但对流项的高阶精度需要额外的重构与限制器。本文从积分守恒出发，推导单元中心格式的线性方程组，讲清面通量、梯度重构、源项线性化与局部守恒的工程含义，并给出一个可复现的一维算例。

## 1. 结论与适用场景

有限体积法的要点可以归纳为一句话：**守恒发生在控制体上，而不是节点上**。它对每个控制体写出质量、动量、能量或组分输运的平衡式，因此：

- 内部面上的通量对两侧控制体符号相反，求和时严格抵消，保证**离散层面的局部守恒**，进而保证全局守恒；
- 不要求网格正交，天然支持四面体、六面体、多面体及其混合的非结构网格，适合复杂几何；
- 变量可以存放在单元中心（cell-centered）或节点（cell-vertex），商用软件以前者为主。

适用范围几乎覆盖全部不可压与可压缩流动、传热、多相与反应流的守恒律问题。当问题本身**不是守恒形式**（缺少通量平衡结构）或需要高阶连续解时，有限元或谱方法可能更合适。要不要坚持严格守恒，可以自问：目标量是否依赖通量平衡（阻力、流量分配、能量收支）？若是，优先选 FVM。需要强调的是，局部守恒是 FVM 与生俱来的性质，而不是"事后补上的修正"；正因如此，它成为面向工程通量核算（流量分配、能量收支、组分守恒）的默认选择。

## 2. 物理与数学基础

### 2.1 积分守恒形式

守恒律的微分形式（以标量 $\phi$ 为例）写作

$$
\frac{\partial(\rho\phi)}{\partial t} + \nabla\cdot(\rho\mathbf{u}\phi) = \nabla\cdot(\Gamma\nabla\phi) + S_\phi
$$

其中 $\rho$ 为密度，$\mathbf{u}$ 为速度，$\Gamma$ 为扩散系数，$S_\phi$ 为源项。对任意固定控制体 $V$ 积分，并对流项与扩散项使用高斯散度定理，得到积分守恒形式

$$
\frac{d}{dt}\int_V \rho\phi\,dV + \oint_{\partial V}\rho\phi\,\mathbf{u}\cdot d\mathbf{A} = \oint_{\partial V}\Gamma\nabla\phi\cdot d\mathbf{A} + \int_V S_\phi\,dV
$$

物理含义清晰：**控制体内 $\phi$ 总量的变化率等于净对流通量、净扩散通量与源项生成之和**。正因为先积分后离散，离散方程才逐面满足通量平衡，这也是"守恒"与"局部守恒"的由来。

### 2.2 网格与自由度

在非结构网格中，通常记录每个面的 owner 与 neighbour 单元。内部面的面积矢量按 owner 指向 neighbour 为正向，边界面的外法向指向域外。变量自由度定义在单元中心，面值由相邻两个中心值重构得到。梯度的常用做法是高斯—格林公式或最小二乘拟合：前者实现简单但对畸变网格更敏感，后者在歪斜网格上更稳健。

### 2.3 面值重构

有限体积法需要两类辅助关系：一是**面值重构**，即由单元中心值构造面上值；二是**梯度重构**，用于扩散项与高阶对流格式。迎风格式取上游值，中心格式取两侧平均，高阶格式在两者之间由限制器权衡。二者的精度与稳定性直接决定整体离散误差，也是数值耗散与有界性的主要来源。

## 3. 关键公式与推导

以定常问题为例，对第 $P$ 个控制体去掉时间项，把面求和写开：

$$
\sum_f \rho_f\phi_f(\mathbf{u}_f\cdot\mathbf{A}_f) = \sum_f \Gamma_f(\nabla\phi)_f\cdot\mathbf{A}_f + S_\phi V_P
$$

定义通过面 $f$ 的**质量流量** $F_f = \rho_f(\mathbf{u}_f\cdot\mathbf{A}_f)$ 与**扩散导度**

$$
D_f = \frac{\Gamma_f|\mathbf{A}_f|}{d_{PN}}
$$

其中 $d_{PN}$ 是相邻单元中心沿面法向的距离。对流项用迎风近似（当 $F_f\geq 0$ 取上游单元值），扩散项用 $\Gamma_f(\nabla\phi)_f\cdot\mathbf{A}_f \approx D_f(\phi_N-\phi_P)$，则每个控制体得到一个代数方程，整理为统一形式

$$
a_P\phi_P = \sum_{N} a_N\phi_N + b
$$

其中 $a_N = D_f - \max(-F_f,0)$，$a_P = \sum_N a_N + \sum_f F_f + S_p V_P$，$b = S_u V_P$。系统整体是一个稀疏矩阵方程，系数应尽量保持**对角占优**与**符号有界**，这是迭代稳定性的来源。

在歪斜网格上，界面法向梯度需补上非正交修正：

$$
\Gamma_f(\nabla\phi)_f\cdot\mathbf{A}_f = D_f(\phi_N-\phi_P) + E_f
$$

其中 $E_f$ 为非正交修正项，通常用上一次迭代的梯度显式计算，因此需要多迭代几次才收敛。若忽略它，光滑解上也会留下与网格歪斜成正比的系统偏差。

源项常与 $\phi$ 自身相关，需要线性化：

$$
S_\phi V_P \approx S_u + S_p\phi_P
$$

为保证有界性，通常要求 $S_p \leq 0$，即把源项"拉"回解。例如线性化的化学反应汇项必须以负系数进入 $a_P$，否则可能出现非物理的正反馈。

瞬态项常用后向欧拉离散：

$$
\frac{d}{dt}\int_V \rho\phi\,dV \approx \frac{\rho_P V_P}{\Delta t}(\phi_P^{n} - \phi_P^{n-1})
$$

后向欧拉无条件稳定但时间上一阶；克兰克—尼科尔森格式为二阶，但在强对流或源项突变时可能产生振荡，故常用有界的时间格式或局部时间步控制。为稳定线性求解，还常对离散方程做亚松弛：

$$
a_P \leftarrow \frac{a_P}{\alpha},\qquad b \leftarrow b + \frac{1-\alpha}{\alpha}\,a_P^{\text{old}}\,\phi_P^{\text{old}}
$$

其中 $0<\alpha\leq 1$，$\alpha$ 越小越稳但收敛越慢，是稳定与速度之间的直接权衡。

### 3.1 线性系统的求解

离散得到的线性系统 $\mathbf{A}\mathbf{x}=\mathbf{b}$ 通常稀疏且按单元耦合。稳态问题可用 Gauss–Seidel、共轭梯度或代数多重网格求解；多重网格能把低频误差快速消除，因此在瞬态外迭代中常作为加速器。系数矩阵的对角占优程度、格式的有界性与松弛因子共同决定迭代是否收敛，也解释了为什么“名义二阶格式在坏网格上会悄悄退化为低阶”这一现象。

## 4. 工程做法与参数取值

**网格与几何量**。逐面检查面积矢量 $\mathbf{A}_f$ 是否外指、体积是否为正、单元是否非凹；统计最小体积、最大长宽比与最小正交角。正交性用面法向与中心连线夹角的余弦衡量，工程上宜大于约 0.2。

**梯度重构**。扩散项与高阶对流依赖面法向梯度。非正交网格上把面法向梯度分解为正交部分与校正部分，正交部分由 $D_f$ 表示，校正部分需显式修正或迭代，否则会引入与网格歪斜成正比的误差。

**对流格式**。一阶迎风鲁棒但耗散大，二阶迎风精度高但对网格更敏感；激波与自由面问题需用有界高阶格式配合限制器。扩散项一般用中心格式，因为它是椭圆型、天然光滑。

**源项与松弛**。非线性源项用 $S_u + S_p\phi_P$ 线性化并要求 $S_p \leq 0$；强耦合时用亚松弛因子 $\alpha$ 稳定迭代，压力约 0.2～0.7、动量约 0.5～0.8。

**收敛判据**。除归一化残差下降（如 $10^{-4}$ 至 $10^{-6}$）外，必须监控**面通量守恒误差**与目标量是否平直；目标量应在最后若干次迭代内基本不变。

**稳态与瞬态的取舍**。稳态求解默认流动存在定常解；当流动本质非定常（卡门涡街、周期性分离、浮力振荡）时，强行求稳态只会得到一个被数值耗散过度抹平的“伪定常”场。正确做法是改用瞬态求解，用足够长的时间窗口统计平均量，并检查时间步与统计窗口两者的收敛性。稳态假时间步或局部时间步可以加速收敛到定常解，但不会改变物理与格式耗散。

## 5. 可复现示例

考虑一维定常对流—扩散问题：域 $0\leq x\leq L$，均匀网格，速度 $u>0$ 恒定，扩散系数 $\Gamma$ 恒定，左端 $\phi(0)=\phi_0$，右端 $\phi(L)=\phi_L$。内部节点离散方程由迎风对流与中心扩散组成

$$
F\phi_P = D(\phi_N - \phi_P) + F\phi_W\quad\Rightarrow\quad (D+F)\phi_P = D\phi_N + F\phi_W
$$

其中 $F=\rho u$、$D=\Gamma/\Delta x$。整理后得到三对角系统，可用 TDMA 直接求解。

```python
import numpy as np

def solve_1d_convdiff(L, u, Gamma, phi0, phiL, n):
    # 内部未知量 n 个，均匀网格
    dx = L / (n + 1)
    F = u                       # 单位面积质量流量，取 rho = 1
    D = Gamma / dx              # 扩散导度
    aW = np.zeros(n); aE = np.zeros(n)
    aP = np.zeros(n); b  = np.zeros(n)
    for i in range(n):
        aW[i] = D + max(F, 0.0)     # 迎风：上游权重
        aE[i] = D + max(-F, 0.0)
        aP[i] = aW[i] + aE[i]
    b[0]     += aW[0] * phi0        # 左端 Dirichlet
    b[n - 1] += aE[n - 1] * phiL    # 右端 Dirichlet
    phi = tdma(aW, aP, aE, b)
    x = np.linspace(dx, L - dx, n)
    return x, phi

def tdma(a, b, c, d):
    n = len(b)
    cp = np.zeros(n); dp = np.zeros(n)
    cp[0] = c[0] / b[0]; dp[0] = d[0] / b[0]
    for i in range(1, n):
        m = b[i] - a[i] * cp[i - 1]
        cp[i] = c[i] / m
        dp[i] = (d[i] - a[i] * dp[i - 1]) / m
    x = np.zeros(n); x[-1] = dp[-1]
    for i in range(n - 2, -1, -1):
        x[i] = dp[i] - cp[i] * x[i + 1]
    return x
```

验证步骤：取 $u=1$、$\Gamma=0.1$、$L=1$、$n=9$，计算单元 Péclet 数 $Pe_\Delta = \rho u\Delta x/\Gamma$，与解析解

$$
\phi(x) = \phi_0 + (\phi_L-\phi_0)\frac{\exp(Px/L)-1}{\exp(P)-1},\qquad P=\frac{\rho u L}{\Gamma}
$$

对比，观察一阶迎风在 $Pe_\Delta$ 较大时的数值耗散；再把 $n$ 逐次加倍，确认误差按一阶收敛（对数斜率约为 1）。同时应检验守恒：累加所有面上的对流通量与扩散通量，内部面应两两抵消，仅剩两端边界通量之差，且与解析解的收支一致。如果改用中心差分并让 $|Pe_\Delta|>2$，很快就会在解中看到非物理振荡，这正是隔壁《对流项离散格式选择与有界性检查》讨论的核心。

## 6. 常见坑与检查清单

- **面矢量方向不一致**：外法向弄反会让扩散项符号错误，出现负扩散甚至发散；
- **忘记源项线性化**：把大源项直接放进 $b$，可能破坏对角占优，导致振荡或负值；
- **只看残差收敛**：残差平不代表守恒，必须核查每个面的通量平衡与整体收支；
- **遗漏非正交校正**：歪斜网格上不校正，会在光滑解上留下系统性偏差；
- **有界性失守**：浓度越界、温度为负、湍流量为负时，先查格式与源项，而不是只调松弛；
- **边界通量不一致**：入口/出口的流量、热流应按同一面通量定义核算，避免边界插值造成虚假源汇；
- **网格收敛指数估计不足**：只做两次加密不足以估计收敛阶，建议至少三套网格并配合 Richardson 外推；
- **格式敏感性缺失**：换网格或换格式后未做敏感性检查，就无法给出可信的数值不确定度；
- 提交前清单：体积与面积有效 → 梯度与面通量一致 → 一阶与二阶结果对比 → 网格加密收敛性 → 全局守恒误差量化。
