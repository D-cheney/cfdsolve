# 瞬态 CFD 的时间步、Courant 数与采样长度

隐式算法即使在较大时间步下不发散，也可能悄悄丢掉涡脱落、压力脉动或热前沿。时间步不是一个"越大越省"的自由参数：它同时受物理分辨率、数值稳定性和求解成本三方面约束。本文把这三者拆开讲清楚——哪些是硬性稳定性限制，哪些只是精度问题，以及采样长度为什么必须独立于时间步来选。

## 1. 结论与适用场景

一句话结论：**稳定性限制决定时间步的"上限"，物理分辨率决定时间步的"下限"，采样长度决定你能否看懂频谱。**

- 显式时间推进受严格的 Courant–Friedrichs–Lewy（CFL）条件约束，超限即发散；
- 隐式时间推进可以突破 CFL 稳定性限制，但时间精度仍随时间步线性恶化；
- 瞬态问题的时间步必须能分辨目标频率与最短物理过程，否则得到的是被抹平的假象；
- 采样长度决定频谱分辨率，与时间步是两件独立的事。

适合需要捕捉时间演化的场景：涡脱落与卡门涡街、旋转机械非定常载荷、燃烧与爆燃、浮力振荡、多相界面演化、瞬态传热与热冲击。反之，若流动确实存在定常解且无关心时间历程，用稳态求解更经济。判断依据是斯特劳哈尔数 $St$ 与非定常项的相对权重：$St$ 不可忽略时，稳态假设就不成立，必须改为瞬态求解并规划时间步与采样策略。

## 2. 物理与数学基础

瞬态问题至少涉及三个时间尺度：

$$
t_c = \frac{L}{U},\qquad t_d = \frac{L^{2}}{\alpha},\qquad t_f = \frac{1}{f}
$$

$t_c$ 是对流时间尺度（流体穿过特征长度所需时间），$t_d$ 是扩散时间尺度，$t_f$ 是目标现象的特征周期（$f$ 为目标频率）。多尺度问题由"最小且与目标量相关"的那个尺度决定时间步。这三个尺度分别对应稳定性、粘性松弛与物理周期，不能相互替代。

另一个关键概念是**稳定与准确的区别**。稳定性指离散误差是否随时间放大；准确性指时间离散误差是否可接受。显式格式的时间步被稳定性卡死，往往远小于精度所需；隐式格式稳定性宽松，但时间步太大时一阶时间格式的截断误差会把瞬态过程抹平。因此"隐式能算大时间步"不等于"应该用大时间步"。二阶时间格式（如 Crank–Nicolson、BDF2）在相同时间步下精度更高，但在强对流或源项突变时可能产生非物理振荡，需要配合有界处理。

稳定性可以用冯·诺依曼分析定量判断：把误差写成傅里叶模态 $\phi \sim g^{n}\,e^{ikx}$，只要放大因子 $|g| \leq 1$，该模态就不增长。对一维显式对流—扩散格式，可得

$$
g = 1 - Co\,(1 - e^{-ik\Delta x}) - 4d\sin^{2}\!\left(\frac{k\Delta x}{2}\right)
$$

对所有波数要求 $|g| \leq 1$，就回到 $Co \leq 1$ 与 $d \leq 1/2$ 这两条限制。这也解释了为什么扩散项总是比对流项更“挑食”：它的放大因子随波数平方增长，网格越细越苛刻。

## 3. 关键公式与推导

**Courant 数**。对显式对流格式，稳定性要求流体在一个时间步内穿过的距离不超过一个单元：

$$
Co = \frac{|u|\,\Delta t}{\Delta x} \leq 1
$$

对一维显式迎风格式，可严格证明 $0 \leq Co \leq 1$ 是稳定条件；多维问题中各向 Courant 数之和也需满足类似约束。旋转机械常按每步转角控制：$\Delta\theta = \omega\,\Delta t$ 应小于若干度。

**扩散数**。对显式扩散项，稳定性条件更严：

$$
d = \frac{\alpha\,\Delta t}{\Delta x^{2}} \leq \frac{1}{2}
$$

注意它随 $\Delta x^{2}$ 变化，网格加密一倍，稳定时间步要缩小到四分之一，这是显式扩散格式的致命弱点。若对流与扩散同时存在，可用组合判据 $Co + 2d \leq 1$ 作保守估计。

**时间离散格式**。一阶后向欧拉（隐式，无条件稳定）：

$$
\left(\frac{\rho V}{\Delta t} + A\right)\phi^{n} = \frac{\rho V}{\Delta t}\,\phi^{n-1} + b
$$

二阶 Crank–Nicolson（隐式，无条件稳定但可能振荡）：

$$
\frac{\phi^{n} - \phi^{n-1}}{\Delta t} = \frac{1}{2}\left(f^{n} + f^{n-1}\right)
$$

时间离散的截断误差阶次直接决定瞬态保真度：后向欧拉时间误差为 $O(\Delta t)$，Crank–Nicolson 与 BDF2 为 $O(\Delta t^{2})$。在相同时间步下，二阶格式能更准确地保持脉动幅值与相位，更适合涡脱落、声学与流致振动类问题。

**频率分辨率**。若采样总时长为 $T_s$，可分辨的最低频率约为

$$
\Delta f \approx \frac{1}{T_s}
$$

想识别更低的频率，就必须延长物理采样时间，而不是减小时间步——这是新手最容易搞反的一点。

## 4. 工程做法与参数

**时间步选取流程**：

1. 估计目标最高频率 $f$ 与最短物理过程，得到 $t_f$；
2. 用局部最小网格与最大速度估算最大 $Co$，据此给出显式稳定上限；
3. 依据离散格式与求解器建议给出初值（隐式可取 $Co$ 目标 0.5～1，显式必须 $\leq 1$）；
4. 先运行若干特征时间，让初始瞬态消失后再开始统计；
5. 把时间步减半，比较均值、幅值、相位和主频，确认时间步无关。

**自适应时间步**。按最大 Courant 数自动调整时间步是最常用的策略：设目标 $Co_{\max}$（如 0.5），每步扫描最大 $|u|\Delta t/\Delta x$ 并据此缩放。这样在低速区省时间、在高速区保精度。还需加上下界与上界：过小的步长会被网格与浮点误差拖死，过大的步长会错过物理过程，因此通常同时设定最小与最大时间步。

**每步内迭代**。每个时间步都要把方程误差降到不污染时间离散误差的水平。监控单步质量不平衡与目标量变化；若单步内还未收敛就推进，结果等价于引入额外数值误差。内外迭代的精度关系应当是"内迭代明显比时间离散误差更精确"，实践中常要求内迭代残差比时间截断误差小一个量级。

**初值瞬态的处理**。从均匀初值起算时，流场需要若干特征时间才能发展到物理真实状态。这段“启动瞬态”必须排除在统计窗口之外，否则均值与湍流量都会被污染。判断方法是在监测点上画出目标量随时间的曲线，看它何时进入平稳脉动。

**采样与统计**。统计量应在初始过程结束后采集，并覆盖足够多的主周期。频谱分辨率约为 $1/T_s$，因此识别低频波动需要更长采样时间。对旋转机械，采样长度常取整周期以避免频谱泄漏。

## 5. 可复现示例

下面用一段脚本，为一个对流—扩散问题估算显式稳定时间步，并据目标频率给出隐式求解的建议时间步与采样时长：

```python
import numpy as np

# 物性与网格
nu_eff = 1.0e-5        # 有效运动黏度 m^2/s (含湍流贡献)
U = 2.0                # 特征速度 m/s
dx = 2.0e-3            # 最小网格尺寸 m
f_target = 250.0       # 目标最高频率 Hz

# 1) 显式稳定性上限
dt_adv = dx / U                 # 对流: Co = 1
dt_dif = 0.5 * dx**2 / nu_eff   # 扩散: d = 0.5
dt_exp = min(dt_adv, dt_dif)

# 2) 精度指引: 每个目标周期至少 20 步
dt_acc = 1.0 / (20.0 * f_target)
# 3) 隐式建议: 取 2 倍精度步长, 受 CFL 软约束
dt_imp = min(dt_acc, 2.0 * dt_adv)

# 4) 采样时长: 至少覆盖 20 个目标周期
Ts = 20.0 / f_target
df = 1.0 / Ts

print(f"显式稳定步长 dt_exp = {dt_exp:.3e} s  (Co=1: {dt_adv:.2e}, d=0.5: {dt_dif:.2e})")
print(f"精度指引步长 dt_acc = {dt_acc:.3e} s")
print(f"隐式建议步长 dt_imp = {dt_imp:.3e} s")
print(f"采样时长 Ts = {Ts:.3f} s,  频率分辨率 df = {df:.1f} Hz")
```

步骤与判读：

1. 显式稳定步长取对流与扩散约束的较小者；本例 $dt_{dif}$ 更严，说明扩散主导稳定性；
2. 精度指引步长按"每周期至少 20 步"给出，分辨率越高越贵；
3. 隐式求解可以用比显式大得多的步长，但不应超过精度指引太多，否则瞬态被抹平；
4. 采样时长独立于时间步，由目标频率决定；若 $df$ 大于想识别的低频特征，就必须延长 $T_s$；
5. 最终仍要做时间步减半对比，确认均值、幅值与主频不变。

把这个估算流程固化到项目模板里，每次改网格或改工况都重新跑一遍，就能避免“算完了才发现时间步根本分辨不了目标频率”这类返工。

## 6. 常见坑与排查

- **隐式大时间步当作无条件准确**：稳定性宽松不代表精度够，涡脱落等高频现象会被直接抹掉；
- **只满足 CFL 就认为足够**：CFL 是稳定性/精度的必要条件，不代表能分辨目标频率；
- **单步未收敛就推进**：等价于给时间积分引入额外误差，结果不可复现；
- **用时间步替代采样长度**：降低时间步不能提高低频分辨率，只会徒增计算量；
- **LES、VOF 与激波问题用统一的时间步**：这些场景需要更严格的局部 $Co$ 控制；
- **把初始启动瞬态计入统计**：未排除启动段会让均值与湍流量被系统性污染；
- **旋转机械忽略每步转角**：应按角度而非固定时间去限制时间步。

还有一个常被忽略的成本事实：时间步减半会让总步数翻倍，往往还把内迭代次数推高，总计算量可能是数倍而不是两倍。因此“时间步减半验证”只应做少量关键算例，而不应变成日常工作流。

排查顺序：确认目标频率与最短物理过程 → 核对 $Co$ 与扩散数 → 检查每步内迭代是否收敛 → 最后做时间步减半验证。
