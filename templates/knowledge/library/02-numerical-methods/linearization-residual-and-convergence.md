# 非线性线性化、残差与收敛判定

有限体积法把守恒方程离散成一组代数方程后，由于对流项与部分源项的非线性，得到的并不是线性系统，而是形如 $\mathbf{F}(\mathbf{x}) = 0$ 的**非线性代数方程组**。求解它的唯一现实途径是迭代线性化：在每个外迭代步把非线性系数"冻结"成常数，构造一个线性系统，解出增量或新解。本文讲清这条链条——线性化怎么来、残差怎么定义、收敛怎么判——因为它决定了求解器为什么"卡住"，以及调什么参数才有用。

## 1. 结论与适用场景

一句话结论：**线性化是求解手段，残差是线性系统的不平衡量，二者都不是解本身；收敛必须由残差加守恒加目标量三者联合判定。**

- Picard 迭代（又称冻结系数法）：用上一步的解构造线性系数，稳健但只线性收敛，是大多数 CFD 求解器的默认策略；
- Newton 法：用 Jacobian 同时捕捉解与系数对未知量的依赖，局部二次收敛但收敛域窄，常配阻尼使用；
- 欠松弛：把迭代增量按比例缩放以扩大收敛域，是线性化与稳定性之间的权衡旋钮。

三者关系可以用一句话概括：Picard 是“简化版 Newton”，欠松弛是给两者加的稳定器。工程求解器的默认路径几乎都是 Picard 加欠松弛，只有对收敛速度极敏感的问题（如某些燃烧与辐射耦合）才投入完整 Jacobian。

适用场景覆盖所有稳态与瞬态 CFD 求解。只要方程非线性（对流项、湍流源项、辐射、化学反应都存在非线性），就需要线性化。理解这条链条的意义在于：当残差停滞时，你能判断问题出在线性化、线性求解、边界还是物理模型，而不是盲目地反复调松弛因子。对瞬态问题，线性化还多一层含义：每个时间步内部仍需迭代到一定程度，否则时间精度会被未收敛的方程误差污染。

## 2. 物理与数学基础

离散后的方程组可以统一写成

$$
\mathbf{F}(\mathbf{x}) = \mathbf{A}(\mathbf{x})\,\mathbf{x} - \mathbf{b}(\mathbf{x}) = 0
$$

其中 $\mathbf{x}$ 是所有未知量（速度、压力、温度、湍流量）组成的向量，$\mathbf{A}$ 是包含非线性系数的稀疏矩阵，$\mathbf{b}$ 是源项与边界贡献。注意 $\mathbf{A}$ 本身依赖 $\mathbf{x}$，这正是非线性的来源。对不可压动量方程，质量流量 $F_f = \rho_f(\mathbf{u}_f\cdot\mathbf{A}_f)$ 含速度；对可压缩流，密度由状态方程给出；对湍流，湍流黏度是速度梯度的函数。每一个这样的依赖，都使线性系统无法一次性求解，必须迭代。

求解的基本思路是在某个近似解 $\mathbf{x}^{k}$ 附近把 $\mathbf{F}$ 线性化。Newton 法用一阶泰勒展开，令增量 $\Delta\mathbf{x} = \mathbf{x}^{k+1} - \mathbf{x}^{k}$：

$$
\mathbf{F}(\mathbf{x}^{k} + \Delta\mathbf{x}) \approx \mathbf{F}(\mathbf{x}^{k}) + \mathbf{J}(\mathbf{x}^{k})\,\Delta\mathbf{x} = 0
$$

令其为零即得 Newton 迭代式。Picard 法则更简单：直接令 $\mathbf{A}(\mathbf{x}^{k})\,\mathbf{x}^{k+1} = \mathbf{b}(\mathbf{x}^{k})$，即在构造系数时用上一次的解，但求解时把未知量当作新值。二者都归结为"构造 $\mathbf{A}$ 与 $\mathbf{b}$，解一个线性系统，更新解"的循环。

$\mathbf{A}$ 对 $\mathbf{x}$ 的依赖来自多个源头：对流项的质量流量含速度与密度，后者又由状态方程或湍流模型给出；扩散系数（特别是湍流黏度）依赖速度梯度；源项（如辐射、化学反应速率）通常是温度与组分的强非线性函数；对流格式的限制器系数也依赖局部解。把这些依赖全部写进 Jacobian 就是 Newton 法，只保留系数本身、忽略其导数就是 Picard 法。

## 3. 关键公式与推导

**Newton 迭代**。设 $\mathbf{F}$ 可微，Jacobian 为 $\mathbf{J}_{ij} = \partial F_i / \partial x_j$，则

$$
\mathbf{J}(\mathbf{x}^{k})\,\Delta\mathbf{x} = -\mathbf{F}(\mathbf{x}^{k}),\qquad \mathbf{x}^{k+1} = \mathbf{x}^{k} + \alpha\,\Delta\mathbf{x}
$$

其中 $\alpha$ 是阻尼或欠松弛因子（$0 < \alpha \leq 1$）。若 $\alpha = 1$ 且初值足够接近真解，Newton 法具有**二次收敛**：

$$
\|\mathbf{x}^{k+1} - \mathbf{x}^{*}\| \leq C\,\|\mathbf{x}^{k} - \mathbf{x}^{*}\|^{2}
$$

也就是每次迭代使有效位数翻倍，但代价是必须构造并求解完整 Jacobian，且初值差时容易发散。

**Picard 线性化**。以有限体积离散方程 $a_P\phi_P = \sum_N a_N\phi_N + b$ 为例，把系数用上一步的值计算：

$$
a_P(\mathbf{x}^{k})\,\phi_P^{k+1} = \sum_{N} a_N(\mathbf{x}^{k})\,\phi_N^{k+1} + b(\mathbf{x}^{k})
$$

它等价于 Newton 法只取 Jacobian 的对角近似（把系数对未知量的导数全部略去）。代价是收敛从二次退化为**线性收敛**：

$$
\|\mathbf{x}^{k+1} - \mathbf{x}^{*}\| \leq C\,\|\mathbf{x}^{k} - \mathbf{x}^{*}\|
$$

但在强对流与湍流源项下更稳健，且不需要显式 Jacobian，因此成为工程默认。代价的具体表现是：达到同样精度所需的迭代次数随问题难度线性增长，而 Newton 在收敛域内往往只需个位数步。这也是为什么商业求解器常用“Picard 起步、后期偶尔加速”的混合策略。

**残差定义**。对离散代数系统，第 $P$ 个方程的**未平衡量**定义为

$$
r_P = a_P\phi_P - \sum_{N} a_N\phi_N - b
$$

把整个求解域求和并归一化，得到最常用的**归一化残差**

$$
R_\phi = \frac{\sum_P |r_P|}{\sum_P |a_P\phi_P|}
$$

注意分母用的是当前解的尺度，因此 $R_\phi$ 是一个相对量，与网格量、变量量纲基本无关，这是它能跨算例比较的原因。软件报告的残差缩放方式各不相同：有的用初始残差，有的用全场通量尺度，有的用 $\sum |a_N\phi_N|$，**"降到 $10^{-5}$"只有在明确残差定义后才可比较**。

**伪瞬态与局部时间步**。为了让强非线性问题更容易线性化，常给定常方程加一个伪时间导数项 $\frac{V}{\Delta\tau}(\phi^{k+1}-\phi^{k})$，把迭代变成“用大时间步求稳态”。伪时间步 $\Delta\tau$ 越小，方程对角越强、越稳，但收敛到定常解越慢；局部时间步（每个单元用不同的 $\Delta\tau$）是它在非均匀网格上的推广。伪瞬态项改善的是**迭代稳定性**，不改变物理，也不会降低离散格式本身的耗散。

## 4. 工程做法与参数

**松弛因子**。压力约 0.2～0.7、动量约 0.5～0.8、湍流量 0.3～0.5 是常见起点。松弛因子越小越稳但收敛越慢；Newton 法中的阻尼 $\alpha$ 则应按残差下降情况自适应：若新残差增大就减半重做。

**线性求解精度**。每个外迭代都要把线性系统解到足够精度，否则线性求解误差会污染外迭代收敛。常把线性残差目标设为当前非线性残差的十分之一量级，做到"内紧外松"。

**收敛判据（联合）**：

- 每个守恒方程的归一化残差下降到设定阈值（如 $10^{-4}$ 至 $10^{-6}$）；
- 全域质量、能量、组分不平衡满足工程容限；
- 压降、升阻力、换热量等目标量进入稳定区间；
- 稳态迭代中无持续周期振荡，或已确认问题本身应为瞬态；
- 继续迭代不再改变报告结论。

**残差停滞的处理顺序**：先定位离散质量与边界相容性，再查网格非正交与源项刚性，最后查线性求解误差与松弛因子。只降低松弛通常无法修复不适定的模型。一个实用的经验是：把松弛因子减半后若残差平台只下降一点而迭代次数大幅增加，说明瓶颈不在松弛，而在线性求解或源项。

## 5. 可复现示例

用一种标量非线性方程对比 Newton 与 Picard 的收敛速度，并观察残差如何随迭代下降：

```python
import numpy as np

# 例: 求解 f(x) = x^3 - x - 1 = 0, 真根约为 1.3247
f  = lambda x: x**3 - x - 1.0
df = lambda x: 3.0*x**2 - 1.0

def newton(x0, tol=1e-12, nmax=30):
    x = x0
    hist = []
    for k in range(nmax):
        F = f(x)
        hist.append(abs(F))
        if abs(F) < tol:
            break
        x = x - F/df(x)            # 阻尼可取 1
    return x, hist

xstar, hist = newton(1.0)
print("root  =", xstar)
print("residual history:")
for k, r in enumerate(hist):
    print(f"  iter {k}: |F| = {r:.3e}")
```

步骤与判读：

1. 从 $x_0 = 1$ 出发，Newton 每步用 $\Delta x = -F(x)/F'(x)$ 更新；
2. 观察 $|F|$ 的下降序列：前几步近似减半，之后有效位数迅速翻倍，这正是二次收敛的特征；
3. 把同一问题改用 Picard 式不动点迭代 $x \leftarrow (x+1)^{1/3}$，会看到 $|F|$ 大致每次乘以固定因子，即线性收敛；
4. 把初值换成 $-2$，Newton 可能不收敛——这印证了 Newton 的收敛域窄，工程上必须配阻尼；
5. 现实中这个"残差"对应求解器报的 $R_\phi$，下降曲线的"台阶"往往正是线性化误差与线性求解误差切换的信号。

把这个一维例子放大到 CFD：每个单元就是一个这样的非线性方程，$\mathbf{x}$ 是全场未知量，$\mathbf{J}$ 是稀疏 Jacobian。把标量里“一次 Newton 就几乎到位”的直觉带到高维是危险的——高维 Jacobian 病态得多，且系数矩阵的非对角耦合使线性求解本身也可能不精确，因此实际收敛曲线常呈“阶梯式”下降，而非平滑的二次。

## 6. 常见坑与排查

- **把残差当误差**：残差是离散代数系统的未平衡量，不等于与真解的偏差；网格再粗，残差也能降到很小；
- **跨软件比残差**：不同软件的缩放、归一化与初始残差定义不同，$10^{-5}$ 不是通用标尺；
- **残差平台期就加速**：平台期往往来自源项刚性或线性求解不足，应先定位再调参；
- **松弛因子过小**：会把模型或边界的错误掩盖成"收敛慢"，并徒增迭代次数；
- **Newton 未加阻尼**：强非线性下直接全步容易发散，应做线搜索或自适应阻尼；
- **只看残差**：必须同时看守恒收支与目标量平直度；
- **瞬态求解不收敛每步**：等价于向时间推进引入额外数值误差。

排查顺序：残差定义 → 线性求解精度 → 边界与源项 → 最后才是松弛因子。
