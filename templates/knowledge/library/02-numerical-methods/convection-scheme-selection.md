# 对流项离散格式选择与有界性检查

对流项给数值方法出了一道两难题：它沿流向单向传递信息，用中心差分近似时容易产生非物理振荡；用一阶迎风压制振荡，又会引入过量数值耗散，把剪切层、涡和温度前沿抹平。本文对比主流格式的耗散、精度与稳定性，给出基于单元 Péclet 数与有界性判据的选型流程，并附一个可复现的一维阶跃输运算例，用来量化超调与数值耗散。

## 1. 结论与适用场景

选型的大原则是：**先保证有界，再追求精度，最后用网格无关性把误差量化**。

- 强对流、含激波或尖锐界面：优先“有界高阶”格式（TVD 或带限制器），避免中心差分振荡；
- 光滑、解析充分、网格质量好：中心差分耗散最小，可给出接近二阶的精度；
- 粗网格、复杂几何初算或强非线性起步：先用一阶迎风拿到物理合理的场，再切到高阶；
- 传热、组分与多相：格式差异会直接影响峰值温度、混合分数与界面位置，必须做格式敏感性分析。

适用边界：本文聚焦**有限体积法框架下的对流项（对流通量）近似**，结论可推广到有限差分与有限元中对流积分的稳定化（如流线迎风 Petrov-Galerkin），但具体系数与实现不同。需要提醒的是，格式选择从来不是纯粹的数学问题：它受网格分辨率、目标量精度要求与计算预算共同约束，脱离网格谈格式好坏意义不大。

另需区分三个常被混用的词：**稳定**指迭代或时间推进不发散；**收敛**指数值解随网格与时间步加密趋于同一解；**准确**指该收敛解与真实物理解之间的误差足够小。一个格式可以稳定却很不准，也可以“收敛”到一个被数值耗散严重扭曲的解。选型时要同时盯住这三者，而不是只追求不发散。

## 2. 物理与数学基础

### 2.1 模型方程

对流—扩散方程（一维定常示例）为

$$
\frac{d(\rho u\phi)}{dx} = \frac{d}{dx}\left(\Gamma\frac{d\phi}{dx}\right)
$$

其精确解是对数—指数型分布，当对流远强于扩散时会在下游形成很薄的边界层（即陡峭梯度），这正是数值格式最受考验的区域。把方程无量纲化后可以看到，梯度薄层的厚度由 $Pe_\Delta$ 控制：$Pe_\Delta$ 越大，薄层越薄，解析它所需的网格也越密。若网格不足以覆盖薄层，任何格式都会失真，区别只是失真方式不同（振荡或抹平）。

### 2.2 单元 Péclet 数

在均匀网格上以单元中心值离散，关键量是**单元 Péclet 数**

$$
Pe_\Delta = \frac{\rho u \Delta x}{\Gamma} = \frac{F}{D}
$$

其中 $F=\rho u$ 为面质量流量、$D=\Gamma/\Delta x$ 为扩散导度。$Pe_\Delta$ 是单元尺度上“对流强度除以扩散强度”的比值：$|Pe_\Delta|$ 越大，对流越占优，中心型格式越难保持有界。注意它与网格尺寸成正比，因此加密网格会把 $Pe_\Delta$ 拉回安全区；但当分子扩散很弱时要保持 $|Pe_\Delta|\leq 2$ 往往需要极密的网格，这也是工程上更常采用有界高阶格式而非死守中心差分的原因。

### 2.3 数值耗散与有界性

两个核心概念需要区分：

- **数值耗散（numerical diffusion）**：截断误差里的二阶导数项，形式与物理扩散相同，但系数由格式决定，会额外抹平解，一阶迎风最典型；
- **有界性/单调性（boundedness / monotonicity）**：离散解不产生新的极值，如质量分数落在 $[0,1]$、被动标量不超过边界极值。Godunov 定理指出，**线性、守恒且单调的格式至多一阶精度**，这正是“高阶”与“有界”难以两全的根源，也是限制器存在的原因。

## 3. 关键公式与推导

以面 $e$ 为例。中心差分取两侧平均：

$$
\phi_e = \frac{1}{2}(\phi_P + \phi_E)
$$

一阶迎风取上游值：当 $F_e\geq 0$ 时 $\phi_e = \phi_P$，当 $F_e<0$ 时 $\phi_e=\phi_E$。把迎风离散解与精确解对比，可得到它的等效数值扩散系数

$$
\Gamma_{\text{num}} = \frac{1}{2}\rho|u|\Delta x
$$

它与网格尺寸成正比、与物理扩散 $\Gamma$ 无关，因此加密网格能减小耗散，但在粗网格上可能远超物理扩散。对中心差分，内部节点的离散系数为

$$
a_E = D - \frac{F}{2},\qquad a_W = D + \frac{F}{2},\qquad a_P = a_E + a_W = 2D
$$

要保证系数非负（从而使解有界、无振荡），需满足 $|F|\leq 2D$，即

$$
|Pe_\Delta| \leq 2
$$

这就是经典结论：**单元 Péclet 数超过 2 时，中心差分会产生非物理振荡**。

从一阶切到二阶时，工程实现常用延迟修正（deferred correction）：把高阶通量拆成“隐式一阶部分加上显式差额”，既保持对角占优，又逐步逼近高阶精度：

$$
\phi_e = \phi_{e,\text{up}} + \left(\phi_{e,\text{high}} - \phi_{e,\text{up}}\right)
$$

显式差额取上一次迭代的值，需要多迭代几轮才能真正达到二阶。从截断误差看，一阶迎风为 $O(\Delta x)$，二阶格式为 $O(\Delta x^2)$，但在非结构网格上实测收敛阶往往低于名义值，因此“二阶”更应理解为一种构造方式，而非精度保证。

高阶有界格式通过限制器在“迎风（一阶）”与“中心（二阶）”之间自适应切换。面值写成

$$
\phi_e = \phi_P + \frac{1}{2}\psi(r)(\phi_E - \phi_P),\qquad r = \frac{\phi_P - \phi_W}{\phi_E - \phi_P}
$$

$\psi(r)$ 为限制器函数，$r$ 是梯度比。TVD（总变差不增）要求总变差 $TV=\sum_i|\phi_{i+1}-\phi_i|$ 不随时间增长，对显式格式可导出 Sweby 允许区域：

$$
0 \leq \psi(r) \leq \min(2r,\,2),\qquad r\geq 0
$$

常用限制器中，minmod 最保守、耗散偏大；van Leer 平滑适中，综合表现好；superbee 最锐利，但可能把光滑解压成台阶。

### 3.1 格式与时间离散的耦合

显式时间格式的稳定受 CFL 条件约束：

$$
\text{CFL} = \frac{|u|\Delta t}{\Delta x} \leq 1
$$

CFL 数过大时，迎风与 TVD 也会不稳定；中心差分在纯对流下对 CFL 尤其敏感，其放大因子模在 CFL 接近 1 时发散。隐式格式放宽了 CFL 限制，但空间耗散与振荡特性不变，只是把误差转移到时间方向。因此瞬态计算应先用小 CFL 验证格式行为，再逐步放大到隐式格式允许的范围。

## 4. 工程做法与参数取值

**网格先行**。沿流向局部加密，把 $|Pe_\Delta|$ 控制在合理范围；若坚持用中心差分，目标是让 $|Pe_\Delta|\leq 2$，否则改用有界高阶格式或提升网格。

**选型流程**：

1. 用一阶迎风起步，得到物理合理的初始场并检查边界与守恒；
2. 检查网格质量（正交性、长宽比、尺寸突变单元）；
3. 切到二阶迎风或 TVD 格式，重新收敛到同一判据；
4. 对比压降、升/阻力、峰值温度、混合分数与界面位置；
5. 把格式差异计入数值不确定度，并在报告中写明所用格式与限制器。

**参数建议**：稳态可用二阶迎风作为主力；瞬态含尖锐前沿用 TVD 或界面捕捉格式；源项强非线性时配合亚松弛；若限制器频繁触发，说明网格分辨率不足，应优先加密而非换格式。工程上常见的组合是“对流二阶迎风加扩散中心差分”，并在强梯度区启用限制器。若网格质量差（畸变大、正交性低），即便用高阶格式，也应先修复网格再谈精度。

**限制器选择与诊断**：minmod 适合对振荡极敏感的量（浓度、相分数）；van Leer 通用性好，是多数软件的默认首选；superbee 适合需要保持界面锐度的场景，但会增大解的非单调压缩。诊断方法是统计限制器函数的取值分布：若大量单元长期退化为迎风（$\psi$ 接近 0），说明网格不足或格式过保守；若限制器几乎不生效，则说明网格足够细，可放心使用高阶。

## 5. 可复现示例

一维线性对流方程 $\partial\phi/\partial t + u\,\partial\phi/\partial x = 0$，初值为阶跃（左侧 1、右侧 0），周期边界。比较一阶迎风、中心差分与 TVD（van Leer）在若干时间步后的波形与超调。

```python
import numpy as np

u, L, N = 1.0, 1.0, 100
dx = L / N
cfl = 0.5
dt = cfl * dx / u

x = np.linspace(0, L, N, endpoint=False)
phi = (x < 0.3).astype(float)          # 阶跃初值
phi_u, phi_c, phi_t = phi.copy(), phi.copy(), phi.copy()

def limiter_vanleer(r):
    return (r + abs(r)) / (1.0 + abs(r))

nsteps = int(0.2 / dt)
for _ in range(nsteps):
    # 一阶迎风
    phi_u = phi_u - cfl * (phi_u - np.roll(phi_u, 1))
    # 中心差分
    phi_c = phi_c - 0.5 * cfl * (np.roll(phi_c, -1) - np.roll(phi_c, 1))
    # TVD / van Leer
    denom = phi_t - np.roll(phi_t, 1)
    num = np.roll(phi_t, 1) - np.roll(phi_t, 2)
    r = np.zeros(N)
    safe = np.abs(denom) > 1e-12
    r[safe] = num[safe] / denom[safe]
    psi = limiter_vanleer(r)
    face = phi_t + 0.5 * psi * (np.roll(phi_t, -1) - phi_t)   # 面值
    phi_t = phi_t - cfl * (face - np.roll(face, 1))

print("upwind  min/max:", phi_u.min(), phi_u.max())
print("central min/max:", phi_c.min(), phi_c.max())
print("tvd     min/max:", phi_t.min(), phi_t.max())
```

检查点：迎风格式单调但前沿被抹宽（数值耗散）；中心差分出现小于 0 或大于 1 的**超调**（无界）；van Leer 的 min/max 保持在 $[0,1]$ 内且前沿更陡。再把 CFL 从 0.5 提高到 0.9、或把 $N$ 减半，观察迎风耗散随网格恶化如何增大。若把初值换成光滑正弦波并统计 $L_2$ 误差随时间的变化，还能定量比较三种格式的精度阶；若把阶跃跨度收窄（如 $x<0.35$），超调与抹宽都会加剧，因为同样的网格要解析更陡的前沿。这组对比用不到五十行代码就能复现三种格式的差异，是理解数值耗散与有界性的最低成本实验。

## 6. 常见坑与检查清单

- **迷信“二阶”标签**：名义二阶不代表实现二阶，梯度重构、非正交修正与限制器触发都会降阶；
- **混用格式比较目标量**：换格式后没重新收敛到同一判据就对比，结论不可靠；
- **只看残差**：残差收敛却出现负浓度、负温度，说明格式或源项有界性失守；
- **限制器过度触发**：在后处理里统计限制器取值接近 0 的单元占比，占比高说明网格不够细；
- **瞬态时步与格式耦合**：显式格式需满足 CFL 约束，隐式格式可用更大步长，但不改变空间离散耗散；
- **拿一阶结果下最终结论**：一阶迎风的数值扩散可能在数量级上改变剪切层厚度与峰值；
- **把网格当格式问题**：梯度区出现振荡或过度抹平时，先判断是网格分辨率不足还是格式无界，再决定加密还是换格式；
- **忽略有界与守恒的联查**：格式切换后既要核对极值是否越界，也要核对总通量是否与边界流量一致；
- 清单：$|Pe_\Delta|$ 是否合适 → 变量是否有界 → 一阶与二阶对比 → 网格加密收敛 → 格式敏感性写入不确定度。
