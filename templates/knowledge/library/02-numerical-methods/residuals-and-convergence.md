# 残差、监控量与 CFD 收敛判定

"算完了吗？"这是 CFD 工程师最常被问到的问题，而相当多的错误结论都来自只盯着那一张残差曲线。残差下降只说明代数方程组被迭代得越来越"平衡"，它既不等于物理正确，也不等于工程可用。本文给出一条从残差到守恒、再到目标量的证据链，适用于稳态 RANS 定常解、瞬态计算的内迭代，以及需要写验证报告的场合。

## 1 结论与适用场景

先把结论摆在前面：

- 收敛不是一个数字，而是四类证据同时成立：方程残差、全局守恒、工程监控量、场量合理性。
- 残差量级高度依赖归一化定义，跨软件、跨案例比较"下降了几个数量级"基本没有意义。
- 稳态与瞬态判据不同：稳态看平台，瞬态要区分"每个时间步的内迭代"与"统计样本收敛"。
- 残差停滞时，优先查物理、网格、边界和源项，最后才动松弛因子与线性求解器。

工程的现实是"够用即停"。迭代过多既浪费时间，也可能把物理上本就不定常的稳态问题拖成一条假平台；迭代过少则会把迭代误差悄悄混进网格无关性研究，让后续所有结论都失去意义。本文面向已经会跑稳态求解、需要判断"结果能不能用"的工程用户。大涡模拟的统计收敛另有专门判据，本文只做提示，不展开。

## 2 物理与数学基础

有限体积法把守恒方程在控制体 $P$ 上离散成代数方程：

$$
a_P \phi_P = \sum_{nb} a_{nb} \phi_{nb} + b_P
$$

其中 $\phi$ 为待求量（速度分量、温度或组分），$a$ 为离散系数，下标 $nb$ 表示相邻单元，$b_P$ 汇总源项与边界的贡献。把右端移到左端，就得到该单元的局部不平衡量。残差就是把所有单元的局部不平衡按某种范数汇总后的结果，它衡量的是"当前解在多大程度上不满足离散方程"。

需要区分两个层次：

- **未缩放残差**直接是局部不平衡的范数，量级随问题、单位制、网格尺度和物理量大小而变。
- **缩放残差**再用一个参考量去除，例如该单元系数量级或初始不平衡量，使不同方程之间可以横向比较。

连续性方程通常不写成归一化残差，而是直接报告**质量不平衡**（进出质量的净差），因为它的物理含义最直观。理解这两者差别，是读懂残差图的前提。

还要清楚残差的"三重局限"：其一，残差反映的只是离散方程的求解程度，而不是离散误差与模型误差；其二，不同的求解器可能把 $L_2$、$L_\infty$ 或归一化 $L_2$ 作为默认输出，曲线看起来相似，含义却不同；其三，耦合求解器（压力–速度同时求解）与分离求解器的残差下降节奏完全不同，前者可能一开始就在低量级缓慢波动。因此，把残差当作"是否需要继续迭代"的辅助信号，而不是唯一的判决书。

## 3 关键公式与推导

设第 $i$ 个单元的局部不平衡为 $r_i$，单元总数为 $N$，最常用的 $L_2$ 残差定义为：

$$
R_\phi = \sqrt{\frac{1}{N} \sum_{i=1}^{N} r_i^2}
$$

一种经典的缩放方式是除以系数量级构成的分母，得到无量纲的相对残差：

$$
R_\phi^{scaled} = \frac{ \sqrt{ \frac{1}{N} \sum_{i=1}^{N} r_i^2 } }{ \sqrt{ \frac{1}{N} \sum_{i=1}^{N} (a_P \phi_P)_i^2 } }
$$

它把残差表示成"相对于该方程量级"的分数，因此不同软件给出的量级差异主要来自分母的取法不同：有的用系数量级，有的用初始残差，有的用总通量。若分母随时间变化，缩放残差曲线的形状会与未缩放残差明显不同，这正是"不能跨软件比较"的原因。

全局守恒用一个无量纲不平衡量表达，以质量为例：

$$
\varepsilon_m = \frac{\left| \sum_{in} \dot m - \sum_{out} \dot m \right|}{\sum_{in} \dot m}
$$

工程监控量的收敛则看它的相对漂移。取最近 $k$ 次迭代构成窗口 $Q_k$：

$$
\delta_Q = \frac{\max(Q_k) - \min(Q_k)}{\left| \bar{Q}_k \right|}
$$

当 $R_\phi^{scaled}$ 低于阈值、$\varepsilon_m$ 足够小、且 $\delta_Q$ 已经平直时，三者互相印证，才可以判定收敛。任何一个不达标，都说明"还没算完"或"算错了"。

## 4 工程做法与参数取值

**残差阈值（RANS 定常的起步参考值）。** 缩放后的连续性、动量残差降到 $10^{-4}$ 量级，能量残差降到 $10^{-6}$ 量级，是很多标准案例的经验起点。请把它当起点而不是终点：在复杂几何、大分离或强三维问题里，残差常常在 $10^{-3}$ 附近就进入平台，只要守恒与监控量达标，同样可以使用。

**阈值标定法（推荐）。** 与其背阈值，不如自己做一次标定：把目标量随迭代的曲线画出来，找到它进入"小幅波动带"的那一步，再看此时各类残差落在什么量级，把这一量级作为本项目、本网格的收敛线。这样阈值就与真实问题绑定，而不是照搬别人的数字。

**守恒判据。** 质量不平衡控制在 0.1% 以内，能量不平衡控制在 0.5% 以内；对多相或组分问题，各组分的收支要单独核查，别只查总的。

**监控量判据。** 至少布置三类监控量：进出口流量、关键壁面的积分力或热流、以及关注点的压力或温度。判据是：在最后 100～200 次迭代内，目标量的相对漂移小于 0.2%，且曲线没有单调趋势。监控点应布置在对你结论最敏感的位置，而不是随便挑一个。

**松弛与稳定性取值。** 压力–速度耦合里，动量欠松弛常取 0.5～0.8，压力取 0.2～0.5；压强修正方程压力取 0.3 左右；能量可取 0.8～1.0。伪瞬态或耦合求解则用库朗数控制，常从 1～5 起调，遇到发散再降。核心原则是：先让边界和初始场合理，再用欠松弛保稳定，绝不用极小松弛去"伪造"一条平直的残差。

**残差停滞的排查顺序。** 出现残差长时间不降时，按以下顺序前进，不要跳步：① 检查网格质量（最小正交性、最大长宽比、负体积）；② 检查边界是否在回流区、是否与物理矛盾；③ 检查初始场和物性是否给出非物理状态；④ 检查时间步/伪时间步与库朗数；⑤ 检查源项刚性与非线性耦合；⑥ 检查离散格式在粗网格上的稳定性；⑦ 最后才是线性求解器与松弛因子。多数停滞能在前四步定位。

## 5 可复现示例

下面给出一个把残差历史与监控量历史读入并自动判定的脚本伪代码：

```text
输入: residuals[iter][eq], monitor[iter], 容差表
阈值 = { continuity: 1e-4, momentum: 1e-4, energy: 1e-6 }
窗口 = 最后一次迭代往前 200 步

# 1) 残差判定
for eq in residuals.columns:
    if max(residuals[eq][窗口]) < 阈值[eq]:
        残差通过[eq] = True

# 2) 监控量漂移
漂移 = (max(monitor[窗口]) - min(monitor[窗口])) / abs(mean(monitor[窗口]))

# 3) 守恒校验（由求解器输出或后处理积分得到）
守恒通过 = (质量不平衡 < 1e-3) and (能量不平衡 < 5e-3)

# 4) 综合判定
if 全部(残差通过) and 漂移 < 2e-3 and 守恒通过:
    打印("收敛，可出结果")
else:
    打印("未达标项:", 未通过的方程, "漂移=", 漂移)
    进入排查顺序（见第 4 节）
```

一个具体的数值例子：某稳态案例在最后 200 次迭代中，连续性缩放残差稳定在 $3 \times 10^{-5}$，动量在 $8 \times 10^{-5}$，能量在 $2 \times 10^{-7}$，监测到的进出口质量不平衡为 0.02%，压降监控量的窗口漂移为 0.05%。四项全部达标，判定收敛。反过来，如果残差都已经降到 $10^{-6}$，但压降在窗口内仍以每百步约 1% 的速度单调下降，就应当判定**未收敛**，需要继续迭代或排查是否存在缓慢的物理过程。

再举一个容易误判的例子：某案例残差在 $10^{-3}$ 附近震荡，看起来"下不去了"，但把监控量的时间序列画出来，发现升力系数在稳定周期振荡，质量不平衡只有 0.03%。这不是"没收敛"，而是**本质非定常**流动，正确做法是改用瞬态求解并做统计，而不是继续硬迭代稳态。

## 6 常见坑与检查清单

常见坑：

- **只看残差**：残差很低但守恒差、监控量仍在漂移，说明结果里还有系统偏差。
- **跨软件比量级**：不同归一化下的 $10^{-4}$ 不是同一回事，不能照搬别人的阈值。
- **用极低松弛制造平台**：曲线平了，物理并没有到。
- **把监控量周期振荡当噪声**：这很可能是本质非定常流动，稳态解根本不存在。
- **忽略场量合理性**：出现负绝对温度、越界组分、异常峰值时，先修物理再谈收敛。
- **在未收敛的粗网格上做网格无关性**：迭代误差会被误当成网格误差，结论完全失真。
- **换格式后没重新标定阈值**：一阶格式残差通常更容易降，不能与二阶结果直接对比。

检查清单：

1. 残差的定义与阈值是否写明？
2. 三类监控量是否都已稳定？
3. 质量、能量、组分收支是否分别达标？
4. 场量是否处处物理合理、无越界？
5. 稳态问题是否被验证为定常？
6. 报告是否给出完整历史，而不是只截一张最后的残差图？
7. 阈值是否来自本项目标定，而非照搬文献？
