# CAE 算法全景图：物理模型、离散、求解与可信度

CAE 不是某一种求解器，而是一条从物理假设到工程决策的算法链。任何一次计算都可抽象为三步：把物理写成连续模型，把连续模型离散成有限维代数或时间问题，再对结果做可信度评估。本文用“物理模型 → 离散 → 求解 → 可信度”四层框架串起 CFD、结构、热、电磁、声学、多体、粒子法与多物理耦合，并给出每层的输入输出、选型条件与验证责任。相比线性罗列算法名称，这条链式视角能解释为什么同一物理问题在不同软件里会给出不同答案。

## 1. 结论与适用场景

全景图的价值在于给出**统一的提问顺序**：

1. 物理模型层：用哪套守恒律与本构？稳态还是瞬态？线性还是非线性？
2. 离散层：几何适合体积离散（FEM/FVM/FDM）还是边界/粒子离散（BEM/SPH/LBM）？
3. 求解层：矩阵是 SPD、对称不定还是一般非对称？时间步显式还是隐式？
4. 可信度层：代码正确吗（验证）？解收敛吗（解验证）？模型对得上现实吗（确认）？

这四问互相制约：物理的非线性决定求解器选择，几何与维度决定离散方案，而可信度要求反过来限定网格、时间步与验证数据。选型的最低证据，是四层各自都能说清楚“为什么这样选”，而不是罗列算法名称。任何跳层决策都要付出代价：例如把非线性问题硬塞给显式格式，会因稳定步长过小而无法收敛；把不可压流交给可压缩求解器，则会在低马赫数下损失精度。用这条链审视任何一个求解器，都能快速定位它的强项与弱项：显式结构求解器擅长冲击与接触但受步长限制，隐式 CFD 求解器擅长稳态但每步代价高。四层之间的错配，正是多数“结果不对”问题的根源。因此在项目早期就把四层写成一句话，能在归档时快速回溯，也能让不同团队对同一模型的理解保持一致。

## 2. 控制方程

四层框架中，物理模型层的产物就是各领域的一组控制方程与本构关系：

- 固体与结构：线弹性、塑性、损伤与断裂；
- 结构动力学：$M\ddot u+C\dot u+Ku=f$；
- CFD：Navier–Stokes、Euler 与 RANS/LES/DNS 平均化；
- 热：导热、对流、辐射与相变；
- 电磁：Maxwell 方程组及其准静态退化；
- 声学：Helmholtz、线化 Euler 与波动方程。

统一的连续模型可写作

$$
\mathcal{L}(u;\mu)=f,
$$

其中 $u$ 是状态量、$\mu$ 是材料与工况参数。物理层的每个假设（无黏、绝热、小变形、线性本构、稳态）都会在后续传播成系统误差，因此必须逐条显式记录，而不是埋在求解器的默认值里。同一物理域往往有多级模型：例如流体可依次采用势流、Euler、RANS、LES、DNS，所选层级决定了问题的可解尺度与计算代价。需要强调的是，物理模型层的选择往往比离散层更决定成败：把湍流问题交给层流模型、把塑性问题交给线弹性，即使离散再精细也无法得到有用结论。因此选型的第一份证据应是模型适用性的论证，而不是网格数量。还要注意各领域模型并非孤立：结构与热通过热膨胀耦合，电磁与热通过焦耳损耗耦合，流体与结构通过界面力耦合，因此物理层的划分要预留跨域接口。

## 3. 离散格式与公式

离散层的任务是把连续模型变成有限维问题：空间离散写作 $R_h(U;\mu)=0$，时间离散给出推进格式。把整条链写成算子形式

$$
\mathcal{L}(u;\mu)=f
\;\longrightarrow\;
R_h(U;\mu)=0
\;\longrightarrow\;
J(U)\,\delta U=-R(U).
$$

最后一步的 Jacobian 与残量决定求解器选择：$J$ 对称正定用 Cholesky/CG，对称不定用 MINRES，一般非对称用 LU/GMRES。离散方法族包括有限差分（FDM）、有限体积（FVM）、有限元（FEM）、间断 Galerkin（DG）、谱方法、边界元（BEM）、格子 Boltzmann（LBM）与粒子/无网格法。粒子与无网格分支还可细分为光滑粒子流体动力学（SPH）、离散元（DEM）和物质点法（MPM），三者分别适合连续介质大变形、颗粒接触和历史变量随物质点迁移的问题。方法选择依据是守恒需求、几何复杂度与所需精度阶。例如守恒核算优先选有限体积，复杂几何与多物理变分问题优先选有限元，而光滑解的高精度则指向谱方法。离散误差的两个来源是截断误差与网格质量：阶次决定误差随网格减小的下降速度，网格质量决定误差的常数因子。评估离散层时，至少要在同一物理模型下比较两种离散方法，确认结论不因方法而异。离散层还要决定自由度与网格类型的匹配：四面体适合复杂几何但单元质量参差，六面体精度高但生成困难，边界层与各向异性网格用于捕捉梯度。

## 4. 工程实现与参数

**求解层**。线性系统按矩阵性质选择迭代法与预条件；非线性残量 $R(U)=0$ 用 Newton、拟 Newton、Picard 或 Jacobian-free Newton–Krylov，并配线搜索或信赖域增强全局收敛。时间积分分显式（受 CFL 约束）与隐式（每步需要求解），结构动力学另有 Newmark、广义-$\alpha$ 等专用格式。

显式时间推进的稳定性约束可写成

$$
\Delta t \leq C\,\frac{h}{c\sqrt{d}},
$$

其中 $h$ 为特征网格尺度，$c$ 为最快波速或最高频率对应的特征速度，$d$ 为空间维数，$C$ 为与格式有关的常数。隐式格式虽无此限制，但每步的线性求解代价与非线性迭代次数会把省下的步数重新还回去。

**耦合、优化与不确定性**。多物理耦合分单体与分区：弱耦合每步只交换一次，强耦合在步内迭代到界面残差达标，Aitken 或 IQN-ILS 可加速。优化由伴随或自动微分提供梯度，不确定性量化用于传播输入分布并报告置信区间，降阶用 POD/DMD 缩减状态维数，代理模型则用于高频调用场景。

**可信度参数**。网格与时间步收敛需至少三套分辨率并配合 Richardson 外推；残差只说明迭代停止，不能替代物理确认；确认环节要把计算量与实验或高保真参考解对齐，并量化参数与模型不确定度。

**性能与可扩展性**。大自由度的瓶颈通常在内存带宽与线性求解，而非浮点运算。预条件的质量往往比迭代法名称更重要，一个匹配矩阵结构的预条件可以把迭代次数降低一个数量级；求解器还应输出收敛诊断，便于判断失败来自物理、离散还是代数层。

**时间与事件**。瞬态问题要在精度与步数之间权衡，事件驱动的问题（接触、碰撞、开关）需要步长自适应与状态重初始化，否则会漏掉关键瞬时响应。此外，自适应步长不能只看残量，还要看物理量的变化率与事件间隙。

## 5. 可复现示例

用一维对流—扩散问题串起四层，作为全景图的最小闭环：

```
物理层:   u*dphi/dx = Gamma*d2phi/dx2,  0 < x < L
离散层:   迎风对流 + 中心扩散 -> 三对角系统
求解层:   TDMA 直接求解; 检查对角占优
可信度层: 与解析解对比; 网格加倍看一阶收敛
          Pe_dx = u*dx/Gamma, 检查是否出现振荡
验收:     内部面通量抵消; 边界通量收支平衡
```

同一个问题分别用 FVM（守恒、面通量）与 FEM（弱式、分片线性）离散，比较同一网格下的误差与守恒误差，即可直观理解“离散层的选择如何影响可信度层的结论”。这两个离散在同一物理模型下给出不同数值，正是四层框架要强调的重点。这个闭环很小，却完整暴露了四层耦合：物理决定方程形式，离散决定矩阵结构，求解决定成本，可信度决定最终能不能用。

## 6. 常见坑与排查

- **跳过物理假设记录**：默认湍流模型、默认本构被当作事实，误差源头无法追溯；
- **只换求解器不改离散**：把收敛慢归咎于迭代法，实际问题出在格式耗散或矩阵病态；
- **残差平即收工**：未做守恒检查与目标量平直性检查，结果可能尚未收敛；
- **网格收敛只看两次加密**：不足以估计收敛阶，无法给出可信误差；
- **耦合界面不守恒**：分区耦合未核对界面通量，产生虚假源汇；
- **术语堆砌代替选型**：罗列算法名不等于说明适用条件与验证责任；
- **忽略模型层级**：用过于简化的物理模型拟合，再用高精度离散掩盖，得到精致却错误的解；
- **验证与确认混为一谈**：代码验证、解验证与确认关注不同问题，缺失任一项都会让结论的可信度无从判断；
- **分辨率与结论错配**：用粗网格下“看起来合理”的结果替代收敛研究，风险会被低估。

## 7. 检查清单与参考

检查清单（按四层）：物理模型层——方程、本构、边界/初始条件、参数不确定度已列明；离散层——方法、阶次、稳定化、守恒特性已说明；求解层——矩阵性质、预条件、非线性策略、收敛准则已记录；可信度层——代码验证、解验证、网格/时间步研究、确认数据已归档。

学习路径建议：先掌握有限体积与有限元两条主线，再按物理域扩展到声、电、热与粒子方法，最后补齐耦合、优化、降阶与不确定度量化。每学一种算法，都按四层框架记录它的适用条件与验证责任，形成可检索的选型卡片。
