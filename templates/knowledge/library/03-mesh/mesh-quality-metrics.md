# CFD 网格质量指标与修复顺序

网格质量指标是风险提示，不是跨软件通用的合格证。同一个数值落在扩散主导区还是强剪切区，后果完全不同。本文把最常用的五个指标——非正交、偏斜、长宽比、体积变化率与负体积——逐一讲清：它们各自度量什么、阈值在哪里、如何影响离散误差与迭代收敛，以及出现坏单元后应当按什么顺序修复。

## 1 结论与适用场景

核心结论：

- 几何合法性是底线。负体积、重复面、孔洞、错误法向与悬挂节点必须清零，否则求解根本无法启动，或守恒关系被静默破坏。
- 偏斜与正交质量是影响最大的两个插值类指标，应优先控制，因为它们直接决定面通量插值与梯度计算的精度。
- 长宽比本身不是罪，方向错了才是。与边界层法向一致的高长宽比单元，往往既省单元又保精度。
- 体积变化率与增长比是"软"指标，控制分辨率突变的程度，主要影响截断误差与迭代稳定性。
- 指标是局部的、定量的、与物理位置绑定的，不要用一个全局平均值给整套网格打分。

适用场景覆盖有限体积与有限元的各类网格：结构六面体、非结构四面体、多面体以及壁面棱柱层。需要强调的是，各指标的重要性随流动机制变化：扩散主导的低速流对非正交最敏感，对流主导的超声速流对偏斜最敏感，而强源项区（燃烧、多相、辐射）会把上述误差进一步放大。

## 2 背景与原理

有限体积法把守恒律写成面通量之和。在单元面上，扩散项需要面法向梯度，对流项需要面值，而面值由相邻单元中心值插值得到。当单元中心连线与面法向不共线时，法向梯度无法只由两侧中心值精确表达，求解器必须补上一项非正交修正；当插值点偏离面中心时，对流面值的精度随之下降。这两件事恰好对应正交质量与偏斜。

非正交度量大的是"扩散项被迫用非共线方向的信息去凑"。在网格较斜处，修正项自身引入截断误差，而修正项又依赖梯度，于是精度与稳定性发生耦合。偏斜度量大的是"插值位置与面中心不一致"，偏斜大时面值误差达到单元尺度的一阶量，会直接污染对流主导的问题。

长宽比度量大的是单元在不同方向的尺度之比，它与误差之间没有简单的单调关系：误差由通量方向与梯度方向的配合决定。沿边界层法向的大长宽比单元，其长边正好沿切向、梯度很小的方向，因此并不放大误差；若把同样的细长单元放在长边与梯度方向一致的位置（例如钝体前缘的横向），误差就会被放大。

体积变化率与增长率度量相邻单元尺度的突变。分辨率突然跳变会产生数值反射、放大色散误差，并让部分限制器与梯度格式行为异常，因此它们更多影响稳定性与光滑度，而非单点精度。

## 3 关键公式与判据

非正交角定义为单元中心连线方向与面法向的夹角：

$$
\alpha = \arccos\left(\frac{\vec{d} \cdot \vec{n}}{\lVert \vec{d} \rVert \, \lVert \vec{n} \rVert}\right)
$$

其中 $\vec{d}$ 是面两侧单元中心连线矢量，$\vec{n}$ 是面法向。$\alpha$ 越小越正交；工程上常把 $\alpha \leq 60^{\circ}$ 视为良好，$\alpha > 80^{\circ}$ 需要警惕，接近 $90^{\circ}$ 时扩散修正几乎失效。

正交质量把上述偏离归一化到 0 到 1 之间，常以方向一致性与位置偏离综合定义：

$$
Q_{orth} = \max\left(1 - \frac{\alpha}{90^{\circ}}, \; 1 - \frac{\lVert \vec{r}_f \rVert}{\lVert \vec{d} \rVert}\right)
$$

$Q_{orth}$ 趋近 1 表示完美正交，趋近 0 表示最差。多数求解器把 $Q_{orth} \geq 0.05$ 作为可疑线、$\geq 0.3$ 作为良好参考。

偏斜度衡量面中心与理想插值点的偏离，理想插值点取面中心在两侧中心连线上的投影。归一化形式为：

$$
S = \max\left(\frac{d_1}{L_1}, \frac{d_2}{L_2}\right)
$$

这里 $d$ 是面中心到投影点的距离，$L$ 是对应单元中心到面中心的距离。另一种常见写法是 $S = d_{max} / L_{eq}$，其中 $L_{eq}$ 为单元等效尺度。无论哪种，$S = 0$ 为完美，$S \geq 0.85$ 属于偏差，$S \geq 0.95$ 属于不可接受。

长宽比与增长率分别写作：

$$
AR = \frac{h_{max}}{h_{min}}, \qquad r_g = \frac{h_{i+1}}{h_i}
$$

$h$ 为单元在三个主方向上的尺度。自由剪切区、边界层内允许 $AR = 100 \sim 1000$，只要细长方向与低梯度方向一致；而在存在多向梯度的核心区，最好把 $AR$ 控制在 $10 \sim 20$ 以内。增长率建议 $r_g \leq 1.2$、不超过 $1.3$，因为三维下线性增长 $1.2$ 对应约 $1.7$ 的体积比。

体积变化率可写成相邻单元体积之比 $V_{i+1} / V_i$，它与线性增长率的三次方近似的对应，因此三维里一个看似温和的 $1.3$ 倍线性增长，其实意味着 $2.2$ 倍的体积跳变。只看线性尺度容易低估这种突变，建议同时对体积变化率单独设线。

把常用阈值汇总成一张速查表，便于分区验收：

| 指标 | 良好 | 可疑 | 不可接受（关键区） |
| --- | --- | --- | --- |
| 正交质量 $Q_{orth}$ | $\geq 0.3$ | $0.05 \sim 0.3$ | $< 0.05$ |
| 偏斜度 $S$ | $\leq 0.5$ | $0.5 \sim 0.85$ | $> 0.95$ |
| 长宽比 $AR$（核心区） | $\leq 20$ | $20 \sim 100$ | $> 1000$（方向一致者可放宽） |
| 增长率 $r_g$ | $\leq 1.2$ | $1.2 \sim 1.3$ | $> 1.3$ |
| 非正交角 $\alpha$ | $\leq 60^{\circ}$ | $60^{\circ} \sim 80^{\circ}$ | $> 80^{\circ}$ |

## 4 工程做法与参数

修复优先级，从致命到可容忍：

1. 清除负体积、重复面、零面积面、孔洞与错误法向；
2. 修复边界、接口与周期映射不一致，保证共形或正确的非共形连接；
3. 处理关键高梯度区的极端偏斜与极端非正交；
4. 平滑体积变化率、增长比与边界层增长率；
5. 最后才优化远离目标区的统计类指标。

需要给出的不是单一数字，而是一张分布：最小值、最大值、体积加权平均，以及最差单元的空间位置。体积加权的 $Q_{orth}$ 比算术平均更能反映壁面对结果的影响，因为壁面附近的单元体积小、数量多，却往往是误差的主要来源。

阈值取舍建议按"关键区/非关键区"分别设线。例如壁面与分离区要求 $Q_{orth} \geq 0.2$、$S \leq 0.85$；远场可放宽到 $Q_{orth} \geq 0.05$、$S \leq 0.95$。数值指标要与几何成因一起看：狭缝、尖角、薄壁尾缘、旋转界面附近出现坏单元，往往是几何清理或尺寸场问题，而不是单纯的"网格太粗"。

常用修复手段包括：对局部坏单元做拉普拉斯光滑或基于面的顶点重排；在四面体区用面交换（swap）改善连接；对极端偏斜单元做局部重划；对薄壁与狭缝改用边界层或扫描式拓扑，从根源上避免退化。这些操作应当**局部进行**，以免平滑掉用户刻意布置的加密。每次修改后都应重新统计分布，而不是凭印象认为已经变好。

还有一个常被忽略的原则：质量指标服务于目标量。若某个坏单元并不在研究关注的路径或表面上，修复它可能收益很小；反过来，一个"看起来还行"的单元若位于分离点或激波上，其影响可能远大于数值所暗示的。因此分区阈值应当由**误差敏感性分析**反推，而不是照搬默认值。

## 5 可复现示例

下面用一段伪代码从单元数据计算质量分布，并按分区阈值给出判定。代码块内不含任何货币符号或美元符，避免与公式渲染冲突。

```text
输入: cells = [(center, volume, faces, region), ...]
       region_limits = {region: (ortho_min, skew_max)}

for c in cells:
    ortho_c = 1.0
    skew_c  = 0.0
    for f in c.faces:
        d      = c.center - f.neighbor_center
        alpha  = angle(f.normal, d)
        o      = 1.0 - alpha / 90.0
        p      = project(f.centroid, d)
        s      = distance(f.centroid, p) / length(d)
        ortho_c = min(ortho_c, o)
        skew_c  = max(skew_c, s)
    c.ortho = ortho_c
    c.skew  = skew_c

vol_total      = sum(c.volume for c in cells)
ortho_weighted = sum(c.ortho * c.volume for c in cells) / vol_total
worst          = min(cells, key=lambda c: c.ortho)

for c in cells:
    lo, hi = region_limits[c.region]
    if c.ortho < lo or c.skew > hi:
        标记(c, c.ortho, c.skew)

打印("体积加权正交质量=", ortho_weighted)
打印("最差单元=", worst.center, "正交质量=", worst.ortho)
```

判定流程：

1. 先跑合法性检查，任何负体积或零面积面直接判失败；
2. 计算体积加权 $Q_{orth}$ 与最大值 $S$；
3. 按区域阈值筛出坏单元并可视化；
4. 定位坏单元的几何成因（狭缝、尖角还是接口）；
5. 调整尺寸场或清理几何后重跑第 2 步；
6. 记录每次迭代的指标分布，作为网格验收证据。

## 6 常见坑与排查

- 只报全局最大值、不报位置：最差单元若在远场无源区，影响也许可以接受；若在目标表面，则必须修复。
- 用算术平均掩盖局部灾难：一个 $Q_{orth} = 0.01$ 的单元会被大量好单元平均掉。
- 把长宽比一票否决：边界层内的大长宽比常常是正确做法，无差别压小会浪费大量单元并拖慢收敛。
- 忽略非共形接口：接口两侧分辨率差异过大，等价于人为制造强体积变化率。
- 修完指标不复查物理：局部加密可能改变 y+，或引入新的高偏斜单元。
- 混用不同软件的阈值：各家对偏斜与正交的定义、归一化都不同，阈值不可直接搬运。
- 用容差放过微小负体积：它会把守恒破坏藏进残差里，长时间迭代后才爆发。
- 只看单一截面或单一区域的平均值：局部坏单元的分布位置比全局均值更有诊断价值。
- 修复时全局重新光滑：把刻意布置的边界层加密和尾迹加密一并抹平，得不偿失。
- 忽略单元类型差异：四面体的偏斜与六面体的偏斜定义与尺度不同，跨类型阈值不能直接比较。

## 7 检查清单与参考

检查清单：

1. 是否先清零所有几何非法项（负体积、重复面、孔洞、错误法向）？
2. 是否分别报告了 $Q_{orth}$、$S$、$AR$ 与增长率的最小值、最大值和加权分布？
3. 阈值是否按关键区与非关键区分开设定？
4. 最差单元是否已定位到几何位置并判断了成因？
5. 接口与周期面两侧是否共形或正确非共形？
6. 修复后是否复查了 y+、增长比与目标量敏感性？
7. 是否保留了完整质量报告作为验收证据？
