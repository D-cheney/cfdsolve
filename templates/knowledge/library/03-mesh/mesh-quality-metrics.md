# CFD 网格质量指标与修复顺序

网格质量指标是风险提示，不是跨软件通用的合格证。相同指标在扩散主导区和强剪切区的影响不同，应结合位置和物理梯度判断。

## 1. 核心指标

非正交描述单元中心连线与共享面法向的偏离，会增加扩散通量修正误差。偏斜反映面中心与插值位置不一致。长宽比本身不一定有害：与边界层方向一致的高长宽比单元可能非常有效，但方向错误会放大误差。尺寸增长过快会造成分辨率突变和数值反射。

## 2. 修复优先级

1. 清除负体积、重复面、孔洞和错误法向；
2. 修复边界、接口和周期映射不一致；
3. 处理关键高梯度区的极端偏斜与非正交；
4. 平滑尺寸跳变和边界层增长率；
5. 再优化远离目标区的统计指标。

## 3. 局部定位

不要只记录最大值，应把最差单元显示在几何中，判断是否位于狭缝、尖角、出口、旋转界面或目标表面。少量坏单元位于强源项区时，影响可能大于大量普通区域的中等质量单元。

## 4. 求解阶段信号

局部残差热点、压力锯齿、非物理温度和线性求解器迭代突增都可能指向网格。可将问题场量与质量指标叠加，确认相关性后再修网格。

## 5. 验收记录

保存单元数量、最小体积、质量分布、最差单元位置、边界层统计和修复说明。不同版本网格应使用固定命名和变更记录。

2. Knupp & Steinberg, *Fundamentals of Grid Generation*.
