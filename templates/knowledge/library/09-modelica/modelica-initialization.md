# Modelica 初始化、初始方程与稳态起点

动态模型开始积分前，工具必须先求出一组“一致初值”：既满足代数约束，又满足离散模式，还给出全部状态的初值。初始化失败往往不是求解器的问题，而是物理约束冲突或用错了初始化工具。对通过接口连接 CFD 特性图或降阶模型的耦合系统，初始化还要保证界面两侧在同一启动点上自洽。本文系统梳理初始化工具、诊断方法与耦合场景的工程做法。

## 1. 结论与适用场景

先明确三个层次：`start` 只是非线性求解的初猜；`fixed=true` 把某变量的起始值提升为强制约束；`initial equation` 定义只在初始化阶段成立的方程。三者混用是初始化失败的头号原因。

- 只想给个合理估计：写 `start`。
- 要求某状态精确从某值出发：写 `start` 并加 `fixed=true`。
- 要求初始处于平衡：写 `der(x)=0` 之类的 `initial equation`。
- 稳态启动（如管网、热网）：用稳态初始化，把随时间变化的项置零，让初值落在物理平衡点上。

对从静态工况启动的 CFD 耦合系统（例如从设计点特性图启动），更推荐稳态初始化，使启动瞬间不产生人为瞬态。反之，若要复现一次具体试验，则应按实测初值设置，而不是强求稳态。

选择哪种初始化，本质上取决于你要回答的问题。如果目的是“看看系统会如何偏离某个工况”，就应从该工况的稳态出发，把扰动作为激励；如果目的是“复现瞬态试验”，就应忠实设置实测初值，并接受启动阶段可能存在的瞬态。把两者混为一谈，常常得到既不像稳态也不像实验的中间结果。无论选哪种，一致性与可复现是两条底线：初值要自洽，过程要能被别人重放。

## 2. 原理与协议/语义

初始化本质上是一个代数求解问题：给定 $t_0$ 时的部分条件，求状态 $x_0$、导数 $\dot{x}_0$ 与代数变量 $y_0$，使 DAE、离散方程与附加初始方程同时满足。工具会先选定哪些状态需要初始化，再用初始方程与 `fixed` 约束补齐数目。

欠定表现为某状态没有任何初值约束，工具会警告“找不到初值”；过定表现为同一物理量被多处固定，约束互相冲突。典型冲突是同时给定压力、温度、流量与总质量：它们本受守恒关系约束，全部固定后系统多出方程，无法满足。

耦合接口处的语义尤其微妙。流体连接器在初始化时用 `stream` 变量约定上游值；若两侧对谁提供压力、谁提供流量没有约定一致，初始化会过定或欠定。经验法则是：每个连接集合里只允许一个“驱动”给定，其余由守恒关系确定。

初始化失败时，第一步不是改参数，而是读工具报出的信息：它列出了哪些状态需要初始值、哪些初始方程被采用、残差在哪个变量上最大。把这些信息与物理直觉对照，往往能直接定位冲突。一个常见误区是不断微调 `start` 值“碰”过去，这会掩盖真正的结构问题，使模型在换工况后再次失败。

初始化还分“求解初始方程组”和“数值求解非线性方程组”两个阶段：前者是结构性的（方程够不够、配不配对），后者是数值性的（初猜好不好、雅可比是否病态）。先解决结构问题，再解决数值问题，顺序不能颠倒，否则调参只是在噪声里摸索。

对耦合系统，界面初值的一致性检查应作为常规步骤：把界面两侧的压力、温度、流量初值打印出来逐项对照，任何一项不匹配都可能是初始化失败的根源。很多“莫名其妙”的失败，最终追到的是两侧参考态或单位不一致。

另一个常见来源是环境参考量：大气压、参考温度、重力加速度等若两侧默认值不同，初始化时的压力与温度平衡就会错位。把这些量集中定义并显式传递，可以消除一整类隐蔽冲突。

## 3. 关键公式与接口

初始化系统可写成

$$ F(t_0, x_0, \dot{x}_0, y_0) = 0, \qquad y_0 = h(x_0) $$

稳态初始化把导数置零：

$$ \dot{x}_0 = 0 $$

于是问题退化为求一组代数量的平衡解。求解常用牛顿迭代：

$$ x_{k+1} = x_k - J^{-1} F(x_k), \qquad J = \frac{\partial F}{\partial x} $$

当积分初猜远离解时，牛顿可能发散。稳健做法是参数同伦，把难解问题逐步过渡到目标问题：

$$ F(\lambda) = \lambda\,F_{sim} + (1-\lambda)\,F_{nom}, \qquad \lambda: 0 \to 1 $$

其中 $F_{nom}$ 是易于求解的“标称”问题（如全部置为常数或线性化），$\lambda$ 从 0 连续增到 1，沿路径跟踪解，最后落到目标系统的初值。Modelica 用 `homotopy(actual, simplified)` 表达这一对表达式。

初始化的一致性还要求离散模式固定：`Boolean` 等离散量的初始值需显式固定，否则工具在初始化时无法确定分支。

牛顿法的收敛域有限，初猜越好越稳。稳态初始化把 $\dot{x}_0=0$ 代入后，问题退化为纯代数方程，通常比直接给定非平衡初值更易收敛，也避免了启动瞬间的人为瞬态。当目标问题本身难以直接求解时，同伦通过连续变形把已知解“搬运”到目标问题，是工程上最可靠的兜底手段。

## 4. 工程做法与参数

- 先看工具报告：初始化前先检查它选定的状态与初始方程列表，判断欠定还是过定。
- 只固定少数关键储能：质量、能量、动量的初始条件通常各固定一个，其余让守恒关系决定。
- 用 `start` 提供合理量级：`start` 值应接近物理量级，可显著改善牛顿收敛。
- 稳态初始化：对长时趋于平衡的系统用 `der(x)=0`，避免启动瞬态；但只对真正平衡的状态施加。
- 同伦兜底：初始化失败时先用 `homotopy` 把表达式在标称值附近平滑，再放开到实际值。
- 分块初始化：大系统先初始化子系统，再逐级组合，定位是哪一块引入冲突。
- 参数扫描起点：做参数扫描时，用上一个工况的收敛解作为下一个工况的初猜，可显著提高成功率。
- 接口一致：耦合系统的界面压力、温度、流量初值要与另一侧一致，必要时用参数的默认值统一。
- 记录日志：保存初始化残差、迭代次数与选定的状态集合，便于复现失败场景。
- 初始方程最少化：只保留必要的初始约束，多余的约束往往是过定的来源。

## 5. 可复现示例

一个带稳态初始化的集总容积，用 `fixed` 指定初始压力，并让它从平衡出发：

```modelica
model TankSteady
  parameter Modelica.Units.SI.Volume V = 0.02;
  parameter Modelica.Units.SI.MassFlowRate m_in = 0.1;
  Modelica.Units.SI.Pressure p(start = 5e5, fixed = true);
  Modelica.Units.SI.MassFlowRate m_out;
  Real rho = 1.2;
equation
  V * rho / 1e5 * der(p) = m_in - m_out;
  m_out = 1e-3 * (p - 1e5);          // 简化的出口阻力
initial equation
  der(p) = 0;                        // 稳态启动
end TankSteady;
```

用同伦改善收敛的写法：

```modelica
  Real rho_eff = homotopy(rho, 1.0);   // 标称值 1.0, 实际值 rho
```

验证：分别用“固定压力 + 稳态初始化”和“仅给 `start`”两种方式启动，比较初值处 $der(p)$ 是否接近零；前者应平稳起步。再把 `m_in` 从 0.1 改为 1.0，观察初始化是否仍收敛，必要时启用同伦。若报告过定，检查是否同时对 `p` 和 `m_out` 施加了约束。

还可以做一个“过定演示”：同时固定 `p` 与 `m_out`，观察工具报出的过定信息，理解约束冲突的形态。理解了报错的语言，诊断效率会大幅提升。这种“最小可复现算例”是排查初始化问题最有效的工具，建议养成随手搭小模型验证的习惯。

## 6. 常见坑与排查

- 过定初始化：同一物理量被多处固定（压力、总质量、各容积压力同时给定），约束冲突。
- 欠定初始化：关键储能状态没有初值，工具找不到自洽起点。
- `start` 当约束：以为写了 `start` 就固定了初值，实际只是初猜，结果偏离预期。
- 盲目 `der(x)=0`：对尚未平衡的状态强行置零，制造矛盾方程。
- 初猜量级差太远：`start` 与真实值差几个数量级，牛顿不收敛却误以为是模型错。
- 离散量未固定：`Boolean` 初值不确定，初始化分支无法确定。
- 接口不一致：耦合两侧对同一界面量的初值互相矛盾，整体初始化失败。
- 同伦参数失配：`homotopy` 的两个表达式量级差太大，路径跟踪仍失败。
- 收敛解未复用：参数扫描每个工况都从默认 `start` 重来，导致边界工况初始化失败。
- 环境参考量不一致：两侧默认大气压或参考温度不同，初始化压力与温度平衡错位。

诊断顺序：查看状态的初始方程列表 → 判断欠定/过定 → 检查 `start` 量级 → 检查 `der(x)=0` 是否合理 → 检查接口一致性 → 启用同伦。

## 7. 检查清单与参考

检查清单：
1. 明确区分 `start`、`fixed` 与 `initial equation` 的角色；
2. 每个需要初始化的状态都有独立且足够的约束；
3. 关键储能状态恰好固定一个初值；
4. 稳态初始化只施加在真正平衡的状态上；
5. 离散模式的初值已显式固定；
6. 耦合界面两侧初值一致，无过约束；
7. 初始化不收敛时使用同伦或分块策略；
8. 记录了初始化残差与选定状态集合；
9. 参数扫描时用上一工况的收敛解作为初猜。
