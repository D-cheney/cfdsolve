# 在这里填写知识文章标题

正文第一段应直接说明问题背景、适用对象和本文结论。建议避免只写概念定义，应说明工程假设与适用边界。

## 1. 问题与物理背景

说明研究对象、控制体、物性假设、初始条件和边界条件。首次出现的符号应给出含义和单位。

## 2. 理论与公式

公式可以使用 LaTeX 线性格式保存，例如：

```text
Re = \frac{\rho U L}{\mu}
```

随后解释每个变量、公式成立条件以及无量纲化或近似过程。

## 3. 数值方法或实施步骤

1. 定义输入与单位；
2. 检查参数范围和物理一致性；
3. 选择离散或求解方法；
4. 检查收敛、守恒和网格敏感性；
5. 与解析解、实验或公开基准比较。

## 4. 示例

提供一个可以复现的输入、计算过程和预期输出。代码块应注明语言：

```python
reynolds = rho * velocity * length / viscosity
```

## 5. 验证与常见错误

- 写明参考解或基准数据来源；
- 给出允许误差和适用版本；
- 区分残差收敛与物理量收敛；
- 提醒单位、符号方向和边界条件错误。

## 6. 参考资料

1. 作者，资料名称，版本或年份。
2. 对于网页资料，填写可长期访问的来源链接和访问日期。
