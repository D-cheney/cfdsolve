# 外流空气动力学：物理建模与适用边界

外流建模的难点不在求解器，而在决定哪些物理可以省略：来流是否可压缩、机翼是否必须按三维处理、边界层在何处转捩、远场截断放在多远。每一项都有可计算的判据，本文把它们换算成具体数字，并说明越界后会出现什么可观测的偏差，便于在建模阶段就确定模型层级。

## 1 什么时候不能再用不可压假设

可压缩性的强弱由马赫数决定，密度变化可由等熵关系估算：

$$
M = \frac{U_\infty}{a_\infty}, \qquad \frac{\rho_0}{\rho} = \left(1+0.2M^{2}\right)^{2.5}
$$

海平面声速 $a_\infty = 340.3\,\mathrm{m/s}$。核算三档：

- $M = 0.3$（$U_\infty = 102\,\mathrm{m/s}$）：$\rho_0/\rho = (1.018)^{2.5} = 1.046$，密度变化 4.6%，不可压求解器仍可用。
- $M = 0.5$（$U_\infty = 170\,\mathrm{m/s}$）：密度变化 14%，已超出 5% 的经验门槛。
- $M = 0.7$（$U_\infty = 238\,\mathrm{m/s}$）：密度变化 29%，必须用可压缩求解器并考虑激波。

## 2 亚声速压缩性对压力的放大

在临界马赫数以下，可用普朗特-格劳厄特修正把不可压压力系数换算到可压：

$$
C_p = \frac{C_{p,0}}{\sqrt{1-M_\infty^{2}}}
$$

修正因子随马赫数迅速增长：$M = 0.3$ 时 $1/\sqrt{0.91} = 1.048$（+4.8%），$M = 0.5$ 时 $1/\sqrt{0.75} = 1.155$（+15.5%），$M = 0.7$ 时 $1/\sqrt{0.51} = 1.400$（+40%）。这说明即使整体不可压，只要局部加速到 $M > 0.3$，翼型上表面的吸力峰就会被低估十几个百分点。对 NACA 0012 这类对称翼型，阻力发散马赫数在 $C_L \approx 0$ 附近约为 0.74，越过它激波阻力急剧上升，任何基于不可压假设的结论都失效。

## 3 三维效应与诱导阻力

有限展弦比机翼的升力线斜率低于二维值，并产生诱导阻力：

$$
a = \frac{a_0}{1+\dfrac{a_0}{\pi\,e\,AR}}, \qquad C_{D,i} = \frac{C_L^{2}}{\pi\,e\,AR}
$$

二维升力线斜率取 $a_0 = 2\pi = 6.28\,\mathrm{rad^{-1}}$，Oswald 效率 $e = 0.85$：

- $AR = 8$：$a = 6.28/(1+6.28/21.36) = 4.85\,\mathrm{rad^{-1}} = 0.085\,\mathrm{deg^{-1}}$
- $AR = 4$：$a = 6.28/(1+6.28/10.68) = 3.95\,\mathrm{rad^{-1}} = 0.069\,\mathrm{deg^{-1}}$

同样的 $C_L = 0.5$，诱导阻力分别是 $C_{D,i} = 0.25/21.36 = 0.0117$（$AR = 8$）与 $0.0234$（$AR = 4$）。若总阻力系数为 $C_D = 0.032$，把 $AR = 4$ 的机翼按二维算，会把诱导阻力当成型阻，$C_D$ 低估 0.023 即 70% 以上。判断方法：只要 $AR < 10$ 且 $C_L > 0.3$，就必须按三维建模或至少施加诱导阻力修正。

## 4 边界层转捩与湍流模型的匹配

低雷诺数翼型（$Re_c$ 在 $10^{5}\sim10^{6}$ 量级）上，层流分离泡与转捩位置直接决定阻力和失速特性。转捩对应的动量厚度雷诺数 $Re_{\theta,t} = \rho U\theta/\mu$ 随来流湍流度 $Tu$ 显著下降，工程上常用的对应关系为：

| $Tu$ | $Re_{\theta,t}$ |
|---|---|
| 0.1% | 约 1070 |
| 1% | 约 530 |
| 3% | 约 210 |
| 6% | 约 165 |

风洞湍流度从 1% 升到 3%，转捩所需的 $Re_\theta$ 下降约 60%，转捩点明显前移，同一翼型在两个风洞里的阻力可以差 20%。平板算例中 $U_\infty = 30\,\mathrm{m/s}$、$x = 0.25\,\mathrm{m}$ 给出 $Re_x = 5\times10^{5}$，对应 $Re_{\theta,t} \approx 510$，与 $Tu \approx 1\%$ 一行吻合，可作为入口湍流度取值的自检。

模型选择的判据：$Re_c > 5\times10^{6}$ 且来流湍流度正常时，全湍流 $k$-$\omega$ SST 足够；$Re_c$ 在 $10^{5}\sim10^{6}$ 且需要准确阻力时，应使用 $\gamma$-$Re_\theta$ 转捩模型或直接做 LES；把全湍流模型套在低雷诺数翼型上，计算阻力通常比实验高 30% 以上。

## 5 远场与近壁的分辨率要求

外流对首层网格的要求与近壁处理绑定。以 $Re_c = 3\times10^{6}$ 为例，估算壁面量并反算首层高度：

```python
import math
rho, nu, U, c = 1.225, 1.5e-5, 50.0, 1.0
Re = U * c / nu
Cf = 0.0592 / Re**0.2          # 湍流平板
tau_w = 0.5 * Cf * rho * U**2  # Pa
u_tau = math.sqrt(tau_w / rho) # m/s
for yplus in (1, 30, 50):
    print(f"y+={yplus:2d}  y1={yplus*nu/u_tau*1e6:6.1f} um")
print(f"Re={Re:.2e}  Cf={Cf:.4f}  tau_w={tau_w:.2f} Pa  u_tau={u_tau:.2f} m/s")
```

输出给出 $y^{+} = 1$ 对应 $y_1 \approx 7.9\,\mu\mathrm{m}$，$y^{+} = 50$ 对应 $395\,\mu\mathrm{m}$。两种策略之间没有中间地带：用壁函数就必须保证首层落在 $30\sim300$，否则改用全解析近壁。远场方面，压力远场或自由来流边界应放在 $20c$ 以上，入口 $5c$、出口 $20c$，否则升力斜率与阻力都会被域截断系统性地拉偏。

## 6 适用边界与失效信号

| 现象 | 根因 | 判定试验 |
|---|---|---|
| 吸力峰 $C_p$ 比实验低 15% | 局部 $M>0.3$ 却用不可压求解 | 计算表面最大马赫数，超 0.3 换可压求解器 |
| 阻力在 $M=0.75$ 附近突增而计算平滑 | 求解器未捕捉激波，或网格过粗 | 加密激波附近网格并检查是否出现 $M$ 数跃变 |
| $AR=4$ 机翼的 $C_D$ 明显偏低 | 按二维处理，漏掉诱导阻力 | 用 $C_{D,i}=C_L^2/(\pi e AR)$ 估算漏掉多少 |
| 低雷诺数翼型阻力高 30% 以上 | 全湍流模型，无转捩 | 换 $\gamma$-$Re_\theta$ 模型，比较转捩位置 |
| 升力斜率对域尺寸敏感 | 远场太近或用了速度入口 | 域扩到 $20c$ 并改压力远场复算 |
| 首层 $y^{+}$ 落在 5～10 | 壁函数与网格不匹配 | 统计 $y^{+}$ 分布，二选一重做近壁策略 |

## 7 建模决策顺序

1. 由 $M_\infty$ 与局部最大马赫数判断是否需要可压缩求解器。
2. 由 $AR$ 与 $C_L$ 判断是否需要三维建模或诱导阻力修正。
3. 由 $Re_c$ 与来流湍流度判断转捩是否重要，据此选湍流模型。
4. 由 $Re_c$ 反算 $y^{+}$ 目标与首层高度，二选一确定近壁策略。
5. 按 $5c$ / $10c$ / $20c$ 布置入口、侧向与出口边界，并记录域尺寸。
6. 把上述五项写入算例说明，后续任何一项改变都重做对应的量级核算。
