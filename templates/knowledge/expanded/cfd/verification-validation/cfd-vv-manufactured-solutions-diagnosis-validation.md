# 制造解与代码验证：结果诊断与可信度验证

制造解方法（Method of Manufactured Solutions, MMS）把"代码有缺陷"这件无法直接观测的事，转写成收敛阶的偏差。只要解析制造场、符号推导的源项和网格序列齐备，观测阶就能把边界重构错误、源项积分错误与格式降阶区分开。本文给出源项的构造方式与两个可直接校核的数值点、五套网格的阶数判读准则，以及阶数异常时的分流试验。需要先划清边界：MMS 只回答离散方程是否被正确求解，不回答物理模型是否合理。

## 制造解的构造与两个校核点

代码验证的目标不是"结果看起来对"，而是让离散误差随网格尺度按名义阶衰减。做法是把解析场 $\phi_m(x,y)$ 代入控制方程，右端项取解析代入后的残差；这样该场就精确满足带源项的方程，数值解与它的差是纯离散误差。对稳态对流扩散方程

$$
\nabla \cdot (\rho \mathbf{u} \phi) - \nabla \cdot (\Gamma \nabla \phi) = S
$$

取 $\rho = 1\ \mathrm{kg/m^3}$、$\mathbf{u} = (1,0)\ \mathrm{m/s}$、$\Gamma = 0.1\ \mathrm{kg/(m\cdot s)}$、$L = 1\ \mathrm{m}$，制造场取 $\phi_m = \sin(\pi x/L)\sin(\pi y/L)$。解析代入后源项是两项之和：

$$
S = \frac{\rho u_0 \pi}{L}\cos\frac{\pi x}{L}\sin\frac{\pi y}{L} + \frac{2\pi^2 \Gamma}{L^2}\sin\frac{\pi x}{L}\sin\frac{\pi y}{L}
$$

在 $(x,y)=(0.25,0.5)\ \mathrm{m}$ 处，第一项为 $1\times3.1416\times0.7071 = 2.2214$，第二项为 $0.1\times19.7392\times0.7071 = 1.3958$，合计 $S = 3.6172\ \mathrm{kg/(m^3\cdot s)}$；在中心点 $(0.5,0.5)$ 处余弦因子为零，只剩 $S = 1.9739\ \mathrm{kg/(m^3\cdot s)}$。这两个数可以直接用作实现的校核点：若求解器输出的源项峰值不等于 1.9739，说明符号推导或单位换算有误。

网格尺度的单元 Péclet 数决定二阶中心格式是否可用，$Pe_h = \rho u_0 h/\Gamma < 2$。代入 $\rho u_0/\Gamma = 10\ \mathrm{m^{-1}}$ 得 $h < 0.2\ \mathrm{m}$；在 $h = 0.125\ \mathrm{m}$ 时 $Pe_h = 1.25$，仍在稳定区。若为了缩短算例把 $\Gamma$ 降到 $0.02$，$Pe_h$ 变为 $6.25$，中心格式出现振荡，此时测到的是格式失稳而非代码缺陷。

## 源项必须来自符号推导

MMS 最常见的自欺做法，是用同一套离散算子作用在制造场上生成源项。这样源项与离散格式严格自洽，数值解在舍入精度内等于制造解，观测阶虚高甚至发散，缺陷被完全掩盖。正确做法是用符号计算得到解析源项，再按单元体积分或单元中心采样赋值，两者之差才是真实离散误差。

```python
import sympy as sp
x, y, L, rho, u0, Gamma = sp.symbols('x y L rho u0 Gamma', positive=True)
phi = sp.sin(sp.pi*x/L)*sp.sin(sp.pi*y/L)
S = rho*u0*sp.diff(phi, x) - Gamma*(sp.diff(phi, x, 2) + sp.diff(phi, y, 2))
Sn = sp.simplify(S.subs({L: 1, rho: 1, u0: 1, Gamma: 0.1}))
print(sp.N(Sn.subs({x: 0.25, y: 0.5})))   # 3.6172
print(sp.N(Sn.subs({x: 0.5,  y: 0.5})))   # 1.9739
```

边界条件同样由制造场给出：四边全部强加 Dirichlet 值 $\phi_m$，不允许出现任何用户自设的零梯度或零通量条件，否则边界误差会伪装成格式降阶。源项赋值方式也要固定，按单元中心采样引入的是 $O(h^2)$ 的源项离散误差，按单元体积分更接近解析值；两种方式混用会让阶数在相邻网格间跳动。

## 五套网格读出观测阶

在单元数 $N$ 上定义体积加权的离散 $L_2$ 误差，再由相邻两级之比计算观测阶：

$$
e_h = \sqrt{\frac{1}{N}\sum_{i=1}^{N}(\phi_{h,i} - \phi_{m,i})^2}, \qquad p = \frac{\ln(e_{2h}/e_h)}{\ln 2}
$$

一次二维稳态验证的结果列于下表，加密比恒为 2，格式名义阶为 2。

| 网格 | 单元数 | $h\ \mathrm{(m)}$ | $L_2$ 误差 | 误差比 | 观测阶 |
|---|---|---|---|---|---|
| G1 | 64 | 0.1250 | $3.20\times10^{-3}$ | — | — |
| G2 | 256 | 0.0625 | $8.00\times10^{-4}$ | 4.00 | 2.00 |
| G3 | 1024 | 0.0313 | $2.00\times10^{-4}$ | 4.00 | 2.00 |
| G4 | 4096 | 0.0156 | $5.00\times10^{-5}$ | 4.00 | 2.00 |
| G5 | 16384 | 0.0078 | $2.50\times10^{-5}$ | 2.00 | 1.00 |

前四级误差比稳定在 4.00，$p = \ln 4.00/\ln 2 = 1.3863/0.6931 = 2.00$，与二阶格式一致，代码通过验证。第五级误差比掉到 2.00，$p = 1.00$，这不是格式降阶，而是截断误差已降到 $2.5\times10^{-5}$ 附近、被舍入与迭代误差接管。此时应检查线性求解器最终残差：若残差只降到 $10^{-8}$，迭代误差本身就与截断误差同量级，必须把残差目标收紧到 $10^{-11}$ 后重算该级。判读准则可以固定下来：$|p - p_{nom}| \le 0.1\,p_{nom}$ 视为通过；$p$ 落在名义阶的 0.5 到 0.9 倍之间通常指向边界或源项实现错误；$p$ 高于名义阶 20% 以上，优先怀疑源项自洽作弊或误差范数取错。

## 边界单元与误差范数是两个失真源

制造解的边界值精确，但边界单元的重构、通量计算与源项积分往往比内部单元低一阶。若全域 $L_2$ 阶偏低而只统计距边界两层以上的内部单元时阶数恢复到 2.00，缺陷就锁定在边界处理上。这个内部子域重算是最快的分流试验，成本仅是重新后处理一次误差范数。

另一类失真来自范数定义。用节点值代替单元平均值，或在非均匀网格上不按体积加权，都会让 $e_h$ 的衰减指数偏离名义阶。范数必须与离散解所在的空间一致：有限体积解是分片常数，用单元体积加权的 $L_2$ 范数；有限元解是分片多项式，用对应的能量范数。瞬态验证还要求制造场含时间，源项里加入时间导数项，漏掉 $\partial \phi_m/\partial t$ 会让稳态阶保持 2.00 而瞬态阶掉到 1.00。判定办法是固定极小 CFL（例如 0.01）单独测时间阶，把空间误差压到可忽略后观察 $p_t$ 是否回到 2.00。

## 失败模式与判定试验

| 现象 | 根因 | 判定试验 |
|---|---|---|
| 全域阶 1.00 而内部子域阶 2.00 | 边界单元重构或边界源项按一阶处理 | 只统计距边界两层以上单元重算阶数，回到 2.00 即定位在边界 |
| 观测阶高于名义阶甚至随加密发散 | 源项由离散算子反算，与格式自洽 | 换成符号解析源项重算，阶数回落到名义阶即证实作弊 |
| 最细网格阶数掉到 0.5 到 1.0 | 截断误差进入舍入与迭代误差区 | 打印 $e_h$ 绝对值与求解器最终残差，确认 $e_h$ 已接近 $10^{-13}$ |
| 稳态阶正确而瞬态阶偏低 | 源项漏掉 $\partial \phi_m/\partial t$ 或时间格式降阶 | 固定 CFL = 0.01 单独做时间阶测试，观察 $p_t$ |
| 阶数随网格单调变化不收敛 | 加密未保持几何相似，或限制器在部分单元激活 | 核对各级 $h$ 比是否恒定，输出限制器激活单元占比 |

## 验证记录与结论边界

一次可复核的记录至少包含：制造场与源项表达式、源项在两个坐标点上的数值、网格序列的 $h$ 与单元数、各级 $L_2$ 误差、观测阶与名义阶的对比、线性求解器残差目标、限制器激活情况，以及内部子域重算的阶数。若某级阶数偏离，还要写明被否定的假设，例如"怀疑边界重构"及其被内部子域试验证实或否定的结果。

制造解验证通过只说明离散方程被正确求解，不检验湍流模型、物性，也不检验边界条件的物理合理性。准确表述是"在该制造场与网格序列下，离散算子实现达到名义二阶"，而不是"模型已验证"。
