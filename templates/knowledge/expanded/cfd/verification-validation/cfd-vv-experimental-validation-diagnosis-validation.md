# 实验对比与确认：结果诊断与可信度验证

确认阶段报出的偏差里，有相当一部分不是模型错，而是比较口径不一致造成的假阳性。同一股流动，热线测的是探针体积内的瞬时值再取时均，CFD 给的是单元体积平均再取时均，两者在强梯度区能差出两位数百分比。本文按空间、时间、参考量三层把口径对齐拆成可执行的检查，给出各层的量化判据，并用一次升力系数对比说明修正口径前后偏差如何变化。
## 空间口径：探针体积与网格单元的尺度差

热线与热膜的测量值是探针敏感体积内的空间平均，而 CFD 输出是单元平均值。两者的尺度差决定了在多大梯度下会显现：

$$
\frac{V_{probe}}{V_{cell}} = \frac{\frac{\pi}{4}d^2 l}{V_{cell}}
$$

以 $d = 50\ \mu\mathrm{m}$、$l = 2.0\ \mathrm{mm}$ 的探针为例，$V_{probe} = 0.7854\times(50\times10^{-6})^2\times2.0\times10^{-3} = 3.93\times10^{-12}\ \mathrm{m^3}$。若 CFD 单元体积为 $1.2\times10^{-9}\ \mathrm{m^3}$，比值达到 306，即 CFD 单元比探针大两个半量级。在速度梯度为 $2.4\ \mathrm{(m/s)/mm}$ 的剪切层里，单元尺度上的空间平均会把峰值削掉，而探针几乎不削。修正办法是在 CFD 中按探针体积做体积平均后再比较，而不是拿单元值直接对齐。

位置对齐同样按梯度换算。实验测量截面标定为 $x/D = 5.0$，安装误差 $\pm 1.0\ \mathrm{mm}$；在 $D = 20\ \mathrm{mm}$ 的模型上这对应 $\Delta(x/D) = 0.05$。若该处横向速度梯度为 $2.4\ \mathrm{(m/s)/mm}$，1.0 mm 的偏移在 $U_\infty = 20.0\ \mathrm{m/s}$ 下造成 2.4 m/s 的偏差，即 12% 的相对偏差。这个量级足以把一次本该通过的确认判成失败，所以截面定位误差必须写进输入不确定度。

## 时间口径：时均统计不确定度与自相关时间

实验的时均值本身带统计不确定度，样本数不够时它会伪装成模型偏差：

$$
u_{stat} = \frac{\sigma}{\sqrt{N_{eff}}}, \qquad N_{eff} = \frac{T}{2\,T_{int}}
$$

$T$ 为采样总时长，$T_{int}$ 为积分时间尺度，$N_{eff}$ 是有效独立样本数。以采样频率 $2\ \mathrm{kHz}$、时长 $T = 30\ \mathrm{s}$ 为例，原始样本 $N = 60000$，但脉动信号存在自相关，$T_{int} = 0.05\ \mathrm{s}$ 时 $N_{eff} = 30/(2\times0.05) = 300$。若脉动标准差 $\sigma = 0.012$，则 $u_{stat} = 0.012/\sqrt{300} = 6.9\times10^{-4}$，相对 $C_L = 0.512$ 仅 0.14%，可以忽略。若把时长缩到 2 s，$N_{eff}$ 降到 20，$u_{stat}$ 升到 $2.7\times10^{-3}$（0.53%），就已进入需要显式计入的量级。

CFD 侧的时均窗口必须与实验一致。一次诊断中，取瞬时流场与实验 30 s 时均比较，出口剖面偏差 8.0%；把 CFD 也做满 30 s 时均后，偏差降到 2.1%。判定试验很简单：固定实验时均窗口，逐步延长 CFD 的统计窗口（5 s、10 s、20 s、30 s），若偏差单调收敛到某个平台，说明之前的偏差含统计未收敛成分；若偏差不收敛，才需要回到模型层追查。

## 实验不确定度的合成与覆盖因子

实验数据不确定度由标定、重复性与参考量三部分按平方和合成，再乘覆盖因子：

$$
U_D = k\sqrt{u_{cal}^2 + u_{rep}^2 + u_{ref}^2}
$$

本例取 $u_{cal} = 0.005$（标定曲线）、$u_{rep} = 0.0045$（同一工况重复 5 次的标准差）、$u_{ref} = 0.006$（来流动压测量），三者均为 $k=1$ 的标准不确定度，合成得 $u_{D,c} = \sqrt{0.005^2 + 0.0045^2 + 0.006^2} = \sqrt{8.125\times10^{-5}} = 0.00901$。取 $k = 2$ 得 $U_D = 0.01803$，相对 $C_L = 0.512$ 为 3.52%。重复性一项若按 5 次样本的标准差除以 $\sqrt{5}$ 得到，则单次测量的重复性区间应取 $2s = 0.009$，两个口径不可混用。

确认判定把数值、输入与数据三项合成后与偏差比较，$|E| \le U_{val}$ 即通过确认，其中 $E = \phi_{cfd} - \phi_{exp}$。本例 $\phi_{cfd} = 0.528$、$\phi_{exp} = 0.512$，偏差 $E = 0.016$。数值项来自 GCI，$U_{num} = 1.56\%\times0.528 = 0.00824$；输入项来自速度与攻角敏感度，$U_{input} = 3.95\%\times0.528 = 0.02086$；数据项 $U_D = 0.01803$。合成得

$$
U_{val} = \sqrt{0.00824^2 + 0.02086^2 + 0.01803^2} = \sqrt{8.281\times10^{-4}} = 0.0288
$$

$|E| = 0.016 < 0.0288$，确认通过，余量为 $U_{val}$ 的 44%。这个余量是健康的，说明偏差落在不确定度带内且不贴边；若余量小于 10%，应先按方差占比找主导项收紧，而不是宣布通过。

## 用剖面与趋势代替单点峰值

单点峰值对位置、网格与采样窗口都极敏感，用它做确认会把口径误差与模型误差混在一起。可靠的比较对象是三类：剖面形状（沿同一坐标线的分布）、积分量（升力、流量、总热流）、以及趋势（偏差随雷诺数、攻角或马赫数的走向）。

趋势比较的判据是：在至少三个工况点上做同一口径的比较，若偏差符号一致且量级随参数单调变化，则属于模型形式偏差，其大小由最差点的 $|E| - U_{val}$ 给出；若偏差符号在不同工况间翻转，则更可能是口径或随机因素，应先回到空间与时间对齐检查。这条判据能把"模型在某区间失效"与"测量在某工况有系统误差"区分开，后者常表现为偏差符号随工况翻转。

```python
import math
# 1) 时间口径：统计不确定度随采样时长的变化
sigma, T_int, CL = 0.012, 0.05, 0.512
for T in (2, 5, 10, 20, 30):
    n_eff = T / (2 * T_int)
    print(f"T={T:2d}s  N_eff={n_eff:5.0f}  u_stat={sigma/math.sqrt(n_eff):.2e}")

# 2) 确认判定
u_cal, u_rep, u_ref = 0.005, 0.0045, 0.006
U_D   = 2 * math.sqrt(u_cal**2 + u_rep**2 + u_ref**2)
U_num = 0.0156 * 0.528
U_in  = 0.0395 * 0.528
U_val = math.sqrt(U_num**2 + U_in**2 + U_D**2)
E     = 0.528 - CL
print(f"U_D={U_D:.5f} U_val={U_val:.5f} E={E:.3f} 余量={abs(U_val-abs(E))/U_val:.0%}")
# U_D=0.01803 U_val=0.02878 E=0.016 余量=44%
```

## 失败模式与判定试验

| 现象 | 根因 | 判定试验 |
|---|---|---|
| 剖面形状一致但整体偏移 8% | CFD 用瞬时值、实验用长时均值 | 把 CFD 统计窗口从 5 s 延到 30 s，偏移收敛即口径问题 |
| 峰值位置差 1 mm 而幅值差 15% | 采样截面 $x/D$ 定位误差落在强梯度区 | 按同一 $x/D$ 重采样并比较剖面，而非只比峰值 |
| CFD 峰值高于实验但积分量一致 | CFD 单元体积远大于探针测量体积 | 在 CFD 中按探针体积做体积平均后重新比较 |
| 偏差随 Re 增大而单调变大 | 模型在某区间失效，或实验出现可压缩效应 | 在三个以上 Re 下同口径比较，看偏差是否单调 |
| 偏差符号随工况翻转 | 测量系统在某工况有系统误差或口径漂移 | 复核该工况的截面定位与来流参考量 |
| 重复性区间与单次偏差同量级 | 样本数不足或含低频漂移 | 延长采样时长并检查 $T_{int}$ 是否随窗口增长 |
| 实验报 1σ 而 CFD 报 95% | 覆盖因子不一致 | 统一到 $k=2$，逐项注明置信水平 |

## 确认结论的写法

结论必须带范围与口径，例如"在 $Re = 3.0\times10^6$、$\alpha = 6.0^\circ$ 下，取 $x/D = 5.0$ 截面的 30 s 时均量，$C_L$ 计算值 0.528 与实验值 0.512 的偏差 0.016 小于合成确认不确定度 0.0288，模型在该工况下通过确认"。不要写成"模型已验证"。外推到未测工况前，先确认新工况的雷诺数与攻角仍在参考数据的覆盖范围内。

记录里还应保留被否决的假设及其证据。本例中"CFD 瞬时值对比实验时均值"这一假设被 5 s 到 30 s 的窗口扫描否定，这项记录能防止后来者重复同一轮无效调参。
