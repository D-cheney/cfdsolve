# 无网格模型验证、标定与可追溯复现

## 1. 区分三类“通过”

| 层次 | 检查内容 | 能说明什么 |
|---|---|---|
| 网站集成 | 文章、分类、搜索、公式、文件链接与视频播放 | 资料正确接入且可访问 |
| 数值实现 | 核求和、内力、非穿透、有限值、守恒与标准算例 | 程序满足被检查的离散关系 |
| 物理确认 | 实测流痕、到达时间、堆积范围与参数不确定性 | 所选模型在指定场景下有何预测能力 |

本页按项目[三维复用模板](/knowledge/meshfree-sph3d-model)整理。当前已有质量与有限值记录、展示视频校核，未提供完整的粒子收敛和现场标定证据。网站验证通过不能升级为工程灾害预测结论。

## 2. 先做小规模实现检查

依照资料包中的 `verify_sph3d.py`，对照独立全对全核求和，检查成对内力总和、三维自由飞行、平床非穿透，以及粒子移动后复用邻居表的正确性。将标准溃坝、静水压力、斜槽和已知宾汉流列为进一步验证任务，明确参考解、误差量和验收条件后再运行。

质量漂移可用：

$$
\epsilon_M(t)=\frac{|M(t)-M(0)|}{M(0)}
$$

本版固定粒子质量，不含沿程侵蚀；质量漂移为零不意味着动量、能量或接触模型同时正确。除了质量，应查看速度、动能、密度偏差、马赫数、地形外框碰撞与邻居表溢出。

## 3. 做分辨率和参数对照

保持源区体积、材料、地形和输出指标一致，改变粒子间距与时间步。对最大流深、传播范围、峰值速度等量分别记录差异；至少形成可判断趋势的多档计算。不能把改变维度、物理方程或源区的两次运行混作收敛结果。

三维等间距减半时，固定体积粒子数约增加八倍，声学时间步还会缩小。先规划计算量，并检查地形误差是否已超过粒子离散误差。摩阻、屈服应力、黏性正则化、声速和源体积也需要敏感性分析；原始滑坡方案进一步要求用材料试验和现场信息约束强度软化。

## 4. 下载与复现步骤

1. 在[专题资料区](/meshfree#downloads)下载 ZIP 或逐个下载文件；用[文件清单](/meshfree/manifest.json)的 SHA-256 校对单文件内容。
2. 保持 `src/`、`config/`、`data/processed/` 的目录关系。资料包含处理后的 DEM、路径和粒子种子；原始 HGT、运行检查点、逐帧大数组不包含在包中。重新提取地形时需按原脚本另行取得原始数据。
3. 在独立 Python 环境按 `config/requirements-sph3d.txt` 准备依赖。原脚本包含原机器的 D 盘路径及 GPU 编号；按所用机器调整配置中的 `output_root`、`gpu_visible_device`，并检查脚本中的依赖目录和后处理输出路径。求解脚本在导入时读取基础 `sph3d.json` 的 GPU 设置，不能只修改 48 万配置。
4. 先运行独立验证和短时试算，再决定是否执行 5400 秒长时程。更改粒子数、物性或地形时使用新运行名；已有检查点只用于相同配置续算。
5. 以新运行的 `summary.json`、实际配置和诊断记录判定完成。资料包内的历史完成证据只属于本页展示的 2026-09-08 算例。

原脚本保留供追溯，本次网站集成没有重新执行耗时的三维 GPU 求解，也不保证其他机器无需环境调整即可运行。详细命令见[三维模板](/knowledge/meshfree-sph3d-model)和[48 万粒子模板](/knowledge/meshfree-cloud-480k)。

## 5. 正确解释回放

八个视频都是同一次计算的不同相机或投影。表面云图采用体积加权重建，俯视采用柱平均速度；相同色标不代表逐点相同的物理采样。示踪点是固定粒子编号的子集，镜头跟随不能代替全域运动距离测量。视频的非均匀时间压缩以画面物理时间为准。
