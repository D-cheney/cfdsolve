# 仿真可视化资源说明

本目录收录 OpenFOAM 与 Modelica 知识库使用的教学可视化。当前 6 张 PNG 均使用 Codex 内置 `imagegen` 生成，分辨率约为 16:9、1672×941。

这些图片用于帮助读者识别物理场、网格结构、系统连接和事件响应，不是由某个可复现实例计算得到的定量结果。文章图题必须保留“教学示意”提示；压力、速度、温度、相分数和时间响应等工程判断应以实际案例、标尺、守恒检查与验证数据为准。
