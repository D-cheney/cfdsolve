# Modelica 与 CFD 特性图、降阶模型耦合

Modelica 擅长系统动态，CFD 擅长局部三维流动。把两者拼起来时，真正的难点不是“怎么连”，而是“降到什么层级还够用”。降阶过度会丢失主导瞬态，降阶不足则让仿真慢到无法接受。本文按成本从低到高梳理耦合层级，给出接口变量、守恒与时间尺度的工程做法，并用可复现示例说明如何验证域外行为与误差预算。

## 1. 结论与适用场景

先估目标精度，再选能满足它的最低成本层级。系统级仿真通常关注流量、压降、温升与效率，很少需要逐时三维场；把 CFD 的网格与时间步直接搬进系统模型，往往带来百倍成本却换不来决策所需的精度。

- 常数或经验关联式：适合工况窄、机理清楚的部件，成本最低，误差可控，也最容易在系统级反复迭代。
- 稳态特性图/响应面：适合设备压降、效率、换热随流量与转速的变化，离线 CFD 扫掠即可生成，是工程中最常用的耦合形式。
- 动态状态空间或其他 ROM：当瞬态（喘振、热惯性、充排）主导时使用，保留主要状态与时滞，误差随模态数下降。
- FMU 联合仿真：当该部件已有独立动态模型、需要封装复用时使用，成本与稳定性要求上升。
- 在线 CFD：仅用于无法离线降阶的强三维瞬态，成本最高，通常只在标定或极端工况下使用。

判据是时间尺度比：若部件内部时间常数远小于系统关注尺度，可当准稳态特性图；若两者同量级，必须用动态 ROM 或联合仿真，否则会错过耦合振荡。对同一部件，也应随设计阶段调整层级：概念设计用关联式，详细设计用特性图，验证阶段才引入动态 ROM。

成本也需要量化理解。一次三维 CFD 稳态工况可能是分钟到小时量级，而系统级准稳态特性图查询是微秒量级；这意味着在参数扫描、控制器整定或实时应用中，特性图几乎是唯一可行选择。反过来，若某部件的瞬态直接决定系统稳定性（例如喘振与管路声学共振），用准稳态图会让模型失去预测能力，此时多花的 CFD 成本是必要投入。

## 2. 原理与协议/语义

特性图把 CFD 结果投影成低维映射：输入是流量、转速、温度、压力等运行变量，输出是压降、效率、换热量。响应面在此之上做平滑拟合，降低 CFD 噪声，但也可能抹平真实的陡峭变化，因此拟合优度必须用独立数据检验。状态空间 ROM 用少量状态描述瞬态记忆，本质是“用低维动力学逼近高维流场”。

降阶的数学起点是快照（snapshot）方法：对若干工况求解全阶 CFD，得到快照矩阵 $X$，用奇异值分解提取主导模态 $\Phi$，把高维状态 $x$ 近似为低维坐标 $a$ 的线性组合，再对原始方程做伽辽金投影。这样得到的 ROM 在训练工况附近精度高，但离开采样范围会迅速退化，因此采样设计几乎决定 ROM 的成败。

从守恒角度看，ROM 与特性图本质上都只是“拟合”，自身不保证守恒。因此接口层必须显式加上质量与能量的闭合关系：进入部件的流量、烩流与离开的必须相等，压降与功率必须与图给出的关系一致。若图与守恒方程冲突，应优先相信守恒方程，把图当作确定自由度的本构关系。

接口语义是耦合成败的关键。要统一：表压还是绝压、总参数还是静参数、质量流量方向（建议统一流入为正）、焓还是温度、参考状态与单位。压力—流量接口要避免双方同时强制同一变量，否则连接集合过定而无法求解。能量耦合则要传递守恒的焓流或热流，而不能只传温度，否则两侧的流量变化无法体现到能量平衡中。

## 3. 关键公式与接口

二维特性图仍用双线性插值，权重

$$ \alpha = \frac{\dot m - \dot m_i}{\dot m_{i+1}-\dot m_i}, \qquad \beta = \frac{n - n_j}{n_{j+1}-n_j} $$

输出（例如压比）为

$$ \Pi(\dot m, n) = (1-\alpha)(1-\beta)\Pi_{ij} + \alpha(1-\beta)\Pi_{i+1,j} + (1-\alpha)\beta\Pi_{i,j+1} + \alpha\beta\Pi_{i+1,j+1} $$

状态空间降阶把全阶解近似为平均场加主导模态：

$$ x(t) \approx \bar{x} + \Phi\,a(t), \qquad \dot{a} = \Phi^{\top} R(\bar{x} + \Phi a) $$

其中 $R$ 是全阶残量，投影后维数由保留的模态数决定。模态数越多精度越高、成本越大，工程上常取能量占比达 99% 的截断。

时间尺度比刻画能否用准稳态替代动态：

$$ S = \frac{\tau_{ROM}}{\tau_{system}} $$

当 $S \ll 1$ 时部件响应远快于系统，可用准稳态图；当 $S \gtrsim 1$ 时必须保留瞬态，否则会漏掉耦合振荡。耦合回路的稳定性还取决于压力—流量增益

$$ K = \Bigl\lvert \frac{\partial \dot m}{\partial p} \Bigr\rvert \, R_{system} $$

$K$ 越大，显式交换越易振荡，需减小通信步长或迭代求解。可以把它理解为：当流量对压力极敏感、而系统阻力又较小时，微小的压力扰动会被放大成流量波动，再反作用于压力，形成自激。

此外，插值误差在特征图上的分布并不均匀：在等值线密集处（效率峰值、喘振边界附近）误差最大，因此评价 ROM 精度应看误差的空间分布，而不只是平均误差。一个整体平均误差很小的图，可能在关键工作点附近误差很大，导致系统模型在该点给出错误结论。

## 4. 工程做法与参数

- 采样设计：用全因子或拉丁超立方覆盖预计工况，在梯度大、转捩、失速边界处加密；记录每次 CFD 的网格、湍流模型与收敛残差，使降阶误差可追溯。
- 数据划分：训练、验证、独立测试三集分开，禁止在测试集上拟合，防止“泄漏”造成虚高精度；测试集应包含至少一个边界工况。
- 平滑与守恒：对图做适度平滑以抑制 CFD 噪声，但能量耦合应传递守恒的焓流或热流而非仅传温度；接口两侧要逐时刻校核总质量与总能量。
- 外推策略：对超出采样范围的查询，报警或切换回经验关联式，不允许静默线性外推；外推区域应有显式标记。
- 通信步长：联合仿真步长应小于 ROM 时滞对应的最快时间常数，并做敏感性扫描，确认关键轨迹不随步长变化。
- 误差预算：把 CFD 离散误差、降阶误差、插值误差与耦合误差分别记录，明确哪一项主导，才能决定是先加密 CFD 还是先增加模态。
- 模态截断：用能量占比或交叉验证选择模态数，保留过多会拖慢仿真、过少会丢瞬态，应画出误差随模态数的收敛曲线。
- 在线修正：对长期漂移，可在系统仿真中周期性用少量 CFD 或高保真数据校正 ROM 参数，兼顾成本与精度。

## 5. 可复现示例

用 `CombiTable2D` 表达一个压气机压比特性图，并以压力—流量接口与系统相连：

```modelica
model CompressorMap "压比随质量流量与转速变化"
  Modelica.Blocks.Tables.CombiTable2D map(
    tableOnFile = true,
    tableName = "PR",
    fileName = "modelica://Pkg/Resources/Data/compressor_map.txt",
    smoothness = Modelica.Blocks.Types.Smoothness.ContinuousDerivative)
    annotation(choicesAllMatching = true);
  Modelica.Units.SI.MassFlowRate m_flow;
  Modelica.Units.SI.AngularVelocity n;
  Real PR;
equation
  map.u1 = m_flow;          // 表内列顺序: 流量
  map.u2 = n;               // 转速
  PR = map.y;
end CompressorMap;
```

用脚本检查数据范围并回放域外行为：

```bash
# 表头与范围
head -n 5 Resources/Data/compressor_map.txt
python - <<'PY'
import numpy as np
d = np.loadtxt("Resources/Data/compressor_map.txt")
print("m_flow range:", d[:,0].min(), d[:,0].max())
print("n range:", d[:,1].min(), d[:,1].max())
PY
```

验证：在训练工况内回放对比 CFD 与 ROM，误差应随采样加密而下降并趋于收敛；把查询点故意推到范围外，模型必须报警或切换到备用关联式，而不是返回非物理解。再改变通信步长，观察关键轨迹是否对步长敏感，以便确定可接受的时间步。若条件允许，再把 ROM 预测与一次未见工况的 CFD 结果并排画图，检查误差是否集中在特定区域，而不是均匀分布。

## 6. 常见坑与排查

- 过约束：系统模型与特性图双方都强制压力，连接集合过定；应一端用压力、一端用流量。
- 静/总参混用：把总压当静压传入，效率与压比出现系统性偏差。
- 外推非物理：范围外线性外推得到负流量或负温度；加范围检查与报警。
- 训练/测试泄漏：用全部数据拟合再自评，精度虚高；严格三集划分。
- 忽略不确定度：只报单一曲线，不报 CFD 离散与模型误差带，导致下游盲目信任。
- 步长过大：通信步长大于 ROM 时滞，出现相位滞后或振荡。
- 单位与参考态：焓的零点与压力参考态不一致，能量对不上。
- 静态图掩盖瞬态：充排或喘振工况用准稳态图，结果失真。
- 模态过少：只图快而截断过度，丢失低频振荡，表现为结果过于平滑、缺少物理波动。
- 未复核守恒：图和接口各自合理，但合起来的质量或能量不闭合；应逐时刻校核总体守恒量。

诊断顺序：接口语义与过约束 → 单位与参考态 → 采样范围与外推 → 数据划分 → 通信步长 → 误差预算。

## 7. 检查清单与参考

检查清单：
1. 已选满足精度要求的最低成本层级，并记录理由；
2. 训练、验证、测试三集独立；
3. 采样范围覆盖预计工况并在强非线性区加密；
4. 接口压力量、流量方向、焓/温度与参考态统一；
5. 压力—流量接口无过约束；
6. 外推有明确策略与报警；
7. 通信步长做过敏感性分析；
8. 记录了 CFD 网格、物理模型与数值不确定度；
9. 模态数或表分辨率有基于误差收敛的选择依据；
10. 逐时刻校核了接口的总质量与总能量闭合。
