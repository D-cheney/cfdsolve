# 参数扫描与工况对比实验室

## 1. 功能定位

`/simulation/lab` 把单次求解扩展为可重复的工程实验。用户选择基础求解器、扫描变量、取值范围、线性或对数步进和对比指标后，网站依次执行多个工况，集中展示趋势曲线、逐工况摘要、警告和可信度清单。

该功能参考了主流云仿真平台把多个参数值组织为 Experiment、分别执行 run、在同一图表比较结果的工作流。验证框架则采用“验证、确认和不确定性量化应显式记录证据”的工程原则。当前评分是工作流提示，不是认证结论。

参考资料：

- [SimScale：Parametric Studies](https://www.simscale.com/knowledge-base/how-to-run-parametric-studies-in-simscale/)
- [SimScale 文档：前处理、求解、后处理与验证](https://www.simscale.com/docs/)
- [NASA：Verification, Validation, and Uncertainty Quantification](https://ntrs.nasa.gov/api/citations/20260001729/downloads/NASA-TM-20260001729.pdf)

## 2. 支持范围

| 基础工具 | 可扫描变量 | 可比较指标 | 单批上限 |
|---|---|---|---|
| 一维对流—扩散 | 速度、扩散系数、网格数 | Péclet 数、L₂/L∞ 误差 | 20 |
| 圆管充分发展层流 | 平均速度、管径、动力黏度 | Re、流量、压降、摩阻系数 | 20 |
| 湍流与近壁参数 | 速度、湍流强度、目标 y⁺ | Re、首层高度、k、ω | 20 |
| 方腔顶盖驱动流 | Re、顶盖速度、x 网格数 | 迭代数、最终残差、主涡位置 | 5 |

方腔工况通过 Web Worker 执行，避免批量计算冻结界面；其余轻量解析或一维计算在浏览器中分批执行，并在工况间主动让出事件循环。

## 3. 可信度清单

每个成功工况都会生成五项检查：

1. 输入与单位：输入必须为有限数并按当前 SI 单位解释；
2. 数值收敛：求解器必须报告收敛，输出序列不能包含非有限值；
3. 模型适用性：例如层流圆管要求 Re 小于常用层流阈值，中心差分检查单元 Péclet 数；
4. 参考解校核：有解析解时记录误差，没有独立实验数据时明确提示；
5. 可复现性：参数快照、求解器标识与完整采样轴必须能随结果导出。

评分规则为：通过不扣分、警告扣 9 分、失败扣 28 分，并映射为 A–D 等级。评分只帮助发现缺失证据；关键设计结论仍应使用网格无关性研究、独立实验或经过验证的生产求解器复核。

## 4. 数据保存与导出

整批实验作为 `parameter-sweep` 仿真任务保存，包含基础参数、扫描设置、逐工况结果和可信度清单。数据库在线时通过工作区 API 写入 SQLite；数据库不可用时保存在浏览器本地缓存。页面支持：

- CSV：用于电子表格和二次绘图；
- JSON：包含配置、参数快照、全部工况、警告与检查清单；
- 历史回看：重新进入实验室可打开最近批次。

## 5. 已知边界

- 当前是一维/二维教学求解器和工程关联式的实验编排层，不等同于商业 CFD 求解平台；
- 当前每批只扫描一个变量，不执行多变量全因子或优化算法；
- 可信度清单不自动完成网格收敛指数 GCI、实验不确定度传播或模型校准；
- 浏览器关闭前应等待任务完成，运行中的批次不支持跨会话恢复。
