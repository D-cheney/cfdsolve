# CFD菜鸟二维建模使用说明

二维建模工作区位于“CFD 仿真”页面的建模入口。页面会自动恢复浏览器中最近一次保存的模型；顶部状态显示“已保存至本机”时，当前修订已经写入 IndexedDB。项目按钮下载可移交的 `.cfd2d.json` 文件。

## 绘图与视图

- 使用点、直线、连续线、矩形、圆、圆弧、椭圆、多边形、槽形和样条工具后，在画布上依提示单击。
- 连续线和样条用 Enter 结束，单击起点可闭合；Backspace 删除最后一个待提交点，Esc 取消当前操作。
- 滚轮缩放，中键或按住空格拖动平移；“适合窗口”会显示全部对象。
- V、L、P、R、C、A、T、O、D、F 分别对应选择、直线、连续线、矩形、圆、圆弧、修剪、偏移、测量和适合窗口。

## 选择与精确修改

- 单击对象或模型树条目选择，Shift 单击多选；从左向右框选要求对象完全位于框内，从右向左框选会选择相交对象。
- 选中对象后可拖动。右侧属性面板可编辑名称、基准坐标、矩形宽高、圆或圆弧半径、多边形边数，并可切换构造几何和编辑锁定。
- 删除、移动、旋转、镜像、偏移和属性修改都进入撤销历史。Ctrl/Cmd+Z 撤销，Ctrl/Cmd+Shift+Z 重做。

## 约束、区域与检查

- 水平、竖直和长度适用于一条直线；平行、垂直、等长适用于两条直线；半径适用于圆或圆弧；固定适用于单个对象。
- “尺寸 mm”是新增长度或半径约束的驱动值。重复或不适用的约束会被拒绝并显示原因。
- 打开自动约束后，新建的水平或竖直直线会保存对应的持续约束。
- 选择一个或多个闭合轮廓后使用“生成区域”。相互独立的轮廓生成独立区域；包含层级按外边界、孔洞和内部岛组织，树中显示每个区域的净面积。
- 检查面板列出零长度、无效尺寸、重复对象和自交等问题；单击问题可定位相关对象。

## 文件交换

- “打开”支持 `.cfd2d.json`、ASCII `.dxf` 和 `.svg`；文件不得超过 50 MiB，项目文件不得超过 20,000 个对象。
- DXF 支持 POINT、LINE、CIRCLE、ARC、ELLIPSE 和 LWPOLYLINE；SVG 支持 line、rect、circle、ellipse、polyline、polygon 及仅含 M/L/H/V/Z 命令的 path。
- 导入失败不会替换当前模型。带 bulge 的 DXF 多段线、SVG 变换或尚未支持的 path 曲线会给出提示，需人工核对。
- “项目”“DXF”“SVG”分别导出完整项目、基础 CAD 交换文件和可查看的矢量文件。构造对象不会进入 DXF/SVG 几何导出。

## 手机操作

手机进入工作区时左右面板默认收起，画布保留完整宽度。画布两侧按钮可按需打开模型树或属性面板；顶部工具带可水平滑动。
