# CFD菜鸟｜二维网格划分与命名完整开发计划

编制日期：2026-09-22。依据当前工作区代码检查编制。

本文定义一次完整交付的网格模块，所有必需功能、接口、测试与文档一起完成后验收，不拆分功能交付阶段。本文是开发计划，不代表下面的功能已经实现。

## 1. 完成后用户能做什么

用户完成二维建模后，直接进入“网格划分”，在同一工作区选择计算面域、命名边界和面域、设置网格方法与尺寸、添加局部加密和边界层、生成真实网格、检查质量，最后保存或导出带完整命名的网格。

默认使用路径：

**当前模型 → 选择计算面域 → 边界与面域命名 → 网格设置 → 生成与检查 → 保存／导出／进入边界设置。**

这是软件中的使用路径，不是开发阶段。命名与网格设置可以来回修改，命名也可以在网格生成后完成，不需要重新划分网格。

本次范围限定为二维平面网格及其交接。包含三角形网格、四边形占优混合网格、适用区域的映射四边形网格、局部加密、二维边界层、共形多面域接口和命名。三维体网格、任意复杂区域自动全四边形分块、滑移网格、非共形接口插值、新流体求解器不在本次范围。

边界名称如“入口”“出口”“壁面”用于组织几何和网格；具体速度、压力、温度和壁面模型仍在后续“边界设置”中指定。面域允许标记“流体”“固体”“待指定”，仅作为区域语义，不在此输入材料物性。

## 3. 工作区布局与操作

采用全宽工程工作区，延续现有白色、灰色和淡蓝色。网格使用页面不增加背景动画。

| 区域 | 内容与交互 |
|---|---|
| 顶部 | 工程名、源模型状态、保存状态；返回建模、保存、撤销、重做、生成、取消、导出 |
| 左侧树 | 计算面域、边界命名、面域命名、接口、局部尺寸、边界层、网格结果；显示数量、状态、显隐与定位 |
| 中央画布 | 原几何、计算面域填色、边界颜色、尺寸预览、真实网格、质量着色；支持缩放、平移、框选、适合窗口 |
| 右侧面板 | 根据当前对象显示命名、尺寸、网格方法、边界层或质量参数，不堆叠全部表单 |
| 底部 | 当前命令提示、坐标和单位、选择类型、节点与单元总数、未命名数量、任务状态 |

选择过滤器至少包含边、面域、网格节点、网格单元和命名集合。命名时默认选择几何边或面域，不能因为点击了网格线而误改集合。

必须支持单击、Shift 多选、框选、反选、清空选择、隐藏其他对象、按名称搜索、点击列表定位。重合位置提供候选对象切换；点击面域高亮整块区域，孔洞内部不能被选成该区域。

右键菜单包含命名、加入已有命名、从集合移除、设置局部尺寸、添加边界层和查看属性。常用命令同时有可见按钮，手机无需右键。

手机默认收起两侧面板，使用单个底部抽屉编辑，画布支持双指缩放和平移，选择使用单击。功能按钮不得小于 44 CSS px，禁止左右面板同时遮盖画布。大网格使用显示抽样但保留完整计算数据和准确总数，界面明确“当前显示抽样”。

## 4. 几何交接与可网格化拓扑

进入网格时读取当前文档的实体、区域和分组，不重新建立默认矩形。首次进入可直接选择有效封闭轮廓形成计算面域；已有有效区域作为候选导入。开放线链只参与边界构建或显式内部约束，不能单独形成面积。

交接对象必须包含：源文档 ID、快照 ID、几何内容指纹、单位、顶点、可引用曲线、闭环、面域、孔洞、来源关系和诊断。

具体规则：

1. 从真实参数重建点、直线、圆、圆弧、椭圆、矩形、多边形和槽形；面域内外环来自曲线，不来自画布像素或面积大小猜测。
2. 矩形暴露四条独立边；多边形和折线暴露各段；槽形暴露两条直线和两段圆弧。每条子边有稳定 ID 和源实体引用。
3. 圆或其他整条曲线允许在命名工作区按参数或几何点分段，例如把圆周上半部分与下半部分分别命名。分段作为网格准备特征保存，不破坏源草图。
4. 源数据没有显式边 ID 的点列，首次交接分配持久子边 UUID；后续通过端点关系、源实体和参数区间追踪，不把当前数组序号直接用作永久 ID。
5. 默认几何容差为 `ε = max(10^-6 mm, 10^-9 × D)`，D 为模型包围盒对角线。显示当前容差，允许用户调整；端点合并必须预览变化后确认，不能自动填补真实窄缝。
6. 检查开口、自交、重复边、零长度、孔洞越界、孔洞接触外边界、区域重叠、非流形连接和悬空引用。错误定位到边或面域；失败不清空建模数据。
7. 相邻面域建立共享几何边与共形网格。发生 T 形连接时在交点处分割共享边，并将分段追踪回原对象。
8. 相互重叠的面域必须先显示重叠区并完成明确的划分／归属选择，不能重复铺两层网格。纯点接触面域默认按独立连通分量处理，不允许通过一个点暗中形成流动通道。
9. 构造几何默认不参与计算域；可显式选为内部加密约束线。显示隐藏状态不等于从计算中排除；参与计算由独立的“参与划分”开关控制。
10. 进入网格后修改建模，应比较几何指纹。几何变化使结果过期；单纯重命名、显隐和视图变化不使网格失效。撤销回到相同几何内容可重新匹配旧结果，不仅比较修订号。

为映射网格提供“网格分块”工具：用户用直线或已有曲线分割选定面域，选择四个逻辑角和四条边链。派生分块保留原面域归属，分块线默认仅作网格内部连接，不自动生成物理接口名称。

## 5. 边界命名：网格板块的必需功能

边界命名对象是面域边界上的一条或多条几何边，网格生成后映射为边界线单元／单元面。命名覆盖不依赖当前网格节点序号。

### 5.1 必须完成的操作

- 单边、整条相连边链、多边批量命名；同一集合可以包含多段不相连边。
- 新建、重命名、加入、移除、拆分集合、合并集合、删除集合、显隐和定位。
- 集合显示名称、颜色、边数、几何长度、网格边数、关联面域和完整／未命名／冲突状态。
- 中文显示名和稳定导出名分开，如“入口”与 `inlet`。导出名按 `[A-Za-z_][A-Za-z0-9_]*` 校验；冲突提供候选名，不静默覆盖。
- 建议语义为入口、出口、壁面、对称、远场、周期配对、接口或自定义；该语义不直接设置物理方程和数值。
- 选择“剩余边界统一命名”时预览剩余边数和总长度，再生成例如 `walls` 的集合。
- 支持按面域筛选外边界、孔洞边界和接口，避免圆孔边漏命名。
- 支持命名后重新划分、加密或改变边界层，名称继续映射到相同几何边。

### 5.2 归属规则

同一侧物理边界必须且只能归属于一个用于求解／导出的边界集合；辅助选择集可以重叠，但与物理命名集合区分。重复归属显示冲突并要求用户选择合并、移动或取消。

共形内部接口用同一条几何边及其两侧面域引用表示。接口保存一对侧引用和配对 ID，面域 A、B 的外法向相反；不能创建两条位置相同而节点编号不同的“假共享边”。网格内部普通分块边不计入外边界覆盖率。

周期命名提供 master/slave、平移或平面旋转变换、反向预览和节点对应表。要求几何可配对、离散节点一一对应；不匹配时阻止标记为有效周期对。本次不实现周期物理求解。

允许未完成命名时试划网格；“检查并接受”“导出求解网格”和“进入边界设置”前必须通过覆盖与冲突检查。不能把未命名边自动当作壁面而不告知用户。

## 6. 面域命名：与边界命名并列管理

面域名称绑定真实二维区域，不绑定用于绘图的颜色，也不绑定包围盒。

- 单面域命名，多面域加入同一单元区域集合，支持拆分、合并、批量修改和定位。
- 一个几何面域可以属于“流体区”这一集合，包含孔洞；孔洞本身不是单元区域。
- 不相连的两块流体区域可以属于同一集合，但仍保留各自连通分量和原面域 ID。
- 每个参与计算的二维单元必须有且只有一个主面域集合 ID，允许另外添加不参与物理归属的辅助集合。
- 显示面域面积、孔洞数量、连通分量、节点数、单元数、网格方法和质量摘要。
- “流体／固体／待指定”只是区域标记。相邻流固面域建立可配对接口；材料参数和耦合物理留在后续模块。
- 面域删除、取消参与或几何重建后，给出受影响的边界命名、加密规则、边界层和旧网格，不静默转移单元归属。

命名空间按边界／面域／接口分开管理，导出包提供显式命名映射表。名称可变，集合 ID 不变，后续条件引用集合 ID。

## 7. 网格方法和适用范围

全部方法在同一次交付内可用；前端根据几何条件显示可用性和限制原因。

| 方法 | 适用输入 | 输出与约束 |
|---|---|---|
| 自动三角形，默认 | 凹多边形、圆弧边界、圆孔、多孔、狭长区域、多面域 | 一阶三角形；真实边界约束、孔洞留空、共享边节点一致 |
| 四边形占优 | 一般有效面域 | 四边形与三角形混合，显示实际比例；不得宣传为全四边形 |
| 映射四边形 | 无孔、可映射为四条逻辑边的区域；或用户完成分块的区域 | 全四边形；用户指定角点与边链，对边分段数必须兼容，Jacobian 必须有效 |
| 边界层混合网格 | 选定面域的一侧壁面／孔洞边界 | 近壁四边形层与外部三角形／混合单元；拐角允许显式报告的过渡单元 |

不承诺任意多孔区域一键全四边形。用户选择映射方法但条件不成立时，保持原设置并说明如何分块或切换方法，禁止静默换算法。

只生成一阶直边网格单元。几何仍可为精确圆弧和椭圆，离散边界以弦长误差控制逼近。高阶曲边网格不在本次交付范围，界面不能把直边网格标为高阶。

## 8. 全局尺寸、局部加密与边界层

### 8.1 尺寸设置

全局设置：目标尺寸 h、最小与最大尺寸、过渡增长率、曲率弦差、每周最少分段数、窄缝最少单元层数、网格方法和可重复生成参数。

默认建议值根据区域尺度生成，但必须标注为建议值并允许修改。输入字段显示单位，内部长度统一使用 mm；所有送入内核的几何和尺寸使用同一单位，不能只换标签。

局部规则覆盖：指定边的目标长度／精确分段数、边的单向或双向偏置、指定面域目标尺寸、点附近半径加密、框／圆形区域加密、到指定边的距离加密，以及沿用户方向定义的尾迹带。

规则必须可以添加、启用、禁用、重命名、复制、删除和定位，能在画布预览实际作用范围。重叠的软尺寸场取更小目标尺寸；精确分段数、周期配对、映射对边等属于硬约束，冲突必须报告，不能悄悄忽略。

曲率细分检查弦差；狭缝检查间距与局部尺寸。目标无法在设定最小尺寸和单元上限内满足时，给出冲突位置与调整建议，不能让单元跨过孔洞或缝隙。

### 8.2 边界层

边界层以“边界集合 + 面域侧”为对象，支持首层厚度 t1、层数 N、增长率 r、总厚度 T、切向尺寸、拐角策略和窄缝处理。首层厚度、层数、增长率驱动时，总厚度为只读计算值：

`T = t1 × (r^N − 1) / (r − 1)`；`r = 1` 时 `T = N × t1`。

支持切换为总厚度驱动，明确哪个字段变为派生值，不允许四个字段互相矛盾。必须由独立测量验证实际生成层数和法向厚度，不能只显示输入值。

点击集合时显示生长箭头；孔洞边向外侧流体区域生长，外壁向域内生长，内部接口按选定的一侧生成。两侧需要边界层时分别建规则。

默认遇到碰撞或过薄间隙时停止并定位。用户可以显式选择局部减层或限制厚度，预览受影响位置；实际层数少于要求时记录在质量报告，不能悄悄关闭整组边界层。

规则参数 r 默认 1.2，建议范围 1.0–1.3；这是产品默认值，不是所有 CFD 工况的通用合格标准。不根据网格几何直接声称满足某个 y+；当前没有流场与摩擦速度数据。

## 9. 采用的技术方案与运行条件

前端沿用 Nuxt、Vue、Pinia、TypeScript。网格生成采用服务端 Gmsh Python 适配器，通过当前 Nuxt 服务的同源接口调用，每个任务使用独立进程。当前本地站点调用本机进程；部署网站时计算进程必须部署到网站服务器，用户手机只负责交互和查看，不安装 Python。

采用 **Gmsh 4.15.2** 作为初始固定验证版本，Python 运行时与平台依赖一起锁定并提供安装检查。官方接口具备二维网格、物理分组、映射控制、边界层尺寸场和质量测量入口；这些只是实现依据，产品能力以固定样例集成测试为准。[Gmsh 官方手册](https://gmsh.info/doc/texinfo/)

实施职责：

- 几何适配器：从建模 JSON 生成内核曲线／面域、来源 ID 映射和共享拓扑。优先在同一内核表示内完成建模与网格，避免跨内核转换丢失来源。
- 网格适配器：全局与局部尺寸、分段控制、映射、混合网格、二维边界层、周期节点配对。
- 结果适配器：提取完整节点和连接关系、单元类型、区域／边界标记，重建面邻接并独立检查。
- 服务层：校验请求、任务队列、取消、超时、结果缓存和日志；不在 Nuxt 请求主线程中执行网格算法。
- 前端 Worker：结果解码、质量分布和空间索引等 CPU 工作。原生 Gmsh 放在独立进程，不能把它描述为已可直接运行于浏览器的 Worker。
- 渲染：Canvas/WebGL 批量绘制网格，SVG/HTML 仅用于少量标签和控件；禁止每个网格单元生成一个 DOM 节点。

必须交付 Windows 本地启动与 Linux Node 部署的可复现配置；依赖由项目脚本管理，不使用开发工具私人运行时路径。没有原生进程能力的纯静态或受限无服务器托管不支持本方案，部署文档明确此要求。

安装脚本核验下载来源、固定版本和校验和，保存第三方许可证与分发说明。Gmsh 的许可证文件应随打包运行时提供，不能把依赖当作无许可二进制复制。[Gmsh 官方发布说明](https://www.gmsh.info/)

## 10. 数据契约与版本规则

新增独立网格工程 `MeshProject`，不将全部网格节点塞进现有建模实体数组。最小必需结构如下，开发时落实为 TypeScript 类型、运行时校验器与格式版本。

| 对象 | 必需字段／内容 |
|---|---|
| `SourceGeometry` | documentId、snapshotId、sourceRevision、geometryHash、lengthUnit、选中面域、曲线参数和几何快照 |
| `TopologyEdge` | 稳定 ID、起终顶点、曲线及参数区间、方向、源实体／子边引用、所属环与两侧面域 |
| `TopologyFace` | 稳定 ID、外环、孔洞环、连通分量、源区域引用、参与计算标记 |
| `BoundarySet` | UUID、显示名、导出名、语义、颜色、带侧引用的边列表、验证状态 |
| `CellZone` | UUID、显示名、导出名、角色、面域引用、验证状态 |
| `InterfacePair` | UUID、类型、两侧引用、变换、方向、共享或配对节点映射 |
| `MeshControl` | UUID、类型、几何目标、值与单位、硬／软约束、启用状态 |
| `LayerControl` | UUID、边界集合及面域侧、驱动方式、t1/N/r/T、碰撞策略 |
| `MeshResult` | resultId、几何及设置指纹、算法版本、完整节点、单元、面邻接、命名映射、质量、生成日志 |
| `MeshProject` | format/schemaVersion、UUID、源快照、命名版本、全部设置、当前结果引用、缓存索引、视图和保存信息 |

运行时存储约定：

- 节点坐标：Float64；面域内连接和几何坐标统一 XY、右手系；二维网格文件的 Z=0。
- 三角形／四边形连接：Uint32 索引、逆时针顺序；节点 ID 与数组下标区分。所有外部稀疏编号导入后有显式映射。
- 每个单元有原面域 ID 和主 CellZone ID；每条网格面有端点、owner 单元、可选 neighbour、几何边来源、外法向和命名 ID。
- 外边界只有 owner；内部面有两个邻居。共享接口只存一个拓扑面，通过两侧引用生成相反外法向。
- 单元面积、质心、面长、法向来自真实连接关系；导出为米时坐标乘 10^-3，面积乘 10^-6，不能重复转换。

指纹分别管理：geometryHash、meshSettingsHash、namingHash、meshFingerprint。改名只更新命名映射和出口状态；尺寸／方法／边界层变化使结果过期；几何变化同时触发引用重绑定和网格过期。

几何边一对多分裂时，可验证覆盖完整原区间后继承命名；多对一合并且来源名称不同、来源消失或匹配不唯一时标记“待确认”，不按最接近位置猜测。后续边界条件继续按集合 UUID 关联；集合被删则条件失效并提示。

## 11. 任务、保存与异常恢复

生成任务状态：空闲、排队、准备几何、计算中、质量检查、成功、失败、取消、结果过期。内核没有连续进度时显示工作状态与已用时间，不用定时器伪造百分比。

每个任务固定请求快照、jobId、几何指纹和设置指纹。任务运行期间可以查看并编辑其他设置，但回来的结果只有与当前快照匹配才成为当前结果；旧请求响应保留为历史，不覆盖新设置。

取消通过服务端终止对应隔离进程并回收临时目录；旧有效网格继续存在。进程崩溃、超时、页面刷新、网络断开后可查询任务状态；重复请求带幂等键，不能多次重复计算。

前端保存草稿、命名和配置到 IndexedDB，网格二进制单独缓存，元信息与当前结果指针原子更新。空间不足时显示未保存状态并提供下载。多标签页使用版本比较与写入者标记，不无声互相覆盖。

服务端任务结果以不可预测能力标识隔离，接口限制模型大小、计算时间和并发，不接受任意路径、Shell 或用户脚本；几何请求按结构化 JSON 解析。本地默认一个生成进程，其他请求排队；部署时资源参数可配置。

网格参数和命名修改可撤销／重做，至少保存 100 条普通操作；大网格结果按缓存引用回退，不为每次改名复制全部节点。删除缓存不删除建模文档。

## 12. 质量检查与完成判定

质量页必须提供真实最小值、最大值、分位数、直方图、阈值筛选和坏单元定位。每个指标说明公式与范围，不混用其他软件同名指标的数值。

必需检查分为两类：

**结构性错误，阻止接受与求解导出：**

- 非有限坐标、无效索引、零面积、负向单元、凹／自交四边形、重复或重叠单元。
- 孔内有单元、单元越出区域、约束边未恢复、区域漏网格。
- 非流形面、邻接缺失、共形接口出现裂缝、周期节点映射不一致。
- 当前命名为空、边界缺失／重复归属、面域归属缺失、引用失效、网格已过期。

**工程质量警告，允许查阅并明确接受：**

- 三角形最小角／最大角、四边形角度偏斜、单元伸长比。
- 内部面的非正交角：单元质心连线与该面法向的夹角；边界面另计算 owner 质心到面中点方向的角度，分别统计。
- 三角形形状指标 `q = 4√3 A / (l1²+l2²+l3²)`，等边三角形为 1；四边形使用单独定义的有符号缩放 Jacobian。
- 邻接单元面积比、局部尺寸达成情况、曲线弦差和网格覆盖面积误差。
- 边界层的实测首层高度、实际层数、增长与厚度偏差。

默认提示阈值：三角形最小角小于 20°、四边形偏离 90° 超过 45°、非正交角大于 70°、各向同性区伸长比大于 10。均为本产品可调整的检查规则，不宣称对所有求解器通用；边界层单独统计伸长比，不套用各向同性区的合格判定。

区域面积检查比较真实几何与单元面积和。精确直边样例相对误差目标 ≤10^-8；曲边样例使用 `max(10^-8 × A, 2δP + πδ²)` 作为几何逼近预算并显示实际误差，其中 δ 为设定弦差、P 为边界总长。该预算不替代单元越界／重叠检查。所有数值阈值和单位写入测试记录。

优化命令必须调用实际平滑／局部优化并重新校验，显示前后统计。硬边界、角点、接口和周期关系保持；退化或更差时回滚，不通过改颜色来“优化”。

不在本次承诺 Fluent 专有格式或直接 OpenFOAM polyMesh；二维到三维单层挤出和求解器格式转换涉及额外约定，当前交付先保证上述通用交换格式完整正确。

## 17. 性能目标和资源边界

以下是验收目标，不能写成当前实测结论。测试记录 CPU、内存、系统、浏览器精确版本、视口、DPR、内核版本和冷热缓存；每个基准至少20次测量，报告中位数和P95。

| 场景 | 目标 |
|---|---|
| 桌面显示10万二维单元 | 缩放／平移帧间隔P95≤33 ms；拾取反馈P95≤100 ms |
| 手机显示2万单元 | 使用适当显示密度，帧间隔P95≤50 ms；命名操作反馈≤200 ms |
| 简单10万单元生成 | 指定8核、16 GB参考电脑热启动P95≤30秒，主界面持续可操作 |
| 500条边、50个孔几何准备 | P95≤5秒；复杂或失败输入可取消并定位 |
| 任务取消 | 接口确认后2秒内停止计算并释放对应进程 |
| 本机10万单元结果恢复 | 暖缓存可见结果P95≤3秒，随后完善质量和索引 |

默认每任务上限：输入几何20000条边、面域1000个、节点600000、单元1000000、请求50 MiB、结果包256 MiB、生成时间120秒。内核进程还必须限制实际内存与输出大小，不能等全部生成后才检查数量。超过预算给出明确错误；部署管理员可调整，上限不表示任意上限模型均满足上述响应时间。

大任务提前显示单元量级和资源估计，用户确认后运行；估计值与真实结果分开显示。手机可生成服务端大网格，但显示允许抽样，命名仍针对原几何。

## 18. 最终交付物与完成标准

交付必须同时具备：

1. 集成到网站的完整二维网格工作区和双向导航。
2. 可运行的真实网格内核、锁定依赖、Windows／Linux启动与部署配置。
3. 完整边界命名、面域命名、接口配对、设置、生成、检查、保存、恢复与导出。
4. G01–G16固定样例、错误模型、数值与拓扑自动化测试。
5. MT-01–MT-32逐项浏览器／文件／性能验收记录，未执行项不能写通过。
6. 网格用户操作说明、格式与单位说明、算法适用范围、旧求解器兼容说明和第三方依赖清单。

验收以“使用现有模型完成真实网格及命名的完整闭环”为标准。只有全部本次范围内的必需功能和检查通过，才认定网格模块完成；按钮、抽样格线、静态质量数字或仅通过编译均不构成完成。

本计划只提出并定义上述开发，不包含立即修改应用代码、安装运行时、提交或推送仓库的操作。
