# CFD 边界条件与求解计算开发记录

更新日期：2026-09-23。

本文记录《CFD边界条件与求解计算完整开发计划》对应代码的实际状态。它只把已经由代码和测试证明的能力标为完成，避免将界面、配置文件或能力探测误写成生产求解能力。

## 已实现并验证

- 建模、网格、物理设置、求解、后处理使用同一五步工作流；旧方腔专用边界页面已移除。
- 网格面域可以在物理设置页指定为流体、固体或未分配；所有网格命名边界逐条生成边界条件。
- 支持流体、固体、单向流固耦合、双向流固耦合四种算例类型和本地保存。
- 流体材料包含密度和动力黏度；固体材料包含弹性模量、泊松比、密度、厚度及平面应力／平面应变选择。
- 固体边界支持固定、X/Y 滚动约束、自由边界、面力和压力载荷；求解前检查缺失网格、无效材料、未约束刚体模态及网格版本。
- 内置二维线弹性有限元将四边形拆为三角形计算，使用稀疏刚度矩阵与预条件共轭梯度法；输出节点位移、单元应力、von Mises 应力及约束反力。
- 内置薄通道 FSI 支持压力到结构的一向传递，以及流道高度、压力分布与结构位移之间的隐式双向迭代；输出流量、最小间隙和耦合残差。
- 规则映射矩形方腔继续由原有流函数—涡量求解器计算。
- 后处理显示结构变形和应力云图、关键极值、耦合量，并导出包含算例与结果的 JSON。
- 服务端提供统一求解 API、输入规模限制及二次校验；能力 API 探测 OpenFOAM、CalculiX 和 preCICE，不存在时明确显示“未安装”。
- 服务端任务支持排队、运行、成功、失败和取消状态，记录输入哈希、阶段、进度、开始／结束时间并持久化到 `.run/analysis-jobs`；页面能够恢复同一网格工程最近一次任务。服务重启时，未结束的旧任务会被明确标记为中断失败，避免显示虚假的运行状态。
- 外部求解包 API 能从同一网格与物理算例生成 OpenFOAM 三维薄挤出网格及场文件、CalculiX 二维结构输入文件，以及流固耦合所需的 preCICE 配置和接口清单。算例包包含网格 SHA-256、运行命令、警告和可审计的 `case.json`。
- 数值测试覆盖结构位移方向、载荷—反力平衡、单向耦合、双向耦合压力梯度、流量及输入诊断。
- 实际浏览器流程已验证“矩形建模—区域生成—1504 单元网格—固体材料/约束/面力—后台任务—应力后处理”；该算例 809 个节点，内置三角形有限元正常收敛并显示位移、von Mises 应力与约束反力。
- 修正了窄屏建模区的网格列定位，避免左右抽屉改为绝对定位后中间 SVG 画布被压缩为 0；修正了物理工作台的自动组件名称，使物理设置、求解和后处理实际挂载；“重置算例”现在同时清空建模与网格状态。

## 当前适用范围

内置结构内核适用于小变形、各向同性线弹性、静力、二维平面应力／平面应变。内置 FSI 是沿 x 方向延伸的薄通道降阶模型，适合验证边界、载荷传递和耦合闭环。它不是任意流场的 ALE FSI，也不等同于 OpenFOAM、CalculiX 与 preCICE 的组合。

通用非结构流体、瞬态结构、有限变形、湍流、非匹配界面映射、ALE 动网格和外部求解器检查点续算仍需计划中锁定的外部求解环境。当前机器没有检测到 OpenFOAM、CalculiX 和 preCICE，因此已生成的外部算例文件经过结构测试，但尚未在这些程序中完成端到端执行验证。preCICE 配置部署前仍需使用目标版本的 `precice-tools check` 校验。

后台任务目前在单个 Node 进程中调度。排队阶段可以可靠取消；内置数值内核进入同步计算后，事件循环无法在矩阵求解中途响应取消。若要获得运行中强制终止、并发配额、远程执行和断点续算，需要把数值内核移入 Worker／子进程或外部任务队列。

## 验证命令

```text
npm run typecheck
npm run test:modeling
npm run test:meshing
npm run test:physics
npm run test:external-case
npm run test:analysis-jobs
npm run build
```

Windows 本机已通过上述检查，生产构建可由 `node .output/server/index.mjs` 启动，仿真页面、能力接口、任务接口和有效外部算例包请求均已验证。物理求解、外部算例生成和任务持久化测试也使用 WSL Node 22 与独立安装的 Linux `tsx` 运行通过。直接从 WSL 复用 Windows `node_modules` 会缺少 Linux 原生 npm 可选绑定，Linux 部署必须在 Linux 文件系统或容器内执行全新 `npm ci`，不能复制 Windows 依赖目录。
