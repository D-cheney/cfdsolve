阅读建议：

1. 第一次运行项目：先读《配置与运行手册》；
2. 接手功能开发：阅读《网站逻辑与功能总结》；
3. 修改表结构或迁移：阅读《数据库运行说明》；
4. 判断功能是否已生产可用：以《网站逻辑与功能总结》的实现等级和已知限制为准。
5. 浏览或维护知识内容：从《知识库内容总索引》进入对应专题。
6. 验收本轮整体整改：查看《深度审计与测试报告（2026-08-24）》中的测试证据和已知边界。
7. 进行批量仿真与校核：阅读《参数扫描与工况对比实验室》。
