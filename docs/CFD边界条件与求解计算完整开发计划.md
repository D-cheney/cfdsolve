# CFD菜鸟｜流体、固体与流固耦合边界及求解完整开发计划

编制日期：2026-09-22。代码基线：`a8819ed7`。

修订范围：独立流体、独立固体力学、单向流固耦合和双向流固耦合均为本次必需交付。原先仅支持流体、固定网格及排除固体求解的范围已替换。保留文件名以免已有链接失效。

本文定义一次完整交付的开发范围、接口、实现要求和验收标准，不拆成功能交付阶段。实施任务可以按依赖关系安排，但全部必需项通过后才能宣布本模块完成。本文是开发规格，不能作为功能已实现的证明。

## 1. 交付目标与范围

用户从已有二维模型生成流体与固体网格，继承边界与面域名称，指定材料、边界、初始条件和耦合界面，在 Linux 服务器计算流场、结构响应或两者相互作用；用户能看到流体残差、结构平衡、界面收敛和监控量，停止或续算任务，并查看流场、位移、应力及耦合结果。

四种模式均须可独立新建、检查、计算、保存和导出：

| 模式 | 必需计算能力 |
|---|---|
| 独立流体 | 二维单相等温不可压缩牛顿流体，稳态／瞬态，层流／k–ω SST RANS/URANS，孔洞及三角形／四边形／混合网格 |
| 独立固体 | 二维平面应力／平面应变，静力／瞬态动力，线弹性与经验证的有限变形弹性模型，多材料共形粘结区域 |
| 单向流固耦合 | 压力及黏性载荷传给结构，静态快照或瞬态载荷历史；计算结构位移／应力，流体几何不反馈更新 |
| 双向流固耦合 | 流体载荷驱动结构变形，结构位移／界面速度反馈流体，ALE 动网格与隐式强耦合；静态平衡与瞬态响应 |

有限变形必须对应明确的本构、应力及应变度量，不能只把小变形结果画成大变形。双向 FSI 必需验收目标包含平面应变结构；独立固体与单向耦合同时支持平面应力。离面运动、壳弯曲和真实三维 FSI 不属于二维目标。

本次范围外：可压缩流、激波、多相自由液面、传热／共轭换热／热应力、浮力、化学反应、塑性、断裂、摩擦接触、滑移／拓扑改变、自适应重网格、轴对称及真实三维计算。FSI 必需的 ALE 网格变形及两侧非匹配界面数据映射属于本次范围。二维湍流不能标注为已解析三维湍流结构。

流体与固体均为真实计算面域，其内部不能重叠。流体占据扣除结构后的空间，结构区域保留独立材料与网格，两侧共享几何界面或配对的重合曲线。刚性障碍物可只作为流体壁面；弹性结构必须分配固体模型，不能统统当成固定孔壁。

默认使用路径为：

**选择分析模式 → 接受流体／固体网格 → 材料与域分配 → 各物理场边界及耦合界面 → 初始条件 → 求解与耦合控制 → 算例检查 → 计算监控／停止／续算 → 结果交接。**

这些是用户的操作顺序，不是开发阶段。

## 3. 求解内核与 Linux 架构

采用 **OpenCFD OpenFOAM + CalculiX + preCICE**：OpenCFD 承担流体及 ALE 求解，CalculiX 承担固体，preCICE 协调双向耦合。候选组合为 OpenCFD v2506、preCICE 3.x、CalculiX 适配版 2.20.x；确切补丁号、编译选项与适配器提交由兼容组合测试锁定，不以浮动标签发布。

原计划 Foundation 13 不再作为默认内核。官方 preCICE 兼容表以 OpenCFD 为主要支持对象，不能推定 Foundation 新版即插即用；所有流体字典、命令和模板须统一调整。依据：[适配器兼容表](https://precice.org/adapter-openfoam-support)。

锁定组合必须通过独立流体、独立固体、官方弹性挡板及应用生成耦合算例的编译和运行验证；失败则修正组合或适配器，不能删掉双向 FSI。适配器只是接入基础，网站的区域转换、约束、厚度和结果映射仍需开发。现有生产服务器的软件与资源尚未核实。

采用以下结构：

```text
浏览器工作台
    │ 同源 API：设置、校验、提交、事件、结果
Nuxt API ── SQLite（算例版本、任务、事件索引）
    │ 持久化任务队列
独立求解 Worker ── 每次运行一个受限 Linux 作业容器
    │ 分区网格检查 → 流体／固体内核输入 → 参与求解器
    │                                └─ preCICE 界面迭代协调
持久化算例目录（原始日志、检查点、场文件、结果索引）
```

长任务不绑定一个 HTTP 请求，不使用现有网格 API 的 120 秒同步子进程方式承载求解。关闭页面、刷新、断开 SSE 或重启 Nuxt 不得结束求解。

默认单机 SQLite 队列、一个 Worker、一个运行槽。独立分析预算默认 2 核／4 GiB／2 GiB 输出／30 分钟；FSI 默认 4 核／8 GiB／10 GiB 输出／4 小时，各参与者共同计入。这些是可调整预算，不是保证完成时间。资源不足则排队或拒绝；Worker 使用事务领取、租约心跳和 fencing token 防止重复执行，多机计算不使用网络盘 SQLite。

Worker 可独立重启，Nuxt 不接触 Docker socket。镜像非 root、无外网、只挂载该任务目录并限制资源。FSI 两内核默认在同一作业容器内，允许 loopback／IPC 通信，不能把耦合通信也禁掉。用户仅填写结构化参数，禁止上传脚本、动态编译代码和任意求解器指令。

## 4. 网格到流体／固体求解的真实交接

### 4.1 唯一可信输入

只读取用户接受的 `MeshResult`，保留节点 ID、单元 ID、边界组 ID、面域组 ID 和原始 mm 单位。不能按外包框重建矩形网格，也不能按节点排序猜测连接关系。

提交时固化几何、网格、命名和条件快照。分别记录 `geometryHash`、`meshHash`、`boundaryAssignmentHash`、`caseHash`，校验通过后任何物理相关变化都会撤销可运行状态；改显示颜色不影响计算。

FSI 的 `meshHash` 标识参考网格与拓扑；每个已接受时刻另存变形坐标及其指纹。合法 ALE 运动不能误触“用户修改网格”的失效逻辑，用户重划分也不能冒充同一次 ALE 运动续算。

### 4.2 流体转换方案

采用可测试的直接 `polyMesh` 构造器，把每个二维三角形／四边形沿 z 方向拉伸为一层棱柱／六面体：

1. 坐标由 mm 精确转换为 m；面积、长度、厚度与黏度使用统一 SI 量纲。
2. 按规范化节点对构造二维边邻接。内部边恰好邻接两单元，外边恰好一单元；重复、三重邻接、悬挂节点和未拆分 T 接口阻断提交。
3. 生成 points、faces、owner、neighbour、boundary、cellZones；内部面在前、边界面按 patch 连续排列，法向与 owner/neighbour 一致。
4. 前后两面设 `empty`，z 方向仅一层且速度 z 分量为零；用户无需手动设置前后面。
5. 平面网格单元数与拉伸后体单元数相同；导出完整 ID 映射，结果按映射还原到原始单元。
6. 共形同材料流体分区间共享边转为内部面。流固界面必须保留为流体外 patch 和固体载荷面／节点集，不能合并成内部流体面。非共形流体—流体连接不支持；非匹配流固采样按第18节映射。
7. 运行 `checkMesh`，检查非正体积、面方向、封闭性、退化面、非正交和偏斜；硬失败阻断，警告记录具体数量和位置。不能只检查进程退出码。

MSH 4.1 保留为用户导出格式，不能假定二维 MSH 直接交给某个网格转换命令就能得到正确三维体网格。转换器输出必须单独验证。

### 4.3 二维厚度与流量／受力

算例要求显式厚度与平面假设。独立流体的 `referenceDepthM` 默认 1 m，表示二维积分参考厚度，不代表侧壁摩擦；平面应力结构还需真实厚度定义刚度、质量与载荷。平面应变 FSI 统一按单位厚度求解，并用同一参考厚度换算总量。界面展示：

- 总质量流量 kg/s 与单位厚度质量流量 kg/(s·m)。
- 总体积流量 m³/s 与单位厚度流量 m²/s。
- 总受力 N 与单位厚度受力 N/m。

同一二维速度场的总流量和总受力随参考厚度成比例变化。质量入口若指定总 kg/s，改变厚度也会改变入口速度，必须使旧结果失效。

### 4.4 固体网格与耦合侧网格

固体网格支持三角形／四边形有限元适配，并保留原单元到求解单元、积分点的映射；增加材料号、阶次、单元族、积分方式和厚度。流体质量指标不能代替固体 Jacobian、畸变与锁死检查。弯曲默认使用经验证的二次或相容弯曲单元，新增中间节点投影到真实曲线。

独立固体使用支持的平面应力／平面应变单元；FSI 按 CalculiX 适配器要求构建受约束的单位厚度实体网格和二维接口，不能假设所有二维单元都直接兼容。三角形挤出如需拆成四面体，必须全局一致拆分、记录一对多映射、检查裂缝；z 约束真正实现平面应变，禁止离面运动。

适配器的准二维位移与力采用不同厚度汇总规则；必须验证厚度分配、总力和位移还原，禁止再次手工缩放导致重复换算。依据：[CalculiX 适配器配置](https://precice.org/adapter-calculix-config)。

现有网格工程需补足按物理域接受网格、FSI 双侧边界和几何一致性检查。两侧可有不同节点密度，但几何曲线必须重合，不能用最近邻强行粘接存在缝隙的区域。

## 5. 边界条件工作区

沿用白、灰、淡蓝色，使用阶段不运行背景动画。左侧按流体域、固体域、各自材料和边界、周期／流固配对、初值和诊断组织；中央以不同淡色显示物理域、真实网格和方向；右侧显示当前物理角色的参数。切换模式需显示哪些条件保留或失效，不能丢弃结构设置。

顶部提供保存、撤销、重做、检查和进入求解；底部显示单位、选中边界长度、未设置数量和网格版本。边界条件与求解设置的撤销历史独立于几何历史。

必须支持名称搜索、点击树定位、多边界高亮、选择同类型、批量赋值、复制条件、恢复默认、隐藏其他边界。批量操作先显示作用对象数量，混合值明确显示“多个值”；不能把未改字段覆盖为默认值。

中央显示外法向 n、入口方向、移动壁面方向、压力标记和条件摘要。曲边法向按局部线段显示，不用一个总体法向误导用户。漏设置、冲突、周期配对失败可直接点击定位。

手机采用边界列表加单个属性抽屉；保留中央预览、至少 44 px 触控目标及可见错误提示。长名称、单位后缀和数值验证信息不造成横向溢出。

## 6. 材料、物理模型和压力约定

### 6.1 材料与模型

材料必填密度 ρ（kg/m³）和动力黏度 μ（Pa·s），二者必须为有限正数；运动黏度由 ν=μ/ρ 得到。允许用 ν 输入，但内部只保留一份一致物性，不能让 μ 与 ν 独立冲突。

提供常见材料的可编辑参考值，并注明参考温度与来源；选用参考物性不意味着启用温度方程。材料、稳态／瞬态、层流／SST 在算例根节点设置，默认不依据一个通用 Reynolds 阈值自动切换湍流模型。

同一连通流体域使用同一材料；固体允许多材料共形粘结区域。参与域必须明确指定，非参与区域灰显，不悄悄忽略用户指定的固体域。固体本构与约束见第17节。

### 6.2 压力、基准与约束

界面统一用 Pa 的表压，求解器不可压缩压力采用运动学压力 `p_kin=p_gauge/ρ`。结果展示时反向转换。工作压力 `p_operating` 只用于展示绝对压力 `p_abs=p_operating+p_gauge`，不会改变等温不可压缩密度。

必须区分三个概念：物理压力边界、无压力边界时的数学参考、绝对压力的展示偏置。它们不能合并为一个“参考压力”输入框。

- 已有压力出口／压力入口固定值：使用边界确定压力基准，不再附加冲突的参考单元约束。
- 全壁封闭腔：指定域内参考点与表压，服务端确定对应单元；点落在孔洞或域外时阻断。
- 全周期流动：同样固定压力零空间；周期对本身不提供压力基准。
- 全速度约束的开口边界：核对净通量兼容性；若指定通量不守恒则阻断，不能靠压力参考掩盖。

FSI 必须定义结构实际承受的内外压力基线。任意表压零点不能任意改变结构载荷，须指定湿润面及其他固体面的外界压力／预应力约定；只有外部均匀压力已抵消时才能直接施加表压载荷。改变显示用工作压力不应改变结构位移，改变真实压差必须改变载荷。控制字典以锁定 OpenCFD 版本为准。

## 7. 必须实现的边界类型

每个条件绑定稳定 `boundarySetId`，中文显示名、导出名与物理类型独立。一个外边界组恰好对应一套兼容物理条件；不同边界允许同类型，但不能重复约束同一网格边。

| 类型 | 用户输入 | 实际行为与必须检查 |
|---|---|---|
| 速度入口 | Ux/Uy，或速度大小与方向，或向内法向速度 | 按向量／局部法向构造速度；压力使用与速度通量相容的模板；禁止二维 Uz |
| 体积／质量流量入口 | 流量、单位厚度或总量、时间变化 | 正值约定为流入，按真实 patch 面积与 ρ 换算；输出积分流量必须与输入相符 |
| 静压入口 | 表压、流入方向、湍流值 | 压力驱动，速度由压力与通量求得；不能再固定相同入口总流量 |
| 总压入口 | 总表压、方向、湍流值 | 模板按不可压缩模型转换总压与静压；显示适用条件，避免把总压当静压 |
| 压力出口 | 静表压、回流策略、回流湍流值 | 允许真实局部回流；回流时使用明确的入口量；回流面积比与流量实时记录 |
| 静止无滑移壁 | 无速度参数 | U=0；压力采用版本匹配模板；湍流变量与壁面处理一起生成 |
| 移动壁 | 切向速度与方向／时间规律 | 固定几何上的切向运动；法向速度超容差阻断，不能当动网格使用 |
| 滑移壁 | 类型选择 | 零穿透、切向滑移；与无滑移和对称面明确区分 |
| 对称边界 | 类型选择 | 法向速度为零并施加相应对称约束；必须为适用平面，弯曲边建议滑移条件 |
| 开放／自由来流边界 | 来流 U、表压、湍流 | 根据局部流入／流出使用耦合模板；只支持本次不可压缩模型，不称为可压缩远场 |
| 平移周期边界 | 成对选择、平移向量、匹配容差 | 校验几何、节点和面一一对应、法向相反及循环引用；两侧条件同时生成 |
| 内部流体接口 | 同材料、共形连接关系 | 作为内部面求解；展示连通关系，不能再赋入口／出口／壁面 |
| 流固耦合界面 | 两侧边界、方向、压力基线、映射设置 | 单向传递压力与剪切，双向反馈位移和界面速度；禁止重复固定或重复施加载荷 |

不提供含糊的“任意出流”或“全部自定义”作为绕过检查的入口。旋转周期、周期压降驱动与非共形周期不在本次范围；平移周期可用于无驱动的周期衰减验证，不能暗中加入动量源。

每种边界以 `BoundaryRecipe` 注册：patch 几何类型、U/p/k/ω/νt 的字典组合、支持物理模型、必填项、交叉验证器和基准算例。不能仅把 UI 类型字符串写进字典就算完成。

衍生边界和时间函数以锁定 OpenCFD 源码、运行时查询及模板测试为准；类名、参数和回流行为逐一验证，不直接混入 Foundation 字典。

### 7.1 条件分布与时间变化

必需支持常量、线性启动斜坡、分段线性时间表，以及直线入口的抛物线速度分布。时间表校验时间递增、维度和区间覆盖；区间外默认保持端点值并明确显示。稳态算例拒绝时间变化条件。

抛物线入口指定平均速度或流量，依据局部入口坐标生成剖面，并在实际网格上积分归一化。曲线、断开的多个入口组不自动套用直线抛物线。

表达式如未来支持，只能使用受限数学解析器；本次不支持 JS/Python eval、OpenFOAM coded 条件或任意文件引用。

### 7.2 SST 设置与壁面处理

入口支持直接 k、ω，或湍流强度 I 与长度尺度 L。转换展示采用的假设与常数，例如 k=1.5(I·Uref)²、ω=√k/(Cμ^(1/4)·L)；I 为无量纲比例，百分比只用于显示，Cμ 的模板值及来源必须记录。Uref 不得在零速入口被隐式补成任意常数。

提供两个经固定版本验证的壁面配置：近壁解析和壁函数。分别生成成套 k/ω/νt 条件，不能允许用户把不同处理方式的字段随意混搭。目标 y+、首层高度和当前边界层网格一起展示；y+ 是求解后依据壁面剪应力计算的量，网格前估计不能标作实测。

近壁解析以 y+ 约 1 为设计目标；壁函数适用范围由选定模型及验证说明约束，不能写成对所有流动统一有效的硬数值。离壁分辨率不足时记录诊断，并提供返回网格修正入口。求解所得 k、ω 非有限或严重非物理解不得以静默裁剪伪装成功；内核的有界处理次数应进入日志与报告。

## 8. 初始条件与算例检查

流体初始条件包含 U、表压，启用 SST 时包含 k、ω。支持全域常量、指定面域覆盖和兼容检查点恢复。区域覆盖明确优先级，孔洞不属于流体初始化域；其中的固体由结构初值独立初始化。

压力驱动工况可选择经验证的势流速度初始化；其是否可用由能力清单控制。初始化失败应显示错误，不自动更换求解模型。

“算例检查”输出阻断项、警告项、信息项，包含对象 ID、位置、原因、修复动作。检查必须在前端即时运行，并在服务端提交前重新运行，前端通过不是后端豁免依据。

检查按 `analysisKind` 分派：固体模式不要求入口、出口或流体参考压力；独立流体不要求结构支撑；双向模式必须同时满足两侧及耦合检查。不能把所有字段硬塞进一个全必填表单。

阻断项至少包含：

1. 未接受／已过期网格、缺失单位、非有限坐标、单元退化、拓扑非流形、未覆盖或重复覆盖外边界。
2. 未指定材料或条件、物理域与分析模式不匹配、固体缺少刚度／惯性／约束、内部接口误设外边界、FSI 配对缺失或重复。
3. 周期长度／节点／面方向不匹配、周期条件孤立、压力零空间未处理。
4. 非法物性、压力与速度过约束、指定通量净不平衡、时间表不合法、参考点域外。
5. 非法数值参数、输出预算超限、缺失求解内核、运行版本不匹配或磁盘不足。
6. 静力刚体模态未消除、同一自由度冲突、耦合载荷重复、平面假设／厚度不一致、流固时间窗不同步或初始动网格无效。

警告项包含预计 Reynolds 适用性、网格非正交／偏斜、出口靠近强回流区、壁面 y+ 估计与处理方式不符、参考厚度缺乏实际工程含义。警告附原因与后果，用户可记录说明继续；硬错误不能通过“忽略全部”跳过。

## 9. 求解设置

普通设置只显示必要项，高级设置按方程、耦合、离散和输出折叠。所有最终参数写入运行快照，修改设置影响下一次运行，不改写正在运行的任务。

| 分类 | 必需设置与约束 |
|---|---|
| 稳态 | 最大外层迭代、最小观察迭代、连续满足次数、收敛阈值和松弛参数；选择经版本验证的稳态控制配方 |
| 瞬态 | 起止时间、初始／最小／最大时间步、目标 Courant 数、自适应步长开关、每步耦合校正次数 |
| 离散格式 | 一阶稳健与二阶有界预设；时间格式与稳态／瞬态兼容；具体格式名由版本模板映射 |
| 线性方程 | p、U、k、ω 分别配置求解器、容差、相对容差、最大线性迭代和预条件；根据矩阵性质限制选择 |
| 压力速度耦合 | 稳态外迭代／瞬态 PIMPLE、非正交校正、压力校正；避免把流函数参数称为压力参数 |
| 初始化 | 新初始场或指定兼容检查点；显示来源运行、时间和版本 |
| 输出 | 每 N 次迭代／每段物理时间输出、日志频率、场列表、检查点周期、保留策略 |
| 计算资源 | CPU 核数、运行预算、内存与输出配额；服务器返回实际允许值 |

预设初始值可设：稳态最多 2000 次外迭代、最少 100 次、连续 20 次满足；外层初始残差 U≤1e-5、p≤1e-4、k/ω≤1e-5；开口净质量不平衡≤0.1%。这是产品起始配置，用户可调整且需经过测试，不代表任意工况的精度保证。

瞬态默认目标最大 Co=0.5，初始步长根据用户设置和网格尺度估算并显示；不能用一次稳态残差阈值来提前终止真实非定常过程。时间步达到下限仍不能满足稳定性要求时报告失败原因。

运行时若内核或部署层限制迭代／时间／单元数量，应在提交前显示；禁止复用旧内核中隐藏的迭代截断并继续宣称按用户设置完成。

## 10. 收敛、守恒与监控

### 10.1 分开记录三类量

- 线性残差：每次方程求解的 initial residual、final residual、线性迭代次数与内核归一化定义。
- 外层／时间步信息：稳态迭代、物理时间、Δt、压力速度校正轮次、最大及平均 Co。
- 物理监控：边界流量、压降、升阻力、探针速度／压力、质量守恒和湍流量界限。

日志解析保留原始字段，UI 不把不同归一化残差画成同一个“误差”。多次压力校正要记录是哪一轮，不能只取日志末行当整个时间步的收敛判定。

### 10.2 守恒定义

外法向通量为正流出。开口稳态相对质量不平衡定义为：

`abs(sum(mdot_external)) / max(sum(mdot_in_abs), sum(mdot_out_abs), mdot_scale_floor)`。

同时展示分子绝对误差与分母参考尺度。全壁或全周期封闭域没有入口流量时，不用接近零的入口作分母；改报告绝对边界泄漏和各单元离散散度范数，并记录归一化所用 Uref、Lref。用户缺少参考尺度时只报绝对量。

移动域 FSI 使用 ALE 控制体质量平衡：`d(∫Ωρ dV)/dt + ∫∂Ω ρ(U-w_mesh)·n dA = 0`。流体体积随结构运动变化时，入口与出口瞬时流量可以不相等；必须计入体积变化和网格相对通量，不能照搬固定域的“入口等于出口”判据。无滑移流固壁面的相对质量通量应接近零。

### 10.3 完成判定

稳态“已收敛”要求：必选方程外层残差达标、守恒达标、指定物理监控在观察窗口内稳定，并连续满足要求次数。监控稳定性定义为窗口变化幅度／参考尺度，近零值用绝对容差；推荐窗口 50 次、相对变化 0.1%，随算例明确记录。

达到最大迭代但没满足判据是“完成但未收敛”，进程退出码为零也不能改成已收敛。

瞬态“完成”要求到达目标时间、没有无效场和未解决的时间步质量失败；稳态收敛标签不适用于周期涡脱落。另报每步内迭代质量、质量守恒、时间步变化与统计窗口，不用残差振荡否认合理非定常流动。

残差持续增长、NaN/Inf、负体积、超资源、文件写入失败分别有明确状态与诊断。发散检测允许启动过渡期，基于连续窗口与物理异常联合判断；不能仅凭一次残差上升强行停止。

## 11. 任务生命周期、停止与续算

每次运行生成不可变 `runId` 和输入快照，不能覆盖旧结果。状态至少包含：

```text
QUEUED → PREPARING → CHECKING_MESH → INITIALIZING → RUNNING
RUNNING → STOP_REQUESTED → STOPPED
RUNNING → CONVERGED | COMPLETED | COMPLETED_UNCONVERGED
任意活动状态 → FAILED | CANCELLED | INTERRUPTED
```

在数据库中约束合法状态转换并记录时间、原因和 Worker 租约。排队取消直接移除运行资格；请求停止运行时先写检查点，等待限定时间后再终止进程组，并标明是否存在可恢复检查点。容器、转换程序和并行子进程均需要清理。

FSI 运行包含 Fluid、Solid、Coupling 参与者子状态和共同时间窗。任何必需参与者失败，父任务都不能成功；达到耦合迭代上限必须标记 COUPLING_FAILED，并回到上一已接受时间窗，而不是输出假定已收敛的终场。

暂停功能采用“保存检查点后停止，恢复时创建继承运行”，不能用浏览器布尔开关假装暂停后端。恢复使用最新完整且校验通过的检查点，不是时间目录名字最大的半写文件。

检查点以临时目录写入，完成后原子发布清单与校验和；包含 U/p、湍流场、时间历史、时间步状态、版本、网格和边界指纹。二阶时间格式续算必须保留所需历史场。

固体检查点还包含位移、速度、加速度、应力及必要内变量。双向耦合须保存同一已接受时间窗的流体场、结构状态、ALE 网格坐标、映射版本及耦合配置；只有两个参与者都完成后才原子发布。preCICE 的窗内回滚不等于跨进程持久化重启：应用必须实现后者，恢复时若重建加速历史，需记录并验证续算误差。

完全相同物理设置可直接续算；只改停止时间或监控输出策略可创建续算分支。改变网格、材料、模型或边界后，旧场只能作为明确的初始化来源，并通过兼容／映射检查，不能称为同一运行续算。

Worker 重启后核对容器和租约；仍在运行的任务重新接管，已丢失进程的任务标为 INTERRUPTED 并提供检查点恢复。用户刷新后通过 runId 拉取历史事件和新事件，不能自动重复提交。

## 13. 求解监控 UI 与后处理交接

求解页上方显示真实阶段、运行时间、迭代／物理时间、资源和停止入口；中央为残差与监控图，侧栏为求解摘要与检查结果，下方为可搜索日志。稳态不显示伪造完成百分比，可显示“已迭代／预算”；瞬态可按物理时间进度显示比例，同时标明准备和结果转换阶段。

图表默认每秒合并刷新一次，支持开关方程、对数轴、暂停图表显示和查看历史；“暂停图表”不能与“暂停求解”混淆。日志环形缓存，原始完整日志可下载。大数据曲线可抽样但不丢失峰值和诊断事件。

最低结果交接必须包含原网格上的 Ux/Uy/速度大小、表压 Pa；SST 增加 k、ω、νt 和实际可计算的 y+／壁面剪应力。记录 cell-centered 与 point-interpolated 的区别，不把插值场标成原始求解场。

提供探针 CSV、边界流量和受力 CSV、完整算例包、VTU 与瞬态 PVD；保留原始 OpenFOAM case。对照参考厚度正确换算压降、流量和力，导出时写入模型、网格、版本、状态及未收敛说明。

旧后处理的 `field.nx/ny` 矩形数组不能消费新结果；本次至少补足三角形／四边形着色和时间／字段选择接口，确保新算例能查看真实数据。复杂后处理工具可另行开发，但不得完成求解后只能显示默认方腔图。

固体结果必须包含位移、应变、应力张量、主应力、von Mises 应力和支座反力，动力另含速度／加速度及能量。平面应变的 σzz 不得丢弃，等效应力按完整适用张量计算；注明积分点原值与节点外推／平均的区别，奇异点最大应力不能当成已收敛强度结论。

耦合结果提供同一已接受时间的流场与变形结构叠加、界面力／位移曲线、两侧残差、网格质量和映射误差。变形显示放大倍率必须显眼，计算始终使用真实位移；不可把放大图形回写成 ALE 坐标。只允许同步时间联合导出，不把不同参与者最近一帧拼成同一时刻。

## 14. Linux 部署及运行保障

交付锁定镜像的构建文件、Worker 服务定义、运行目录规范、健康检查、安装说明及启动／停止脚本。推荐 Ubuntu 24.04 x86_64 为验收基线；其他 Linux 发行版通过相同镜像验证，ARM 未测时明确返回未认证架构。

部署变量包括内核镜像、任务目录、运行槽、CPU／内存、超时、输出配额和日志保留策略；示例只放占位值。数据库迁移有备份与恢复步骤，禁止自动覆盖服务器 SQLite。

反向代理支持 SSE 长连接、关闭该路由缓冲、心跳和断线重连。服务重启测试覆盖 Nuxt、Worker 和容器三层。默认本地 SSD，磁盘不足时先拒绝新任务并通知，不能让所有在算任务写坏检查点。

卸载／清理遵循运行状态与保留策略，清理路径必须限定任务根目录且验证 runId；正在运行的任务不参与自动清理。

## 16. 数值验证与验收

### 16.1 基准工况

验证目标和误差阈值必须在实施前固定，不能因为跑不过就放宽。使用解析解与固定内核参考解两类证据；同内核对照只证明集成一致，不能替代独立物理验证。

本节为流体及公共功能验收；第19节的固体与耦合验收同为完整交付门槛，共 42 项功能验收，不能仅完成 BS 清单即宣告完成。

| 基准 | 输入及对照 | 验收要求 |
|---|---|---|
| 平面 Poiseuille | H=0.01 m、L=0.1 m、ρ=1000、μ=0.01、平均速度 0.001 m/s；入口抛物线、出口零表压 | u(y)=6Umean(y/H)(1-y/H)，Δp=12μLUmean/H²=0.12 Pa；速度相对 L2 与压降误差均≤1%，净流量误差≤0.1% |
| 平面 Couette | H=0.01 m、ρ=1000、μ=0.01、上壁 U=0.01 m/s、下壁零速、左右平移周期、压力参考 | u=Uy/H；速度相对 L2≤1%，剪应力误差≤2%；验证周期与移动壁 |
| 周期 Taylor–Green 衰减 | 双向平移周期；u=U0 sin(kx)cos(ky)e^(-2νk²t)，v=-U0 cos(kx)sin(ky)e^(-2νk²t) | 匹配解析压力初值并保存公式推导；速度 L2≤2%，三档空间／时间分辨率分别验证误差下降，时间步减半关键量差≤1% |
| 带孔通道 | 实际生成的带孔三角形／混合网格，速度入口、压力出口、孔壁无滑移 | 不得穿孔；入口出口守恒；与锁定版本独立命令行算例的压降／受力差≤1% |
| SST 通道或后台阶 | 固定版本标准湍流算例，记录模板来源、模型、壁面处理和参考网格 | 生成字典一致性；相同网格命令行与平台关键量差≤1%；验证 k/ω/νt 条件、y+ 输出和回流设置 |

## 17. 固体力学完整开发要求

### 17.1 分析与本构

固体模式无需创建虚假的流体域。支持平面应力、平面应变；线弹性静力、线弹性瞬态动力，以及具有几何非线性的有限变形弹性分析。材料库可保存钢、铝、弹性材料的参考值，但必须由用户确认实际材料，不仅凭名称选择刚度。

线弹性输入 E、泊松比 νs 与密度 ρs；E、ρs 为有限正值，理论稳定范围 -1<νs<0.5。接近不可压缩极限时按所选单元和本构的实测能力设门槛，不能只要数值小于 0.5 就允许严重体积锁死。静力可不用惯性项，转动力后密度必填。

有限变形采用锁定 CalculiX 版本支持并经验证的本构配方，至少提供可压缩 Neo-Hookean；指定剪切模量与体积参数，界面显示单位及到内核参数的精确映射。线弹性、几何非线性和超弹性开关分别说明，不能把材料非线性与大转动混为一谈。

多材料固体共形连接默认完全粘结，位移连续、牵引平衡。接触、脱粘、摩擦及损伤不在当前范围，界面不提供可运行的空选项。CalculiX 的平面单元和结构能力依据：[官方能力清单](https://dhondt.de/ov_calcu.htm)，锁定旧版本可用项仍需检查其源码和手册。

### 17.2 约束、载荷和初始状态

| 条件 | 参数与校验 |
|---|---|
| 固定支撑 | 锁定面内位移；明确平面约束，不无意锁住本应自由的横向收缩 |
| 分量位移 | ux/uy 或局部法向／切向位移，可随时间变化；冲突自由度阻断 |
| 滚子／滑移支撑 | 固定局部法向位移、保留切向；曲线边按节点方向生成经验证的约束 |
| 对称约束 | 对称线法向位移零，切向自由；须与实际平面假设相容 |
| 压力 | Pa、正压方向和参考基线；大变形时明确随动法向／面积更新 |
| 分布牵引 | 全局或局部向量，单位 Pa 或单位厚度线载荷；积分转换一次完成 |
| 边界合力 | 总 N 或单位厚度 N/m，按边界积分权重分配并检验合力与力矩 |
| 节点集中力 | 节点及方向，注明局部应力奇异性，验收使用位移／远场量 |
| 重力／体力 | 固体专属加速度或单位体积力；不误开启流体浮力方程 |
| 耦合载荷 | 来自明确的流体运行与界面，记录压力及黏性两部分；不能与手工同源压力重复叠加 |

静力每个独立连通结构必须消除二维的两个平移与一个转动刚体模态；采用实际约束矩阵／刚度诊断，不能只数固定节点。也检查过约束、重复自由度、孤立组件和载荷作用域。动力学允许数学上可解的无支撑运动，但需完整初值；当前双向 FSI 以有支撑结构为验收范围，不宣称支持自由漂浮刚体系统。

初始条件包含位移和速度，必要时包含一致初始应力；初始加速度由平衡求得或校验。预载／初应力必须来自已验证初始化步骤，不能仅填写一个数值而省略平衡过程。

### 17.3 计算控制与收敛

静力设置载荷步、初始／最小／最大增量、最大 Newton 迭代、残余力与位移增量容差；载荷切换／几何非线性导致失败时允许有限次减步重试，保留每次失败原因。

动力设置起止时间、时间积分方案、步长、质量矩阵与可选阻尼；默认无物理阻尼，数值耗散与材料／Rayleigh 阻尼分别记录。若启用 Rayleigh 阻尼，输入系数和单位，不静默调整参数以压平振荡。

结构收敛需要力平衡和位移增量同时满足。监控反力、外载、位移、动能、应变能和耗散；静力看载荷／反力平衡，动力还要计入惯性与阻尼，不能要求运动中的结构瞬时外力合计为零。

大变形检查单元 Jacobian、非物理体积变化和本构有效性。结构失败明确定位到区域／单元／增量；结果可查看已接受步，但不能称整体计算成功。

## 18. 流固耦合完整开发要求

### 18.1 单向与双向的实际行为

单向模式支持选择一个稳态／瞬态流体结果作为结构载荷来源：静态快照驱动静力，时间序列驱动动力。结构有反应但不反馈流体；缺失时间点的插值方式、输出频率及参考形状必须记录。变形足以影响流场时显示适用性诊断，不能把单向结果标成双向。

双向模式必须在每个时间窗内真实执行“结构预测 → 移动流体网格 → 求解流体 → 映射载荷 → 求解结构 → 检查界面收敛”。静态 FSI 使用外层载荷—变形固定点迭代，内层分别达到流体稳态和结构静力平衡；瞬态使用共同物理时间和隐式子迭代。不能以一次流体计算加一次结构计算代替强耦合。

### 18.2 界面定义、符号和量纲

界面对象明确流体侧、固体侧、结构参与者、参考曲线、法向及两侧网格。初始几何缝隙、交叉、重复配对、未覆盖湿润面均阻断；相同几何但采样不同可使用映射。

耦合交换物理量至少包括流体作用于固体的完整牵引，以及结构位移／界面速度。用流体向外法向 n_f 定义时，流体给固体的作用力应由 `-σ_f n_f` 积分，σ_f=-pI+τ；用固体法向时按相反法向换算。以受压薄板小算例验证方向，不能仅靠两个负号“看起来合理”。RANS 使用模型一致的有效黏性应力，压力先从运动学压力恢复为 Pa。

边界无滑移要求流体界面速度等于结构速度；ALE 网格速度用于相对对流通量，它不是另一份结构载荷。总位移、增量位移、速度、当前坐标分别命名，避免将增量反复累加或把总位移当增量。

FSI 的静态压力基线须遵循第6节，外界压力和预载作用范围可追溯。所有厚度换算只在协议边界执行一次，传输载荷明确是 N、N/m 还是 Pa。

### 18.3 非匹配映射与守恒

配对几何一致时允许流体细网格、结构粗网格。位移采用一致插值，离散力采用守恒映射；不能直接把压力采样值当节点力。曲线积分、面中心到结构节点的等效载荷分配必须包含积分权重。

每对映射需要恒定位移、刚体平移／微小转动、恒定牵引及非均匀牵引测试；检查合力、合力矩、映射位移与界面功。守恒映射保证求和不等于自动保证力矩或功守恒，后两项必须单独测；达不到标准时调整映射或界面离散，不隐藏误差。

优先选择能构造位移映射及相容载荷传递的配置；若直接使用 preCICE 配方，必须记录其确切约束和不保证的性质。映射依据：[preCICE 数据映射](https://precice.org/configuration-mapping)。禁止跨越薄板两面、尖角或不相邻边界执行最近邻搜索，双面载荷各自配对。

### 18.4 ALE 动网格

以结构真实位移驱动流体界面，外边界固定或按明确约束移动，内部使用经验证的网格运动算法。流体需要 ALE 方程、网格通量及几何守恒处理，不能只更新显示坐标后继续在旧网格上求解。

每次运动后检查最小体积、面翻转、非正交、偏斜和最小间隙。超门槛时拒绝当前耦合尝试，回滚双方与网格到窗起点，按共同重试策略缩短时间窗；达到重试／步长下限则明确失败。不得裁剪结构位移来假装收敛。累计变形已无法维持有效网格时停止并报告，本次不承诺自动重网格、接触或拓扑改变。

验收需要“均匀场随网格运动”的几何守恒测试，证明没有仅因网格变形产生虚假质量源。

### 18.5 强耦合与时间协调

默认隐式分区耦合，提供经验证的 IQN-ILS 配方；串行 Aitken 可作可选配置。记录初始松弛、历史长度、过滤和尺度归一化，低密度比／附加质量显著时必须有实际稳定性测试。参考：[preCICE 加速配置](https://precice.org/configuration-acceleration)。

耦合窗要求位移和载荷变化均满足绝对／相对阈值，并检查运动学连续及力平衡。建议起始相对容差 1e-4、最多 50 次耦合迭代；绝对容差分别按 m、N 或 N/m 输入，不能对不同量纲统一用一个数。零位移／近零力用绝对判据，不能用零分母。

内核方程收敛、结构 Newton 收敛和界面耦合收敛分别展示。参与者内部未解好时不能靠减小耦合残差蒙混过关；容差依据尺度和基准协调，不简单比较不同定义残差的数值大小。

流体按 Co、固体按积分精度与结构时间尺度设置允许步长；协调器确定共同窗口。默认双方在窗端同步，子步必须准确到达窗端并记录数据时间插值。双向适配器回滚时恢复完整 U/p、结构位移／速度／应力、历史场和 ALE 坐标；不能只回滚时钟。

达到最大耦合迭代时强制视为失败，不依赖可能默认接受的内核行为。减窗重试在两侧共同检查点上重建协调过程并清理不兼容历史；若锁定适配器不支持运行时改窗，需要在作业层实现受控重启。配置依据：[耦合方案与判据](https://precice.org/configuration-coupling)。

### 18.6 实时监控和故障处理

显示流体／结构／耦合三组日志、共同时间、窗内迭代、位移／力残差、界面合力、固体端点位移、结构能量和流体网格质量。进度以已接受时间计算；重试时解释原因，不在未接受的子迭代上虚增进度。

一个参与者退出、通信超时或检查点写坏时，父任务保存诊断并终止／回收另一参与者。用户停止整个 FSI 作业，不允许只停止流体留下结构等待。恢复必须使用共同完整检查点；只有流体结果时可显式另建单向算例，不能恢复成双向作业。

## 19. 固体与流固耦合新增验收

### 19.1 数值基准

| 基准 | 验证内容与目标 |
|---|---|
| 常应变 patch test | 三角形、四边形及多材料允许配置的基本一致性；线性场误差受线性求解容差限制，畸变单元单独测试 |
| 单轴拉伸 | δ=FL/(EA)，平面应力下自由横向收缩；位移及远离端部应力误差≤1%，反力误差≤0.1% |
| 悬臂小挠度 | 细长梁端部载荷 δ=FL³/(3EI)，I=b h³/12；满足梁理论适用条件时挠度误差≤2%，三档加密检查弯曲锁死 |
| 平面应变对照 | 同几何分别求平面应力／应变，与解析或独立参考值对照；σzz、等效应力及约束正确 |
| 结构自由振动 | 一阶频率与细长梁／固定参考结果差≤2%；时间步减半响应差≤1%，无阻尼时量化数值能量漂移 |
| 超弹性均匀伸长 | 对锁定 Neo-Hookean 本构的解析应力—伸长关系验证，误差≤1%；检验应力／应变度量及大转动客观性 |
| 单向受压弹性板 | 流体积分压力加剪切与结构外载合力一致；相同等效结构载荷与独立结构结果差≤1% |
| 静态双向弹性通道 | 压力改变→结构变形→流道改变→流量／压力改变；与锁定独立命令行耦合算例的位移、流量差≤2%，不能只有显示变形 |
| 官方垂直弹性挡板 | 使用官方 OpenFOAM／CalculiX 配方的同材料、同假设输入；启动过渡后位移幅值、频率与独立参考差≤5%，实际 ALE 网格随位移变化 |
| 挡板界面非匹配测试 | 分别改变两侧密度，合力相对误差≤0.1%、力矩与周期界面功差≤1%；关键响应保持网格收敛趋势 |
| 耦合停止续算 | 在已接受窗停止再恢复，与连续算的短时间对照位移／力误差≤1%；恢复失败和半写文件必须拒绝 |

上述阈值是开发验收目标，必须记录采样区间、参考尺度和零量绝对容差，不是任意网格自动保证的精度。FSI 至少独立改变三档网格与三档时间步，区分时间、空间和耦合误差。

弹性挡板参考：[preCICE 官方算例](https://precice.org/tutorials-perpendicular-flap)。更强附加质量测试可参考 [Turek–Hron FSI3](https://precice.org/tutorials-turek-hron-fsi3)，但该官方教程的结构实现并非默认 CalculiX，不能把更换本构／结构内核后的数值不加区分当成同一基准。本次必需的低密度比压力测试使用已经锁定并独立求得参考解的挡板工况，完整记录参数。
