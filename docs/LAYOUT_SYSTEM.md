# 布局系统与响应式规范

## 1. 设计目标

流研工坊同时包含内容阅读、工具列表、参数表单、计算结果和 Modelica 工程工作台。布局不能只依靠“桌面三栏、手机横向滚动”，而要根据任务类型选择结构：

- 内容发现页采用可伸缩 Feed/Grid；
- 文章与结果页采用主内容 + 支持信息；
- 仿真工具采用参数支持栏 + 主工作区；
- Modelica 采用宽屏三栏、中屏双栏加下沉属性区、手机纵向分区；
- 页面标题、导航、卡片正文统一在同一组垂直关键线上。

参考原则来自 [Material Design 3 canonical layouts](https://m3.material.io/foundations/layout/canonical-examples/overview)、[Fluent 2 Layout](https://fluent2.microsoft.design/layout) 和 [Carbon 2x Grid](https://carbondesignsystem.com/elements/2x-grid/overview/)。实现没有直接复制其视觉风格，只采用了可验证的栅格、间距和自适应方法。

## 2. 全局栅格

| 项目 | 规则 |
|---|---|
| 最大内容宽度 | 1360px |
| 页面边距 | `clamp(16px, 3.35vw, 48px)` |
| 基础间距 | 8px，允许 4px 半级 |
| 常规区块间距 | 桌面 72px、平板 50px、手机 42px |
| 面板圆角 | 10px |
| 触摸按钮 | 主要操作最小高度 40px，移动端保持清晰点击区域 |

导航、正文容器和页脚使用同一 `--layout-max` 与 `--layout-gutter`，避免导航品牌、标题和卡片边缘各自使用不同的起始线。

## 3. 响应式分段

### 1181px 及以上：Expanded

- Modelica 使用 216px 元件栏、流体主工作区、300px 属性栏；
- 仿真工具使用 320–360px 参数栏和自适应主内容；
- 首页能力卡片使用四列；
- 支持信息持续可见，减少反复切换。

### 821–1180px：Medium / Small desktop

- Modelica 主区域使用“元件栏 + 编辑器”；
- 属性与实验流程作为 supporting pane 下沉到主区域下方；
- 文章目录、非关键侧栏按需要隐藏；
- 列表卡片一般使用两列。

### 561–820px：Tablet / Large mobile

- 页面主结构改为单栏；
- 参数栏位于计算说明之前；
- Modelica 元件库成为横向可滚动工具带；
- 画布仅在自身区域内横向滚动，页面本身不得产生横向溢出；
- 属性区使用双列信息区。

### 560px 及以下：Compact mobile

- 所有主要内容按自然阅读顺序纵向排列；
- Modelica 属性区改为单列；
- 首页隐藏复杂流场主视觉后同步取消其高度占位；
- 主操作按钮满宽或等分排列；
- 卡片取消不必要的固定高度。

## 4. 页面模式

### 首页

首屏只承担价值说明、两个主行动和可信提示。桌面显示流场示意，手机隐藏示意并立即进入下一节，不保留空白占位。后续能力卡片使用统一高度和底部行动位置，但手机端由内容决定高度。

### 仿真工具

参数栏是 supporting pane：桌面保持在视口内，移动端恢复正常文档流。说明区、方程和模型假设共享主内容对齐线。计算进行中覆盖主工作区，不覆盖参数输入。

### Modelica 工作台

宽屏保留工程软件熟悉的“资源—编辑—属性”模型。中屏不压缩画布，而把属性区放到下一行。手机端按以下顺序排列：

1. 项目与保存/检查/运行操作；
2. 横向元件工具带；
3. 画布/源码；
4. 问题与运行历史；
5. 元件属性、算法草稿、连线和实验流程。

画布宽度独立于手机视口，使元件拓扑仍保持空间关系；横向滚动被限制在画布容器内。

### 内容与社区

内容列表按 Feed/Grid 缩减列数；文章详情保留舒适行长；社区主题在小屏隐藏次要统计，但保留状态、标题和主要行动。

## 5. 验收要求

每次涉及布局的修改至少检查以下尺寸：

- 1440×900：桌面三栏、导航与内容关键线；
- 1024×768：中屏 supporting pane；
- 768×1024：平板单栏重排；
- 390×844：手机触摸目标、自然阅读顺序与横向溢出。

所有尺寸都需要满足：

- `document.documentElement.scrollWidth <= window.innerWidth`，明确设计为内部滚动的画布/表格除外；
- 标题不逐字换行；
- 主操作在首个可视区域内可发现；
- 固定/粘性区域不遮挡输入和标签；
- 页面隐藏某个模块时同时移除其高度占位；
- 键盘焦点轮廓不被容器裁剪。
