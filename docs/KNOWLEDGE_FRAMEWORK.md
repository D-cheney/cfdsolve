# CFD菜鸟 · 知识库框架与重建方案 v1

> 目标：把"空洞的条目堆"变成真正可用的工程知识库。
> 状态：方案待确认；确认后在**测试环境 `/opt/cfdsolve-ceshi`** 落地，预览通过再 `promote-to-prod.sh` 上线。

## 1. 知识库是怎么工作的（现状逻辑）

- **唯一内容源**：`templates/knowledge/**/*.md`，每篇是「YAML Front Matter + Markdown」，标记 `template_version: flowlab-knowledge/1.0`。
- **导入器**：`server/services/knowledge-importer.ts` → 服务端用 **KaTeX 严格解析公式**（任一公式失败整篇拒收）→ 单个事务 upsert 进 SQLite（`content_items` / `categories` / `tags`）。
- **接口**：`/api/knowledge`（列表/搜索）、`/api/knowledge/:slug`（正文）、`/api/knowledge/categories`（分类计数）。
- **前台**：`/knowledge`，按 5 个**集合**浏览：CFD 理论 / OpenFOAM / Modelica / CAE 算法 / 无网格法；集合由分类 slug 前缀映射（`server/utils/knowledge-collections.ts`）。

## 2. 现状诊断（为什么"空洞、没用"）

1. **线上其实只有 44 篇**：cfd 40 + modelica 4。
2. **三个集合完全是空的**：OpenFOAM = 0、CAE 算法 = 0、无网格法 = 0。
3. **全量同步在本机跑不完**：`templates/knowledge` 共 **11,025 篇**，实测解析阶段直接 **OOM**（本机内存 1.67G）→ 知识库从未被完整导入，只剩早期的一小批。
4. **11,025 篇里 10,907 篇是机器生成的"逐文件源码桩"**（如"OpenFOAM 14 源码解析：options"，正文多为"未识别到明确的类/函数…"），本身没有知识价值。
5. **成篇内容偏短**：现有文章正文 ~600–1000 字符，缺公式推导、可复现算例、检查清单。

**结论**：不是"再塞点内容"，而是**先定义框架，再按框架重写存量 + 补齐空集合**，同时**把 1 万多条源码桩从"知识库"里剥离**。

## 3. 重建框架（集合 → 分类 → 文章）

### 集合 A · CFD 理论（cfd）
分类：流体力学基础 / 控制方程与物理建模 / 无量纲与尺度分析 / 数值离散方法 / 网格与离散质量 / 边界条件与初始化 / 湍流与近壁建模 / 传热与可压缩流 / 多相流与组分输运 / 数值稳定性与线性求解 / 验证确认与后处理
### 集合 B · OpenFOAM（openfoam）
分类：入门与算例组织 / 网格与几何 / 物理模型设置 / 数值格式与边界 / 运行与自动化 / 后处理与排错
### 集合 C · Modelica（modelica）
分类：语言基础 / 组件与复用 / 动力学与事件 / 物理域建模 / 仿真质量与初始化 / 与 CFD 联合仿真
### 集合 D · CAE 算法（cae）
分类：结构有限元 / 线性与非线性求解器 / 时间积分与特征值 / 物理离散（电磁/声学/粒子）/ 多物理耦合 / 优化·不确定度·降阶 / 算法全景图
### 集合 E · 无网格法（meshfree）
分类：方法选型 / SPH 理论与离散 / 核函数与邻域 / 边界处理 / 验证与基准

**规模目标**：~110–130 篇**深度文章**（对比现状 44 篇浅文）。

## 4. 每篇文章统一规范

- **深度**：正文 2,500–4,500 字符；≥2 个可渲染公式；≥1 个可复现示例（Python/OpenFOAM 字典/Modelica 片段）。
- **结构**：① 结论 & 适用场景 → ② 原理/物理背景 → ③ 数学与公式 → ④ 工程做法与参数取值 → ⑤ 可复现示例 → ⑥ 常见坑 & 检查清单 → ⑦ 参考资料。
- **Front matter**：`flowlab-knowledge/1.0` + 必填字段 + `tags`/`seo`；`level` 用 入门/进阶/工程/专题 分层。
- **公式**：行内 `$...$`、独立 `$$...$$`，只用标准 LaTeX（KaTeX 严格模式，禁私有字符）。

## 5. 空的分类/集合怎么补

- 先在**集合 A** 内新增空分类：`控制方程与物理建模`、`无量纲与尺度分析`、`数值稳定性与线性求解`（DB 里已存在的空分类 `control-equations / dimensionless / numerical-stability / turbulence` 归并进去）。
- 集合 B / D / E 目前为空 → 按第 3 节框架**从零建全**（OpenFOAM 工程向、CAE 算法、无网格法）。

## 6. 10,907 条"逐文件源码库"的处置（需拍板）

- **建议：不进主知识库**（它不是"知识"，会把知识库稀释成代码目录）。
- 备选：作为**独立层**（单独 collection + 默认折叠 + 标注"源码参考"），或仅保留 `openfoam-source-v14` 的 14 篇架构级文章。
